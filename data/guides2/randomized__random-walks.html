When do I reach for this?

You are moving randomly on a graph and want to know: will I reach a target? how fast do I forget where I started? The engine is spectral — the second eigenvalue \(\lambda_2\) of the walk matrix controls how quickly the distribution flattens to uniform.

  • "Does the walk reach \(t\) within poly steps?" → cover-time bound + Markov, or the mixing bound.
  • "How fast does it mix?" → bound the spectral gap \(1-\lambda_2\).
  • "Is the graph connected / bipartite?" → read it off the spectrum (\(\lambda_2<1\) iff connected; \(\lambda_n=-1\) iff bipartite).
  • Space-\(O(\log n)\) connectivity (USTCON \(\in\) RL) → a length-\(O(n^3)\) walk.

Core tools

NORMALIZED WALK OPERATOR
\(A_{ij}=\tfrac1d\) on edges (\(d\)-regular). Symmetric & row-stochastic, so real eigenvalues \(1=\lambda_1\ge\lambda_2\ge\cdots\ge\lambda_n\ge-1\) with \(\mathbf{1}\) the top eigenvector. Lazy walk \(B=\tfrac12 I+\tfrac12 A\) forces all eigenvalues \(\ge 0\). setting up any walk analysis on a regular graph
MIXING BOUND
With \(\pi=(\tfrac1n,\dots,\tfrac1n)\) and \(p^{(t)}=B^t p^{(0)}\): \[ \big\|p^{(t)}-\pi\big\|_1\le \sqrt{n}\,(\lambda_2)^t. \] bounding distance to uniform after \(t\) steps; a small \(\lambda_2\) means fast mixing
COVER-TIME + MARKOV
Cover time \(\le 2m n\); by Markov, from \(s\) the walk visits \(t\) within \(8mn\) steps with probability \(\ge \tfrac34\). "reach the target within poly steps w.h.p." with no spectral computation
Theorem Spectral gap. If \(G\) is connected then the lazy walk has \[ \lambda_2\le 1-\frac{1}{4dn^3}. \] So \(1-\lambda_2\) is bounded away from \(0\), which forces mixing (and reachability) in polynomially many steps.

Worked example — the thinking

hw2025s2 P1. Prove the spectral-gap bound by exhibiting a large coordinate gap in the \(\lambda_2\)-eigenvector.

  1. Normalize. Take a unit eigenvector \(x\) for \(\lambda_2\), so \(\sum_k x_k^2=1\). Then some coordinate has \(x_i^2\ge \tfrac1n\), i.e. \(x_i\ge \tfrac{1}{\sqrt n}\).
  2. Use orthogonality. Since \(x\perp\mathbf{1}\), \(\sum_k x_k=0\), so some coordinate \(x_j\le 0\). Now \(x_i-x_j\ge \tfrac{1}{\sqrt n}\).
  3. Walk the path. Connectivity gives a path \(i=i_1,\dots,i_t=j\) of length \(\le n\). By telescoping + Cauchy–Schwarz, some edge \((u,v)\) on it has \(|x_u-x_v|\ge \tfrac{1}{n\sqrt n}\).
  4. Convert to the gap. Relate that edge difference to the Laplacian quadratic form to extract the \(1-\lambda_2\ge \tfrac{1}{4dn^3}\) factor. The one big edge difference is what a connected graph guarantees.
Traps. Use the lazy walk before invoking mixing — a bipartite graph has \(\lambda_n=-1\), so the plain walk oscillates and never converges. Reachability needs \(\lambda_2\) bounded away from \(1\) (connectivity), which is exactly the spectral-gap theorem. Do not confuse \(\ell_1\) distance with per-coordinate deviation; the mixing bound is on \(\|\cdot\|_1\).

Checklist

  1. Write the (lazy) normalized walk operator; note \(\lambda_1=1\), eigenvector \(\mathbf{1}\).
  2. Reachability fast? → cover-time \(\le 2mn\) + Markov, or the mixing bound.
  3. Mixing rate? → bound \(\lambda_2\) via the spectral-gap argument (big coordinate gap along a path).
  4. Connectivity/bipartiteness → inspect \(\lambda_2<1\) and \(\lambda_n=-1\).
  5. State the number of steps and the resulting success probability.
