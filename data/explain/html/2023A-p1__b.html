Claim True: the isolation lemma still holds when the weight of a set is the product of its element weights instead of the sum.

Strategy Take a logarithm to turn products into sums, apply the ordinary isolation lemma there, then translate the unique minimum back.

Key idea The original proof never used that weights come from \(\{1,\dots,N\}\) — it only needed \(N\) distinct values and an additive weight. A log map supplies exactly that.

Why this move Products and "unique minimum" scream logarithm: \(\log\) is order-preserving, so it moves the multiplicative world to the additive world where we already have the lemma.

  1. Define the transform. Given a multiplicative weight function \(w\), set \(w_\ell(x)=\log w(x)\). This map is one-to-one, onto, and order-preserving from the original weights onto \(\{\log 1,\dots,\log N\}\), still \(N\) distinct values.
  2. Products become sums. If \(w(A)=\prod_{i\in A}w(i)\), then \(w_\ell(A)=\sum_{i\in A}\log w(i)\), so the multiplicative weight of a set matches its additive weight under \(w_\ell\).
  3. Apply the known lemma. The standard isolation lemma only needs distinct additive weights, which \(w_\ell\) provides. So with high probability there is a unique minimum-weight set under \(w_\ell\).
  4. Translate back. Because \(\log\) preserves order, that same set is the unique minimum under the product weight. So the lemma carries over — nothing special about sums was ever being used.
