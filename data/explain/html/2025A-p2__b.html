Claim any \(x^*\) with \(Ax^*=c\) and \(x^*\ge 0\) is an optimal solution of \((P)\).

Strategy show this one point is feasible for both \((P)\) and its dual \((D)\), and gives them the same objective value; duality then forces it to be optimal.

Key idea an equality \(Ax^*=c\) satisfies both \(\ge c\) (primal) and \(\le c\) (dual) at once, so the same point lives in both problems.

Why this move matching primal and dual objective values is the textbook certificate of optimality — no need to search over all solutions, just exhibit the pair.

  1. Feasible for \((P)\). \((P)\) needs \(Ax\ge c,\ x\ge 0\). Since \(Ax^*=c\), certainly \(Ax^*\ge c\); and \(x^*\ge 0\) is given. Both hold.
  2. Feasible for \((D)\). Recall \((D):\ \max c^Tz\) s.t. \(Az\le c,\ z\ge 0\). Take \(z=x^*\): from \(Ax^*=c\) we get \(Ax^*\le c\), and \(x^*\ge 0\). So \(x^*\) is dual-feasible too.
  3. Same objective value. The primal value at \(x^*\) is \(c^Tx^*\); the dual value at \(z=x^*\) is also \(c^Tx^*\). One point, identical value in both.
  4. Conclude optimality. Weak duality says every primal-feasible value is at least every dual-feasible value \((\min\ge\max)\). Here a feasible primal point and a feasible dual point hit the same value \(c^Tx^*\), so neither can improve past it. Thus \(x^*\) attains the primal minimum.

In short, \(x^*\) plays both roles at once and pins the two objectives together, so it must be optimal for \((P)\) — and by the same token \(z=x^*\) is optimal for \((D)\).
