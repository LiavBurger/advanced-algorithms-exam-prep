Goal add slack variables and rewrite the LP in the equality (dictionary) form that simplex runs on.

Strategy turn each inequality into an equality with a nonnegative slack/surplus variable, then solve each equation for its slack.

Key idea a "\(\ge\)" constraint loses a surplus, a "\(\le\)" constraint gains a slack, and once everything is an equality simplex can read a starting vertex by zeroing the nonbasic variables.

Why this move simplex only works on equalities plus nonnegativity, so converting the two inequalities is the required setup step.

  1. Fix the "\(\ge\)" row. \(2x_1-x_2\ge -5\) needs a surplus \(s_1\ge 0\) subtracted: \(2x_1-x_2-s_1=-5\).
  2. Fix the "\(\le\)" row. \(3x_1-x_2+2x_3\le 9\) needs a slack \(s_2\ge 0\) added: \(3x_1-x_2+2x_3+s_2=9\).
  3. State the equality form. With \(s_i,x_i\ge 0\): \(\max\,5x_1-7x_2+2x_3\) s.t. \(2x_1-x_2-s_1=-5\), \(3x_1-x_2+2x_3+s_2=9\).
  4. Solve for the slacks. \(s_1=5+2x_1-x_2\) and \(s_2=9-3x_1+x_2-2x_3\), the dictionary form.

Now the basic variables \(s_1,s_2\) are written in terms of \(x_1,x_2,x_3\), so setting those to \(0\) hands simplex a candidate vertex to start from.
