Goal Use part (c)'s recurrence to prove by induction that \(\mathbb{E}[T(n)]=O(n)\).

Strategy Guess \(\mathbb{E}[T(n)]\le cn\), plug the guess into the recurrence, sum the arithmetic series, and pick \(c\) so the algebra closes.

Key idea The recurred sum only touches the top half of sizes, so its average is about \(\tfrac34 cn\); leaving room \(\tfrac{c}{4}n\) to absorb the \(\Theta(n)\) partition cost.

Why this move A linear target with a recurrence over smaller sizes is the textbook setup for induction with an unknown constant chosen at the end.

  1. Guess and hypothesis. Claim \(\mathbb{E}[T(n)]\le cn\) for a constant \(c\) fixed later; assume \(\mathbb{E}[T(n')]\le cn'\) for all \(n'
  2. Base case. Pick \(d\) with \(T(1)\le d\). Choosing \(c\ge d\) gives \(\mathbb{E}[T(1)]\le d\le c\), so \(n=1\) holds.
  3. Apply recurrence + hypothesis. \[\mathbb{E}[T(n)] \le \frac{2}{n}\sum_{k=n/2}^{n-1}\mathbb{E}[T(k)] + bn \le \frac{2}{n}\sum_{k=n/2}^{n-1}ck + bn.\]
  4. Sum the series. Using (first + last) times half the count: first term \(\tfrac{cn}{2}\), last \(\approx cn\), about \(n/2\) terms, so \[\sum_{k=n/2}^{n-1}ck \approx \frac{\left(\tfrac{cn}{2}+cn\right)\tfrac{n}{2}}{2}.\]
  5. Simplify. Then \(\mathbb{E}[T(n)] \le \frac{2}{n}\cdot\frac{\tfrac{3cn}{2}\cdot\tfrac{n}{2}}{2}+bn = \frac{3cn}{4}+bn = n\big(\tfrac{3c}{4}+b\big).\)
  6. Close it. We need \(\tfrac{3c}{4}+b\le c\), i.e. \(c\ge 4b\). Take \(c=\max(d,4b)\); both requirements hold, so \(\mathbb{E}[T(n)]\le cn\) for all \(n\), giving \(O(n)\). In words: each level's work is a shrinking fraction of the last, so the total stays linear.
