Use one variable \(x_v\in\{0,1\}\) for each vertex \(v\in V\), where \(x_v=1\) means \(v\) is chosen into the dominating set \(D=\{v:x_v=1\}\), and \(x_v=0\) means it is not. The size of \(D\) is \(\sum_{v\in V}x_v\), which we minimize. For a dominating set, every vertex \(v\) must be in \(D\) or have a neighbor in \(D\); this is captured by requiring \(x_v+\sum_{u:(u,v)\in E}x_u\ge 1\). The IP is:

\[\text{minimize}\quad \sum_{v\in V} x_v\] \[\text{subject to}\quad x_v+\sum_{u:(u,v)\in E} x_u \ge 1 \quad\text{for all } v\in V,\] \[x_v\in\{0,1\}\quad\text{for all } v\in V.\]

Every feasible solution corresponds to a solution of the original problem: given a feasible \(0/1\) assignment, let \(D=\{v:x_v=1\}\). For each \(v\), the constraint forces \(x_v=1\) or \(x_u=1\) for some neighbor \(u\), so \(v\) is in \(D\) or has a neighbor in \(D\); hence \(D\) is a dominating set. Conversely, any dominating set gives a feasible assignment with the same value. So minimizing the objective yields a minimum dominating set.

Intuition. One yes/no choice per vertex, and each vertex demands that it or a neighbor said yes.
