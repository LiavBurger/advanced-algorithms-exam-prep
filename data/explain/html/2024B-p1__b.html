True. Suppose the polytope is \(\{x:Ax=b,\ x\ge 0\}\). Given the point \(y\), first check feasibility, which is easy: verify \(Ay=b\) and \(y\ge 0\). If either fails, \(y\) is not a vertex.

We saw in class that a feasible \(y\) is a vertex if and only if the columns of \(A\) indexed by the coordinates where \(y\) is strictly positive are linearly independent — that is, the submatrix \(A_y\) of \(A\), whose columns are exactly those coordinates, has full column rank. We can check this in polynomial time by computing the rank of \(A_y\) (for example by Gaussian elimination) and comparing it to the number of positive coordinates of \(y\). All steps are polynomial, so the test is efficient.

Intuition. A feasible point is a vertex exactly when the columns for its positive entries are independent, and checking rank is a fast linear-algebra computation.
