Goal Write minimum-cost perfect matching as an integer linear program and say what the variables mean.

Strategy Put one binary variable on each edge for "chosen or not," make the objective the total weight of chosen edges, and force every vertex to be covered exactly once.

Key idea A perfect matching is precisely a \(0/1\) choice of edges where each vertex touches exactly one chosen edge.

Why this move "Choose a subset of edges" is the natural cue for one indicator variable per edge, and "perfect matching" becomes a linear count constraint at each vertex.

  1. Variables. For each edge \(e\in E\) introduce \(x_e\in\{0,1\}\), where \(x_e = 1\) means \(e\) is in the matching and \(x_e = 0\) means it is not.
  2. Objective. The cost of the chosen set is \(\sum_{e\in E} w(e)\,x_e\), which we minimize.
  3. Perfect-matching constraint. Each vertex must meet exactly one chosen edge: \(\sum_{uv\in E} x_{uv} = 1\) for every \(v\in V\). Equality (not \(\le 1\)) is what forbids leaving a vertex uncovered.

The full program is \[\min \sum_{e\in E} w(e)\,x_e \quad\text{s.t.}\quad \forall v\in V:\ \sum_{uv\in E} x_{uv} = 1,\qquad \forall e\in E:\ x_e\in\{0,1\}.\] Every feasible \(x\) is exactly the indicator of a perfect matching, so an optimum is a minimum-cost one.
