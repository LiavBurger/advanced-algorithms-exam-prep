The statement is true. Here \(\alpha_k\) denotes the minimum number of scalar multiplications needed to multiply two \(k\times k\) matrices. We must exhibit some algorithm for \(k^2\times k^2\) matrices using \((\alpha_k)^2\) scalar multiplications; since \(\alpha_{k^2}\) is the minimum over all algorithms, this proves \(\alpha_{k^2}\le(\alpha_k)^2\).

  1. Let \(A,B\) be two \(k^2\times k^2\) matrices. Partition each into a \(k\times k\) grid of blocks, where every block is itself a \(k\times k\) matrix. This is consistent because \(k\cdot k=k^2\).
  2. Matrix multiplication respects this block structure: the product \(AB\) is computed by the same formulas as a \(k\times k\) matrix product, except the "entries" are the \(k\times k\) blocks and "entry multiplication" is block (matrix) multiplication.
  3. By definition of \(\alpha_k\), multiplying these \(k\times k\) arrays of blocks can be done with \(\alpha_k\) block-multiplications (the additions of blocks are free, as they use no scalar multiplications).
  4. Each such block-multiplication is a product of two \(k\times k\) matrices, which again by definition costs \(\alpha_k\) scalar multiplications.
  5. Hence the total number of scalar multiplications is \(\alpha_k\cdot\alpha_k=(\alpha_k)^2\). Since this is a valid method, the minimum satisfies \(\alpha_{k^2}\le(\alpha_k)^2\).
