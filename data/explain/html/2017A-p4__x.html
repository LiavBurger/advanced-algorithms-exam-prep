Goal Find how many samples estimate the fraction of ones within \(0.01\) with probability at least \(0.9\).

Strategy Sample bits, output the sample mean, and use Chernoff to size the number of samples \(n\) so the error stays under \(0.01\) with the required confidence.

Key idea Chernoff bounds the chance the sample mean strays \(0.01\) from the truth, and since the true fraction \(\mu\le 1\) we can bound \(n\) without knowing \(\mu\).

Why this move "How many samples for accuracy \(\varepsilon\) with confidence \(1-\delta\)" is exactly what a Chernoff concentration bound answers — set the tail probability to \(\delta\) and solve for \(n\).

  1. Setup. Let \(X_i\) be an indicator random variable for the \(i\)-th sampled bit being a one; the samples are independent with \(\mathbb{E}[X_i]=\mu\), the true fraction. The estimate is \(\frac1n\sum_i X_i\).
  2. Chernoff. \(\Pr\!\left[\left|\tfrac1n\sum_i X_i-\mu\right|\ge 0.01\right]\le 2\,e^{-\frac{n(0.01)^2}{3\mu}}\), where the \(2\) covers both tails.
  3. Impose confidence. Require this \(\le 0.1\). Taking logs gives \(\ln 20\le \frac{n(0.01)^2}{3\mu}=\frac{n}{30000\,\mu}\), i.e. \(n\ge 30000\,\mu\ln 20\).
  4. Drop \(\mu\). Since \(\mu\le 1\) always, taking \(n=30000\ln 20\) works for every possible \(\mu\).

So about \(30000\ln 20\approx 90000\) samples — a fixed constant, independent of the stream length — guarantee the estimate is within \(0.01\) with probability at least \(0.9\).
