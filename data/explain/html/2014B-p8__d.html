Making DLP1 integral means adding \(y_{uv}\in\{0,1\}\), so \(y_{uv}=1\) marks that edge \(uv\) is picked and a solution is a set \(M=\{uv:y_{uv}=1\}\subseteq E\). For each vertex \(v\) the constraint \(\sum_{u\in N(v)} y_{uv}\le 1\) says that at most one picked edge is incident to \(v\), i.e. no two chosen edges share an endpoint. The objective \(\max\sum_{uv} y_{uv}=|M|\) maximizes the number of chosen edges. So the integer program asks for the largest set of pairwise non-adjacent edges, which is the maximum matching problem.

Intuition. "At most one chosen edge per vertex" is exactly a matching, and maximizing the count gives maximum matching, the natural dual of minimum vertex cover.
