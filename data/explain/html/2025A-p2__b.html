We are given a point \(x^{*}\) with \(Ax^{*}=c\) and \(x^{*}\ge0\), and must show it is optimal for \((P)\). The idea is that this single point is simultaneously feasible for \((P)\) and for its dual \((D)\) from part (a), and it gives the two problems the same objective value — which, by duality, forces it to be optimal.

  1. \(x^{*}\) is feasible for \((P)\). \((P)\) requires \(Ax\ge c\) and \(x\ge0\). Since \(Ax^{*}=c\), in particular \(Ax^{*}\ge c\); and \(x^{*}\ge0\) is given. Both hold.
  2. \(x^{*}\) is feasible for \((D)\). Recall \((D):\ \max c^{\top}z\ \text{s.t.}\ Az\le c,\ z\ge0\). Take \(z=x^{*}\): from \(Ax^{*}=c\) we get \(Ax^{*}\le c\), and \(x^{*}\ge0\). Both hold, so \(x^{*}\) is dual-feasible too.
  3. Equal objective values. The primal objective at \(x^{*}\) is \(c^{\top}x^{*}\); the dual objective at \(z=x^{*}\) is also \(c^{\top}x^{*}\). So this one point achieves the identical value in both problems.
  4. Conclude optimality. Weak duality says every primal-feasible value is \(\ge\) every dual-feasible value (\(\min\ge\max\)). Here a primal-feasible point and a dual-feasible point attain the same value \(c^{\top}x^{*}\). No primal solution can go below it (it would fall under a feasible dual value, contradicting weak duality), so \(x^{*}\) achieves the primal minimum. Hence \(x^{*}\) is optimal for \((P)\) (and, symmetrically, \(z=x^{*}\) is optimal for \((D)\)).
A point that is feasible for both a primal and its dual with equal objective values is optimal for both. Since \(Ax^{*}=c,\ x^{*}\ge0\) makes \(x^{*}\) such a point, it is optimal for \((P)\).
