False. We give an instance where the rounding "\(x_i\ge \tfrac1u\mapsto 1\), else \(0\)" produces an infeasible integral solution.

Take \(A=\{a_1,a_2\}\), \(m=1\), \(U_1=A\), so \(u=|U_1|=2\) and \(c_1=1\). The only constraint is \(x_1+x_2\le 1\). The optimal fractional solution is \(x_1=x_2=\tfrac12\), of value \(1\); it is optimal because the constraint holds the sum at \(1\). The rounding threshold is \(1/u=\tfrac12\), and both \(x_i=\tfrac12\ge\tfrac12\), so both round up to \(1\). Now \(x_1+x_2=2>1\), violating the cap, so the rounded solution is infeasible.

A less trivial example: take \(A=\{a_1,a_2,a_3,a_4\}\), \(m=4\), \(U_j=A\setminus\{a_j\}\), so \(u=3\) and each \(c_j=1\). Setting every \(x_i=\tfrac13\) is feasible (each constraint sums \(3\cdot\tfrac13=1\)) with value \(4/3\), and it is optimal since any higher value would force three variables summing above \(1\). Again the threshold is \(1/u=\tfrac13\), every \(x_i=\tfrac13\ge\tfrac13\) rounds to \(1\), and each course's sum becomes \(3>1\), infeasible.

Intuition. A fair fractional split lands every variable exactly on the rounding line, so rounding them all up overfills each cap-\(1\) course.
