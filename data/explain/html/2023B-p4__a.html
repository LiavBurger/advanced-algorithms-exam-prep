Claim Every Hamiltonian cycle gives a feasible solution to the degree-constrained TSP integer program.

Strategy Encode the cycle by setting each variable to whether its edge is used, then check both degree constraints.

Key idea A Hamiltonian cycle enters and leaves each vertex exactly once, which is precisely what the constraints ask.

Why this move The IP variables are edge indicators, so the natural candidate solution is just the indicator vector of the cycle's edges.

  1. Build the solution. Given a Hamiltonian cycle \(H\), set \(x_{u,v}=1\) if edge \((u,v)\) is in \(H\), else \(x_{u,v}=0\). These are in \(\{0,1\}\), meeting the integrality constraint.
  2. Recall the degree constraints. For every vertex \(v\), the incoming edges must sum to \(1\) and the outgoing edges must sum to \(1\).
  3. Use the cycle structure. \(H\) visits each vertex exactly once as a single closed tour, so at each \(v\) it enters through one edge and leaves through one edge.
  4. Conclude feasibility. Thus each incoming sum and each outgoing sum equals exactly \(1\), so all constraints hold and the indicator vector is feasible. (Its objective value is exactly the cycle's weight, which is why the IP models TSP.)
