Claim false — the rounding "\(x_i\ge \tfrac1u\mapsto 1\), else \(0\)" can produce an infeasible integral solution.

Strategy exhibit one small instance where the optimal fractional solution sits exactly at the threshold \(1/u\), so rounding pushes everything up to \(1\) and blows a cap.

Key idea a cap of \(1\) split evenly among \(u\) students gives each \(x_i=1/u\) — right at the threshold — so all of them round up and the sum jumps to \(u>1\).

Why this move to refute a "for every input" claim you only need one counterexample, and the threshold \(1/u\) is precisely where a balanced fractional optimum lands, making it the natural place to attack.

  1. Simplest instance. Take \(A=\{a_1,a_2\}\), \(m=1\), \(U_1=A\), so \(u=2\) and \(c_1=1\). The only constraint is \(x_1+x_2\le 1\), and the fractional optimum is \(x_1=x_2=\tfrac12\) with value \(1\) — optimal since the cap holds the sum at \(1\).
  2. Rounding breaks it. The threshold is \(1/u=\tfrac12\), and both \(x_i=\tfrac12\ge\tfrac12\), so both round to \(1\). Now \(x_1+x_2=2>1\): the cap is violated, so the rounded solution is infeasible.
  3. A tighter instance. Take \(A=\{a_1,a_2,a_3,a_4\}\), \(m=4\), \(U_j=A\setminus\{a_j\}\), so \(u=3\), each \(c_j=1\). Setting every \(x_i=\tfrac13\) is feasible (each constraint sums \(3\cdot\tfrac13=1\)) with value \(4/3\), and it is optimal because any better value would force three variables to exceed a sum of \(1\).
  4. Same failure. Threshold \(1/u=\tfrac13\), and every \(x_i=\tfrac13\ge\tfrac13\) rounds to \(1\); then each course's sum is \(3>1\), infeasible again.

So the rule fails exactly because a fair fractional split lands every variable on the rounding line — round them all up and each cap-\(1\) course is overfilled.
