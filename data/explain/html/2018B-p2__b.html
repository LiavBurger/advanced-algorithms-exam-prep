When every vertex has degree at most \(\Delta\), the same greedy is a polynomial-time \((\Delta+1)\)-approximation. The proof has three ingredients: correctness (the output really is independent), a counting bound relating the output size to \(|V|\), and a trivial upper bound on \(\mathrm{OPT}\).

  1. Output is independent. Each time a vertex \(v\) is added to \(S\), all of \(v\)'s neighbors are immediately deleted from the graph, so no later-chosen vertex can be adjacent to \(v\). Hence no two vertices of \(S\) are adjacent.
  2. Upper bound on the optimum. An independent set is a subset of \(V\), so trivially \(\mathrm{OPT}\le|V|\).
  3. Counting iterations. Let \(k\) be the number of loop iterations. Each iteration adds exactly one vertex to \(S\), so the returned set has size \(|S|=k\). Each iteration deletes the chosen vertex plus its remaining neighbors — at most \(1+\Delta\) vertices in total. The loop runs until the graph is empty, i.e. until all \(|V|\) vertices have been deleted, so the deletions must account for everything: \(k\,(\Delta+1)\ge|V|\), giving \(k\ge \dfrac{|V|}{\Delta+1}\).
  4. Combine. \(|S|=k\ge \dfrac{|V|}{\Delta+1}\ge \dfrac{\mathrm{OPT}}{\Delta+1}\), which rearranges to \(\mathrm{OPT}\le(\Delta+1)\,|S|\). That is exactly a \((\Delta+1)\)-approximation.
\[ |S|=k\ \ge\ \frac{|V|}{\Delta+1}\ \ge\ \frac{\mathrm{OPT}}{\Delta+1}\quad\Longrightarrow\quad \mathrm{OPT}\le(\Delta+1)\,|S| . \]

Running time. There are at most \(|V|\) iterations. Keeping the vertices' current degrees in a heap lets us extract a minimum-degree vertex, delete it and its neighbors, and update the affected degrees, all in polynomial time per iteration — so the whole algorithm is polynomial.
