Claim Yes — the expected-runtime bound holds for every input, the worst-case array included.

Strategy Locate where the randomness actually comes from, then check what the guarantee is averaging over.

Key idea The only random thing is the pivot the algorithm flips for; the array itself is fixed, whatever an adversary hands us.

Why this move For a randomized algorithm "expected running time" always means the average over its own coin flips, not over random inputs — so it can't be broken by a bad input.

  1. Separate fixed from random. The input array \(A\) is arbitrary (possibly the nastiest one an adversary can pick); the pivots are chosen uniformly at random by the algorithm.
  2. Read off the conclusion. The analysis bounds \(\mathbb{E}[T(n)]\) for a fixed but arbitrary \(A\), averaging only over pivots. So the \(O(n)\) bound already covers the worst-case input — the answer is Yes.
