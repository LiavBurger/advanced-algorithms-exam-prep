We relax the given ILP and round at the threshold \(1/d\):

  1. Replace \(x_i\in\{0,1\}\) by \(0\le x_i\le 1\) and solve the LP for an optimal \(x^*\). Since every integer solution is LP-feasible, \(\text{LPOPT}=\sum_i w_i x_i^*\le\text{OPT}\).
  2. Round: set \(x_i=1\) if \(x_i^*\ge 1/d\), else \(x_i=0\); let \(H\) be the corresponding set.

The set \(H\) is representative. Fix any \(T_j\). Its constraint \(\sum_{i\in T_j}x_i^*\ge 1\) is a sum of at most \(d\) nonnegative terms, so not all can be below \(1/d\); some \(i\in T_j\) has \(x_i^*\ge 1/d\), hence \(x_i=1\) and \(i\in H\). So \(H\) contains an element of every \(T_j\).

The weight of \(H\) is at most \(d\cdot\text{OPT}\). For every \(i\) we have \(x_i\le d\,x_i^*\): if \(x_i=0\) this holds since \(x_i^*\ge 0\), and if \(x_i=1\) then \(x_i^*\ge 1/d\) makes \(d\,x_i^*\ge 1\). Summing with weights \(w_i\ge 0\),

\[w(H)=\sum_i w_i x_i\le d\sum_i w_i x_i^*=d\cdot\text{LPOPT}\le d\cdot\text{OPT}.\]

So \(H\) is a valid representative set of weight at most \(d\) times optimal, found in polynomial time.

Intuition. Since each \(T_j\) has at most \(d\) elements, one must carry a \(1/d\) LP share, so rounding at \(1/d\) covers it while losing at most a factor of \(d\).
