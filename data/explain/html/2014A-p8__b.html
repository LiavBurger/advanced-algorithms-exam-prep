Goal Bound, in closed form, the probability the random assignment satisfies fewer than \(3/4\) of the clauses.

Strategy Flip to counting unsatisfied clauses (a nonnegative quantity), then apply Markov's inequality.

Key idea "Few satisfied" is the same event as "many unsatisfied," and the unsatisfied count has small expectation \(m/8\), which Markov turns into a tail bound.

Why this move The clauses can share variables, so the satisfied indicators aren't independent; Markov needs only the mean, so it's the safe tool.

  1. Rewrite the event. With \(X=\sum_i X_i\) the number of satisfied clauses, "fewer than \(\tfrac34 m\) satisfied" is \(X<\tfrac{3m}{4}\), equivalently \(m-X>\tfrac{m}{4}\) for the unsatisfied count.
  2. Its expectation. From part (a), \(\mathbb{E}[X]=\tfrac{7m}{8}\), so by linearity \(\mathbb{E}[m-X]=m-\tfrac{7m}{8}=\tfrac{m}{8}\).
  3. Markov. Since \(m-X\ge0\), \[\Pr\!\Big[m-X > \tfrac{m}{4}\Big] \le \frac{\mathbb{E}[m-X]}{m/4} = \frac{m/8}{m/4} = \frac{1}{2}.\] So \(\Pr[X<\tfrac34 m]\le\tfrac12\).
  4. Why not Chernoff. Chernoff would need the \(X_i\) independent, but shared variables make them dependent. If one wrongly assumed independence it would give a much smaller bound like \(2e^{-m/168}\) — sharper but not justified here, so the honest closed-form answer is the Markov \(\tfrac12\).
