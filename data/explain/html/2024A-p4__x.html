Goal Write an integer linear program for weighted Max-SAT and justify the variables and constraints.

Strategy Use one binary variable per Boolean variable and one per clause, cap each clause variable by a linear count of its satisfied literals, and maximize total satisfied weight.

Key idea A clause is satisfied exactly when at least one of its literals is true, and "at least one" is captured by bounding \(z_j\) above by the number of true literals.

Why this move To turn a logical formula into an IP, encode truth values as \(0/1\) and translate "clause satisfied" into a linear inequality — the standard SAT-to-IP recipe.

  1. Variables. For each variable \(x_i\) take \(y_i\in\{0,1\}\) (\(y_i=1\) means \(x_i\) true); for each clause \(C_j\) take \(z_j\in\{0,1\}\) meant to be \(1\) when \(C_j\) is satisfied. Let \(C_j^{+}\), \(C_j^{-}\) be the variables appearing positively, negatively in \(C_j\).
  2. The program. \[\max\ \sum_{j=1}^{m} w_j z_j\quad\text{s.t.}\quad z_j\le \sum_{i\in C_j^{+}} y_i+\sum_{i\in C_j^{-}}(1-y_i),\qquad y_i,z_j\in\{0,1\}.\]
  3. Right side counts true literals. A positive literal contributes \(y_i\) (true iff \(x_i\) true); a negative literal contributes \(1-y_i\) (true iff \(x_i\) false). So the sum is the number of satisfied literals in \(C_j\).
  4. Constraint links \(z_j\) to satisfaction. If no literal is satisfied the sum is \(0\), forcing \(z_j=0\); if some literal is satisfied the sum is \(\ge 1\), permitting \(z_j=1\). Since \(w_j\ge 0\) in a maximization, the optimum sets \(z_j=1\) whenever allowed, so \(z_j=1\) iff \(C_j\) is satisfied.

Every choice of the \(y_i\) is just a truth assignment, and the objective then sums the weights of the satisfied clauses — so maximizing it solves weighted Max-SAT.
