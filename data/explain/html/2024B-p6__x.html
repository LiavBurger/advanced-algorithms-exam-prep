We must produce, in poly time, a bipartite graph that is \((C\log n,\tfrac1{100})\)-balanced with probability \(\ge 0.9\). "Balanced" means: for every size \(m\ge k=C\log n\) and every \(S\subseteq L,\ T\subseteq R\) with \(|S|=|T|=m\), the number of \(S\text{–}T\) edges is close to its "ideal" value: \(\big|\,|E(S,T)|-\tfrac12 m^2\big|\le \tfrac1{100}m^2\).

Key idea: put each of the \(n^2\) possible edges independently with probability \(\tfrac12\). Then \(|E(S,T)|\) is a sum of \(m^2\) independent \(\{0,1\}\) variables with mean \(\tfrac12 m^2\); Chernoff makes each \((S,T)\) deviate with tiny probability, and a union bound survives all \(\le n^{2m}\) pairs once \(k=C\log n\) is large enough.
  1. Algorithm & expectation. For every pair \((i,j)\in L\times R\), independently add edge \((i,j)\) with probability \(\tfrac12\). Let \(X_{i,j}\) be an indicator for the event that \((i,j)\) is an edge, so \(\mathbb E[X_{i,j}]=\tfrac12\). For fixed \(S,T\) of size \(m\), \(|E(S,T)|=\sum_{i\in S,j\in T}X_{i,j}\), a sum of \(m^2\) independent indicators, so by linearity \(\mathbb E[|E(S,T)|]=\tfrac12 m^2\).
  2. Chernoff for one pair. The deviation \(\tfrac1{100}m^2\) is a constant fraction of the mean \(\tfrac12 m^2\), so the Chernoff bound gives an exponentially small tail: \(\Pr\!\big[\,\big||E(S,T)|-\tfrac12 m^2\big|\ge\tfrac1{100}m^2\big]\le e^{-cm^2}\) for an absolute constant \(c>0\) (the failure of the balance condition for that single \((S,T)\)).
  3. Union bound over pairs of size \(m\). The number of ways to pick \(S\) and \(T\) is \(\binom{n}{m}^2\le n^{2m}\). So \(\Pr[\exists\,S,T\text{ of size }m\text{ that fail}]\le n^{2m}e^{-cm^2}=e^{2m\ln n-cm^2}\).
  4. Choosing \(C\). With \(m\ge C\log n\), the exponent \(2m\ln n-cm^2=m(2\ln n-cm)\) becomes very negative once \(cm\) beats \(2\ln n\). Taking \(C\) large enough forces this bound below \(\tfrac1{10n}\) for every \(m\ge k=C\log n\).
  5. Union bound over sizes. Sum the failure probability over all \(m\) from \(k\) to \(n\) (at most \(n\) values): total failure \(\le n\cdot\tfrac1{10n}=\tfrac1{10}\). Hence with probability \(\ge 1-\tfrac1{10}=0.9\) the graph is \((C\log n,\tfrac1{100})\)-balanced. Generating the graph takes \(O(n^2)\) coin flips, i.e. poly time.
