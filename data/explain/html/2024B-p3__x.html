Let \(M(G)\) be the set of minimum cuts of \(G\), a graph on \(n\) vertices. Fix any minimum cut \((A_0,B_0)\). As shown in class, a single run of Karger's contraction algorithm returns this particular cut with probability at least \(\dfrac{2}{n(n-1)}\), and this holds for every minimum cut, since the analysis never used anything special about \((A_0,B_0)\).

A single run outputs exactly one cut, so the events "the algorithm returns \((A,B)\)" for distinct cuts \((A,B)\) are pairwise disjoint. Therefore the probability of returning some minimum cut is the sum of the individual probabilities, and this sum is at most \(1\):

\[1\ \ge\ \sum_{(A,B)\in M(G)}\Pr[\text{the algorithm returns }(A,B)]\ \ge\ \sum_{(A,B)\in M(G)}\frac{2}{n(n-1)}\ =\ \frac{2}{n(n-1)}\,|M(G)|.\]

Rearranging gives \(|M(G)|\le\dfrac{n(n-1)}{2}\), as required.

Intuition. Each minimum cut claims its own disjoint slice of at least \(\frac{2}{n(n-1)}\) probability, and the slices must fit inside a total of \(1\), so there is room for at most \(\frac{n(n-1)}{2}\) of them.
