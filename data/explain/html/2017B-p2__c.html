The relaxation keeps the same objective and weight constraint but replaces each integrality constraint \(x_i\in\{0,1\}\) by the interval \(0\le x_i\le 1\), allowing fractional items: \[\max \sum_i b_i x_i \quad\text{s.t.}\quad \sum_i w_i x_i \le W,\qquad x_i\le 1\ \ \forall i,\qquad x_i\ge 0\ \ \forall i.\] This is now a linear program, since every constraint and the objective are linear.

Intuition. Drop the "whole item only" rule and let items be taken in fractions, turning the integer program into a solvable LP.
