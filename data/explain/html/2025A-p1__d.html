The claim is true. The set \(\{v\in\mathbb{R}^n : Av = v\}\) is precisely the eigenspace of the adjacency matrix \(A\) for eigenvalue \(1\), so its dimension equals the multiplicity of the eigenvalue \(1\). We must argue this multiplicity is exactly \(1\) for a connected regular graph.

A subtlety: the statement uses \(A\) (the adjacency matrix) and eigenvalue \(1\). For a \(d\)-regular graph the all-ones vector satisfies \(A\mathbf{1} = d\mathbf{1}\), so eigenvalue \(1\) here refers to the normalized setting where \(A\) is divided by \(d\) (the random-walk / normalized adjacency matrix), whose top eigenvalue is \(1\). Under that normalization the argument is exactly the one seen in class and the homework.

  1. The all-ones vector is an eigenvector with eigenvalue \(1\): each row of the normalized matrix sums to \(1\), so \(A\mathbf{1} = \mathbf{1}\). Thus \(1\) is indeed an eigenvalue and the eigenspace has dimension at least \(1\).
  2. Regular graphs are symmetric, so \(A\) is diagonalizable with real eigenvalues \(1 = \lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_n \ge -1\), and all eigenvalues satisfy \(|\lambda_i|\le 1\).
  3. It was proved in the homework that if \(G\) is connected then the second eigenvalue is strictly smaller than \(1\), i.e. \(\lambda_2 < 1\). This is the spectral characterization of connectivity: a spectral gap at the top.

Since only \(\lambda_1 = 1\) equals \(1\) and \(\lambda_2 < 1\), the multiplicity of the eigenvalue \(1\) is exactly \(1\), so the eigenspace \(\{v : Av = v\}\) has dimension exactly \(1\).
