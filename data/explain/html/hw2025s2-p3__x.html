The task is to decide whether the bipartite graph \(G\) has a perfect matching using exactly \(k\) red edges, and if so to find a minimum-weight one. The algorithm encodes matchings as monomials of a symbolic determinant, marks red edges with an extra variable \(y\), and reads the answer off the coefficient of \(y^k\). Let \(m=|E|\).

  1. Setup. Let \(A\) be the \(n\times n\) symbolic biadjacency matrix, with entry \(x_{i,j}\) when \((i,j)\in E\) and \(0\) otherwise. For each edge draw an independent random weight \(w_{i,j}\in\{1,\dots,10m\}\); substitute \(2^{w_{i,j}}\) for a non-red edge and \(2^{w_{i,j}}\!\cdot y\) for a red edge. Compute the determinant and write it as \(\det=\sum_{t}c_t\,y^{t}\).
  2. Matchings as monomials. Each monomial \(\prod_i x_{i,\sigma(i)}\) with nonzero coefficient in \(\det(A)\) is a distinct perfect matching \(\sigma\). After substitution, a matching with exactly \(t\) red edges contributes \((-1)^{\operatorname{sgn}(\sigma)}\,y^{t}\,2^{w(\sigma)}\), where \(w(\sigma)=\sum_i w_{i,\sigma(i)}\). Hence the coefficient \(c_k=\sum_{\sigma}(-1)^{\operatorname{sgn}(\sigma)}2^{w(\sigma)}\), summed over perfect matchings \(\sigma\) with exactly \(k\) red edges (and \(c_k=0\) if none exist).
  3. Isolation. Apply the isolation lemma to the family \(\mathcal F\) of matchings with exactly \(k\) red edges: with probability \(\ge 9/10\) there is a unique minimum-weight \(\sigma_0\). Factoring out \(2^{w(\sigma_0)}\), \[c_k=2^{w(\sigma_0)}\Big(\pm1+\sum_{\sigma\ne\sigma_0}\pm 2^{\,w(\sigma)-w(\sigma_0)}\Big).\] Since \(\sigma_0\) is the unique minimum, every other exponent is \(\ge1\), so the bracket is odd; thus \(2^{w(\sigma_0)}\) is exactly the largest power of \(2\) dividing \(c_k\).
  4. Recovering the matching. If \(c_k=0\), report that no such matching exists (always correct). Otherwise \(w(\sigma_0)\) is the minimum weight; as in class, lower each edge's weight by \(1\) and keep the edge whenever this reduces the minimum weight of a \(k\)-red perfect matching, recovering \(\sigma_0\) edge by edge. The determinant has degree \(\le n\) in \(y\), so only \(\le n\) coefficients are tracked and the whole procedure is polynomial.
