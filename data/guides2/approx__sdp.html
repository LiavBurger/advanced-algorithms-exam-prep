When do I reach for this?

The question mentions a positive semidefinite (PSD) matrix, a semidefinite program, unit vectors replacing \(\pm1\) variables, or a 0.878 approximation. In the lectures this is the second half of the approximation deck: Max-Cut cannot be written as an LP, so it is relaxed to an SDP, solved with the ellipsoid method, and rounded with a random hyperplane.

  • "Is this matrix PSD?" / "Prove PSD \(\Rightarrow\) ..." → pick whichever of the four equivalent definitions makes the step one line.
  • "Give a 0.878-approximation for a Max-Cut-like problem" → write the \(\pm1\) IP, relax to unit vectors, round by a random hyperplane, compare edge by edge.

Core tools

FOUR EQUIVALENT DEFINITIONS OF PSD
For a real symmetric \(A\in\mathbb{R}^{n\times n}\) the following are equivalent (write \(A\succeq 0\)):
  1. \(v^T A v\ge 0\) for every \(v\in\mathbb{R}^n\);
  2. every eigenvalue of \(A\) is \(\ge 0\);
  3. \(A=B^T B\) for some \(B\in\mathbb{R}^{m\times n}\), so \(A_{ij}=\langle u_i,u_j\rangle\) for the columns \(u_i\) of \(B\);
  4. every principal minor of \(A\) is \(\ge 0\).
Standard proofs: (1)⇒(2) plug in an eigenvector, \(v^TAv=\lambda\|v\|^2\). (2)⇒(3) diagonalize \(A=Q\Lambda Q^T\) and take \(B=\Lambda^{1/2}Q^T\). (3)⇒(1) \(v^TB^TBv=\|Bv\|^2\ge0\). homework PSD chain; true/false items about PSD matrices
SDP AND WHY IT IS SOLVABLE
An SDP optimizes a linear function of the entries of \(X\) subject to linear constraints and \(X\succeq0\). The PSD set is convex but not polyhedral, yet the ellipsoid method still works because there is a separation oracle: if \(Y\) is not PSD it has an eigenvector \(v\) with eigenvalue \(\lambda<0\), and \(v^TYv=\lambda\|v\|^2<0\le v^TXv\) for every PSD \(X\). By definition (3) the same program can be written with vectors: \(X_{ij}=\langle u_i,u_j\rangle\). justifying that a relaxation can be solved in polynomial time
GOEMANS–WILLIAMSON ROUNDING
Max-Cut IP: maximize \(\sum_{(u,v)\in E}\frac{1-y_uy_v}{2}\) with \(y_v\in\{-1,1\}\). Relax each \(y_v\) to a unit vector: maximize \(\sum\frac{1-\langle y_u,y_v\rangle}{2}\) with \(\|y_v\|=1\), so \(\text{SDPOPT}\ge\text{OPT}\). Pick a random \(r\) and set \(A=\{v:\langle r,y_v\rangle\ge0\}\). An edge is cut with probability \(\theta_{uv}/\pi\), where \(\theta_{uv}\) is the angle between \(y_u\) and \(y_v\). Since \[ \frac{\theta}{\pi}\ \ge\ \alpha\cdot\frac{1-\cos\theta}{2}\quad\text{for all }\theta\in[0,\pi],\qquad \alpha=\frac{2}{\pi}\min_{0<\theta\le\pi}\frac{\theta}{1-\cos\theta}\approx0.878, \] summing over edges gives \(\mathbb{E}[\text{ALG}]\ge\alpha\cdot\text{SDPOPT}\ge\alpha\cdot\text{OPT}\). Worked example — the thinking

hw2026 s4 P4. Max-2-LIN: constraints \(x_ix_j=1\) or \(x_ix_j=-1\) over \(x_i\in\{-1,1\}\). Give a 0.878-approximation.

  1. Write the IP. Split pairs into \(E_-\) (want \(x_i\ne x_j\)) and \(E_+\) (want \(x_i=x_j\)). Maximize \(\sum_{E_-}\frac{1-x_ix_j}{2}+\sum_{E_+}\frac{1+x_ix_j}{2}\).
  2. Relax. Replace \(x_i\) by unit vectors \(v_i\) and \(x_ix_j\) by \(\langle v_i,v_j\rangle=\cos\theta_{ij}\). Any \(\pm1\) assignment is feasible, so \(\text{SDPOPT}\ge\text{OPT}\).
  3. Round. Take a random hyperplane and set \(x_i=\operatorname{sign}\langle r,v_i\rangle\). Then \(\Pr[x_i\ne x_j]=\theta_{ij}/\pi\) and \(\Pr[x_i=x_j]=1-\theta_{ij}/\pi\).
  4. Compare term by term. Pairs in \(E_-\) are exactly the Max-Cut inequality. For \(E_+\) substitute \(\theta'=\pi-\theta\): \(1-\frac{\theta}{\pi}=\frac{\theta'}{\pi}\) and \(\frac{1+\cos\theta}{2}=\frac{1-\cos\theta'}{2}\), which reduces to the same inequality. Summing gives \(\mathbb{E}[\text{ALG}]\ge\alpha\cdot\text{SDPOPT}\ge\alpha\cdot\text{OPT}\).
Traps. A nonnegative determinant does not make a symmetric matrix PSD: \(-I_2\) has determinant 1 and eigenvalue \(-1\) (2024A P1b). Definition (4) needs all principal minors, not only the full determinant. PSD is a property of symmetric matrices; say so when you diagonalize. In the rounding analysis, compare ALG with SDPOPT, not with OPT directly, and state that the relaxation contains every integral solution. The ratio is in expectation over the random hyperplane.

Checklist

  1. Name the PSD definition you are using at each step and prove any equivalence you rely on.
  2. For an approximation: write the \(\pm1\) integer program and check that its objective counts satisfied constraints.
  3. Relax to unit vectors and say why \(\text{SDPOPT}\ge\text{OPT}\).
  4. State the random-hyperplane probability \(\theta/\pi\) for each pair.
  5. Compare each term of \(\mathbb{E}[\text{ALG}]\) with the matching term of SDPOPT, then sum and chain the inequalities.
