False. The \(n\) products \(Av_1,\dots,Av_n\) can be computed in \(O(n^\omega)\) time with \(\omega<3\) using fast matrix multiplication, so \(n^3\) is not required.

Stack the vectors as the columns of a matrix \(B=[\,v_1\mid\cdots\mid v_n\,]\). Then the product \(AB\) is an \(n\times n\) matrix whose columns are exactly \(Av_1,\dots,Av_n\). So computing all \(n\) products is the same as one matrix–matrix multiplication.

We saw in class that matrix multiplication can be done in time \(O(n^\omega)\) with \(\omega<3\) (for example Strassen already gives \(\omega\approx 2.81\)). This applies to any matrices and never uses the assumption that \(v_1,\dots,v_n\) are linearly independent.

Hence the batch of products is computed in \(O(n^\omega)=o(n^3)\) time, so the claim that it requires time \(n^3\) is false.

Intuition. Many matrix–vector products with the same \(A\) are just one matrix–matrix product, which fast multiplication does below \(n^3\).
