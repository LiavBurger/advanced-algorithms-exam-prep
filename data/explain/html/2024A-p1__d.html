The statement is true. Strictly positive reduced costs certify that the basic feasible solution \(z\) beats every other feasible point, uniquely.

  1. Setup: \((P)\) is \(\min c^\top x\) s.t. \(Ax=b,\ x\ge 0\). At the basic feasible solution \(z\) with basis \(B\) (nonbasic set \(N\)) we have \(z_N=0\) and \(z_B=A_B^{-1}b\), so the objective value is \(c^\top z=c_B^\top A_B^{-1}b\).
  2. Express any feasible \(y\) (with \(Ay=b,\ y\ge 0\)) through the basis. From \(A_B y_B+A_N y_N=b\) we get \(y_B=A_B^{-1}b-A_B^{-1}A_N y_N\), hence \[ c^\top y=c_B^\top y_B+c_N^\top y_N=c_B^\top A_B^{-1}b+\big(c_N-(A_B^{-1}A_N)^\top c_B\big)^\top y_N=c^\top z+\tilde c_N^\top y_N, \] where \(\tilde c_N\) is exactly the reduced-cost vector.
  3. Since \(y\ge 0\) gives \(y_N\ge 0\), and every entry of \(\tilde c_N\) is strictly positive, the term \(\tilde c_N^\top y_N\ge 0\), so \(c^\top y\ge c^\top z\): \(z\) is optimal.
  4. Uniqueness: if any coordinate of \(y_N\) were positive, then \(\tilde c_N^\top y_N>0\) and \(c^\top y>c^\top z\), so \(y\) is not optimal. Thus any optimum must have \(y_N=0\); then \(Ay=b\) forces \(y_B=A_B^{-1}b=z_B\), i.e. \(y=z\).

So \(z\) is the one and only optimal solution.
