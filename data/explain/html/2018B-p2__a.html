Claim False — the min-degree greedy does not have approximation ratio \(1\); on a family of graphs it returns \(2\) while the optimum is \(n\).

Strategy Ratio \(1\) would mean greedy always finds a maximum independent set, so we only need one family of graphs where it does much worse, forever.

Key idea Picking the globally minimum-degree vertex can be a trap: that vertex drags in neighbors whose removal wipes out a large independent set that was sitting right there.

Why this move To refute a claim you never argue in general — you build the single cleanest counterexample and just compute what greedy does versus what's possible.

  1. The graph. For any \(n\ge 3\) take \(2n+1\) vertices \(x, v_1,\dots,v_n, w_1,\dots,w_n\), with edges \(x v_i\) for all \(i\), \(v_i w_j\) for all \(i,j\), and \(w_i w_j\) for all \(i\ne j\) (the \(w\)'s form a clique).
  2. Degrees. \(\deg(x)=n\), \(\deg(v_i)=n+1\) (the \(w\)'s plus \(x\)), and \(\deg(w_i)=2n-1\) (the \(v\)'s plus the other \(w\)'s). For \(n\ge 3\), \(x\) is the strict minimum-degree vertex.
  3. What greedy does. It grabs \(x\) first and deletes \(x\) with all its neighbors, the \(v_i\)'s. Only the \(w\)-clique is left; it picks one \(w_i\), which deletes the whole clique. Now the graph is empty, so greedy stops with \(\{x, w_i\}\), size \(2\).
  4. The optimum. The \(v_i\)'s have no edges among themselves, so \(\{v_1,\dots,v_n\}\) is an independent set of size \(n\); hence \(\mathrm{OPT}\ge n\).

So greedy returns \(2\) while \(n\) was available, and the ratio \(n/2\) can be made as large as we like. In short, chasing the smallest-degree vertex once fooled greedy into throwing away the whole good set, so ratio \(1\) simply can't hold.
