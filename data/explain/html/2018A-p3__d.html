The obstacle is that \(|2x-10|\) is not a linear function of \(x\), so \(\min |2x-10|\) is not directly an LP. The standard trick is to introduce an auxiliary variable \(z\) that stands for the absolute value from above.

Key identity: for any real \(t\), the value \(|t|\) equals the smallest \(z\) satisfying both \(z\ge t\) and \(z\ge -t\). Minimizing such a \(z\) therefore reproduces \(|t|\).
  1. Set \(t = 2x-10\) and introduce \(z\). Impose \(z \ge 2x-10\) and \(z \ge -(2x-10) = -2x+10\). Together these say \(z \ge \max(2x-10,\,-2x+10) = |2x-10|\).
  2. Make \(z\) the objective: \(\min z\). At the optimum the minimization pushes \(z\) down until one of the two constraints is tight, so \(z = |2x-10|\); minimizing \(z\) is thus equivalent to minimizing \(|2x-10|\). We do not need a sign constraint on \(z\) because the two inequalities already force \(z\ge 0\).
  3. Keep the original feasibility constraint \(4x-5\ge 0\) unchanged; it is already linear.

The resulting linear program is \[\min z \quad\text{s.t.}\quad 4x-5\ge 0,\qquad z\ge 2x-10,\qquad z\ge -2x+10.\] Every constraint and the objective are linear in the variables \(x\) and \(z\), so this is a valid LP whose optimal \(z\) equals \(\min|2x-10|\) subject to \(4x-5\ge0\).
