The LP relaxation is obtained from the BIP of part (b) by relaxing the integrality constraint: we keep the objective and the capacity constraint but let each \(x_i\) take any real value in \([0,1]\) instead of only \(\{0,1\}\).

  1. Replace \(x_i\in\{0,1\}\) by the interval \([0,1]\). The discrete set \(\{0,1\}\) is exactly the integer points of the interval \([0,1]\); dropping integrality means allowing every value in between. We write the interval as two linear inequalities: \(x_i\le 1\) and \(x_i\ge 0\).
  2. Everything else is unchanged. Objective \(\sum_i b_i x_i\) and constraint \(\sum_i w_i x_i \le W\) are already linear, so they carry over verbatim.

The relaxation is therefore \[\max \sum_i b_i x_i \quad\text{s.t.}\quad \sum_i w_i x_i \le W,\qquad x_i \le 1\ \forall i,\qquad x_i \ge 0\ \forall i.\]

Why do this: the integer program is NP-hard, but this LP is solvable in polynomial time, and its optimum is an upper bound on the integer optimum (any feasible 0/1 solution is also LP-feasible). Interpreting \(x_i\in[0,1]\) as "the fraction of item \(i\) taken" makes this the fractional knapsack.
