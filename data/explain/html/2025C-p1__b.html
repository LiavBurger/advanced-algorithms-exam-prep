True. To bound the minimum \(\alpha_{k^2}\) from above, it is enough to exhibit one method that multiplies \(k^2\times k^2\) matrices using \((\alpha_k)^2\) multiplications.

Let \(A,B\) be two \(k^2\times k^2\) matrices. Partition each into \(k\times k\) blocks, where every block is itself a \(k\times k\) matrix; so \(A\) and \(B\) become \(k\times k\) matrices whose entries are \(k\times k\) blocks. Multiply these two block matrices using the optimal \(k\times k\) scheme, which uses \(\alpha_k\) block multiplications. Each such block multiplication is a multiplication of two \(k\times k\) matrices, which can be done with \(\alpha_k\) scalar multiplications.

So the total number of scalar multiplications is \(\alpha_k\cdot\alpha_k=(\alpha_k)^2\). Since \(\alpha_{k^2}\) is the minimum over all methods, \(\alpha_{k^2}\le(\alpha_k)^2\).

Intuition. Treat a \(k^2\times k^2\) product as a \(k\times k\) grid of \(k\times k\) blocks — \(\alpha_k\) outer products, each an \(\alpha_k\)-multiplication, giving \((\alpha_k)^2\).
