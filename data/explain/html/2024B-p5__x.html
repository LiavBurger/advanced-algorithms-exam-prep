Goal give a \(d\)-approximation for minimum-weight representative set (hit every \(T_j\), each \(|T_j|\le d\)) by relaxing and rounding the given ILP.

Strategy solve the LP relaxation, then take every element whose fractional value is at least \(1/d\).

Key idea a set \(T_j\) has at most \(d\) elements whose LP values sum to at least \(1\), so one of them is at least \(1/d\) — the threshold that guarantees \(T_j\) is hit.

Why this move the LP optimum lower-bounds OPT, and the bound \(|T_j|\le d\) hands you the exact rounding threshold, so relax-and-round is the natural approach.

  1. Relax and solve. Replace \(x_i\in\{0,1\}\) by \(0\le x_i\le 1\), solve the LP for \(x^*\), with value \(\text{LPOPT}=\sum_i w_i x_i^*\le\text{OPT}\).
  2. Round. Set \(x_i=1\) if \(x_i^*\ge 1/d\), else \(0\); let \(H\) be the resulting set.
  3. \(H\) is representative. Fix \(T_j\). Its constraint \(\sum_{i\in T_j}x_i^*\ge 1\) is a sum of at most \(d\) terms, so their average is at least \(1/d\); some \(i\in T_j\) has \(x_i^*\ge 1/d\), giving \(x_i=1\) and \(i\in H\). So \(H\) hits every \(T_j\).
  4. Weight bound. For every \(i\), \(x_i\le d\,x_i^*\): true if \(x_i=0\) since \(x_i^*\ge 0\), and if \(x_i=1\) then \(x_i^*\ge 1/d\) makes \(d\,x_i^*\ge 1\).

Summing with weights \(w_i\ge 0\): \(w(H)=\sum_i w_i x_i\le d\sum_i w_i x_i^*=d\cdot\text{LPOPT}\le d\cdot\text{OPT}\). So \(H\) is a valid representative set of weight at most \(d\) times optimal, found in polynomial time.
