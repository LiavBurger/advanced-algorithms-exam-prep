Claim True: \(\mathrm{BPP}(1/8,1/4)=\mathrm{BPP}(2^{-n},1-2^{-n})\).

Strategy One inclusion is trivial; for the other, take an algorithm with a weak gap and boost it by repeating and taking a majority-style vote.

Key idea A constant gap between the accept probabilities on yes- and no-instances can be amplified to an exponentially small error by running many independent copies.

Why this move Whenever you see two BPP classes with different error thresholds, the reach is always error amplification: independent repetitions plus a Chernoff bound close the gap.

  1. Easy inclusion. A tiny error rate is stronger than a large one, so \(\mathrm{BPP}(2^{-n},1-2^{-n})\subseteq\mathrm{BPP}(1/8,1/4)\) is immediate.
  2. Set up the weak algorithm. Let \(A\in\mathrm{BPP}(1/8,1/4)\) via a machine \(M\) with \(\Pr[M(x)=1]\ge 1/4\) when \(x\in A\) and \(\le 1/8\) when \(x\notin A\). There is a fixed gap around the threshold \(3/16\).
  3. Repeat independently. Run \(M\) on \(x\) about \(O(n)\) times with fresh coins each time, and accept iff the fraction of accepting runs is at least \(3/16\).
  4. Bound the error. The true accept rate sits at distance \(\ge 1/16\) from the threshold in both cases, so by the Chernoff bound the empirical count is very unlikely to land on the wrong side; the error shrinks fast, below \(2^{-n}\), once we use enough repetitions.
  5. Conclude. So the boosted algorithm places \(A\) in \(\mathrm{BPP}(2^{-n},1-2^{-n})\). Both inclusions hold, so the classes are equal — a weak coin-flip advantage is really as good as an almost-certain one.
