Goal write an ILP for bin packing and explain why every feasible solution is a valid packing.

Strategy use \(n\) candidate bins with a "used" variable each, plus an assignment variable per item-bin pair, and tie capacity to the used-flag.

Key idea the single constraint \(\sum_i w_i x_{i,j}\le B\,y_j\) does double duty: it caps a used bin at \(B\) and forbids putting anything into an unused bin.

Why this move since one item per bin is always feasible, at most \(n\) bins are ever needed, so indexing bins \(1,\dots,n\) loses nothing and makes the model finite.

  1. Variables. \(y_j\in\{0,1\}\): is bin \(j\) used. \(x_{i,j}\in\{0,1\}\): is item \(i\) placed in bin \(j\).
  2. Objective. Minimize the number of used bins: \(\min\sum_{j=1}^n y_j\).
  3. Each item placed once. \(\sum_{j=1}^n x_{i,j}=1\) for every item \(i\) forces exactly one bin to hold it.
  4. Capacity tied to "used". \(\sum_{i=1}^n w_i x_{i,j}\le B\,y_j\) for every bin \(j\). If \(y_j=1\) this reads \(\le B\) (respect capacity); if \(y_j=0\) it reads \(\le 0\), which (weights \(\ge 0\)) forces all \(x_{i,j}=0\) — nothing may go into an unused bin.
  5. Why it's valid. The placement constraints put each item in exactly one bin; the capacity constraints keep each used bin within weight \(B\); any bin holding an item is forced to \(y_j=1\), so \(\sum_j y_j\) truly counts bins used. Conversely any real packing gives a feasible \((x,y)\) of equal cost, so the ILP optimum equals the minimum number of bins.
