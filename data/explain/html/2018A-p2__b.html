Claim The \(|D|\le 3\) greedy is a polynomial-time 3-approximation for minimum hitting set.

Strategy Show it runs in polynomial time, always outputs a hitting set, then sandwich its size between \(3k\) above and \(\mathrm{OPT}\ge k\) below.

Key idea The subsets we fully grab are disjoint, so no single element hits two of them — forcing any hitting set, including OPT, to spend at least one element per grabbed subset.

Why this move Disjointness is a built-in lower bound on OPT — the same trick as vertex cover's disjoint matched edges, adapted to sets of size at most \(3\).

  1. Polynomial time. Store \(X\) as a linked list; testing \(X\cap D=\emptyset\) costs \(O(|X|)\). Since \(X\subseteq\bigcup_{D\in C} D\), \(|X|\) is bounded by the input size, so each of the \(|C|\) iterations is polynomial.
  2. It is a hitting set. After processing any \(D\) we have \(X\cap D\ne\emptyset\), so every subset is hit.
  3. Upper bound. Let \(k\) be the number of subsets that triggered an add. Each adds at most \(3\) elements, so \(|X|\le 3k\).
  4. Lower bound. Those \(k\) added subsets are pairwise disjoint, so one element hits at most one of them; any hitting set needs at least one element per subset, giving \(\mathrm{OPT}\ge k\).

Combining, \(|X|\le 3k\le 3\,\mathrm{OPT}\) — the greedy stays within a factor of three of the best possible.
