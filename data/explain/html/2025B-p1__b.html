Claim True — an \(n\times n\) by \(n\times n^2\) product can be done in fewer than \(n^4\) operations.

Strategy Cut the wide matrix into square blocks and reuse fast square multiplication on each.

Key idea Multiplying by a wide matrix is just several independent square multiplications placed side by side.

Why this move The naive count is \(n^4\); to beat it you lean on fast square matrix multiplication (exponent \(\omega<3\)), so you reshape the problem into square pieces where that tool applies.

  1. Split into blocks. Write \(B=[\,B_1\mid B_2\mid\cdots\mid B_n\,]\), where each \(B_i\) is \(n\times n\).
  2. Multiply block by block. Then \(AB=[\,AB_1\mid AB_2\mid\cdots\mid AB_n\,]\), so the whole product is \(n\) square multiplications of \(n\times n\) matrices.
  3. Count the cost. Each square product costs \(n^{\omega}\) with \(\omega<3\), so the total is \(n\cdot n^{\omega}=n^{\omega+1}\).
