The expectation is taken over the random choices of pivots made by the algorithm.

This is the natural follow-up to part (a). When we write \(\mathbb{E}[T(n)]\), the running time \(T(n)\) is a random variable, and we must be clear about what probability space it lives in.

  1. The input array is treated as fixed (arbitrary, possibly worst-case). It contributes no randomness.
  2. The only random events are the pivot selections: at each recursive call the algorithm picks a pivot uniformly at random among the current elements.
  3. These independent uniform choices determine which subarray we recurse on and hence how much work is done, so \(T(n)\) is a function of the pivot sequence. Averaging \(T(n)\) over all equally likely pivot sequences gives \(\mathbb{E}[T(n)]\).

In short, the randomness comes entirely from the coin flips inside the algorithm, which is precisely why the expectation bound is valid on every input.
