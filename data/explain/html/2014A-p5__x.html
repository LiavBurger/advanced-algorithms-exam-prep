Goal Give a \(2\)-approximation for the minimum-cost subgraph in which every receiver \(r\in R\) has a path to some sender in \(S\) (senders may differ across receivers).

Strategy Merge all senders into one artificial terminal so the task becomes an ordinary Steiner tree, then apply the known \(2\)-approximation for Steiner tree.

Key idea A zero-cost hub attached to every sender makes "reach some sender" the same as "reach the hub", collapsing many targets into a single required terminal.

Why this move "Connect each receiver to any one of a group" is exactly a Steiner-tree shape once the group is contracted to a point, and we already have a \(2\)-approximation there — so reduce rather than build from scratch.

  1. Reduction. Add one new vertex \(v\) to \(G\) and connect it to every sender \(s\in S\) with a cost-\(0\) edge; call this graph \(G'\).
  2. Why it matches. In \(G'\), a receiver reaches \(v\) iff it reaches some sender: any \(r\)-to-\(v\) path must use a zero-cost edge \((s,v)\), so it passes through a sender, and conversely any \(r\)-to-\(s\) path extends to \(v\) for free.
  3. Steiner formulation. A minimum-cost subgraph of \(G'\) connecting all of \(R\) to \(v\) is a minimum Steiner tree with terminals \(R\cup\{v\}\); since the added edges cost \(0\), its optimal cost equals the optimum of the original problem.
  4. Apply and finish. Run the known \(2\)-approximation for Steiner tree on \(G'\) with terminals \(R\cup\{v\}\). It returns cost at most twice optimal; dropping the free artificial edges gives a subgraph of the original graph that is a \(2\)-approximation.
