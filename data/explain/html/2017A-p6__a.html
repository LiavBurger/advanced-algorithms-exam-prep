Goal write minimum hitting set as a binary integer linear program.

Strategy put one \(0/1\) variable on each element, turn "hit every set" into linear constraints, and minimize the count of chosen elements.

Key idea "\(X\) meets \(D\)" means at least one element of \(D\) is picked, which is just \(\sum_{i\in D}x_i\ge 1\).

Why this move a yes/no choice per element is the natural way to model a subset, and indicator variables convert set conditions into linear inequalities.

  1. Variables. For each \(i\in S\) let \(x_i\in\{0,1\}\), where \(x_i=1\) means \(i\) is in the hitting set. The chosen set is \(X=\{i:x_i=1\}\).
  2. Constraints. The requirement \(X\cap D\neq\varnothing\) says at least one element of \(D\) is picked. Since \(\sum_{i\in D}x_i\) counts the picked elements of \(D\), this becomes \(\sum_{i\in D}x_i\ge 1\) for every \(D\in C\).
  3. Objective. Minimize the size \(|X|=\sum_{i\in S}x_i\). Altogether: \[\min\ \sum_{i\in S}x_i\quad\text{s.t.}\quad \sum_{i\in D}x_i\ge 1\ \ \forall D\in C,\qquad x_i\in\{0,1\}\ \ \forall i\in S.\] The \(\{0,1\}\) values force an all-or-nothing choice, so optimal solutions are exactly minimum hitting sets.
