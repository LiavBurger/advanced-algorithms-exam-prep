The statement is false. The claimed equivalence "\(x\) is optimal \(\iff\) \(x\) is a vertex" fails in both directions, and a single simple example already breaks it.

  1. An optimal solution need not be a vertex. Consider the program: minimize \(0\) subject to \(0\le x\le 1\). The objective is constant, so every feasible point is optimal—including all the non-vertex points in the open interval \((0,1)\), not just the vertices \(x=0\) and \(x=1\). Thus optimality does not force being a vertex.
  2. A vertex need not be optimal. In the same box \(0\le x\le 1\), if instead we minimize \(x\), the vertex \(x=1\) is feasible but has value \(1\), while the optimum is \(0\) at the other vertex. So a vertex can be strictly suboptimal.
  3. What is true (and what the false statement distorts) is a one-directional fact: if the LP is feasible and bounded, then there exists an optimal solution that is a vertex. That guarantees an optimal vertex, but says nothing forcing every optimum to be a vertex or every vertex to be optimal.
