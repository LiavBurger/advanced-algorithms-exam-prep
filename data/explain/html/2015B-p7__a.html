Read the ILP variable by variable. There is one binary variable \(x_v\in\{0,1\}\) per vertex, which we read as: \(x_v=1\) means "put \(v\) in the chosen set \(S\)", \(x_v=0\) means "leave it out". A \(0/1\) vector is therefore the same thing as a subset \(S\subseteq V\).

  1. The objective \(\max\sum_{v\in V}x_v\) counts how many vertices are chosen, so maximizing it means picking a set \(S\) of maximum size.
  2. The constraint \(x_u+x_v\le 1\) for every edge \((u,v)\in E\) says that among the two endpoints of any edge, their indicators sum to at most \(1\). With \(0/1\) values that forbids \(x_u=x_v=1\): the two endpoints of an edge cannot both be chosen.
  3. "No edge has both endpoints in \(S\)" is exactly the definition of an independent set: no two chosen vertices are adjacent.

So we are choosing a largest vertex subset with no edge inside it. This is the maximum independent set problem.
