Goal Add slacks and perform the first simplex pivot, writing the objective and basic variables in terms of the non-basic ones.

Strategy Build the starting dictionary with slacks, pick an entering variable with positive objective coefficient, do the ratio test, and substitute.

Key idea One pivot swaps one non-basic variable for one basic variable and rewrites every row in terms of the new non-basic set.

Why this move Slack variables turn "\(\le\)" rows into equalities you can read as a dictionary, and the simplex pivot is the mechanical way to raise the objective.

  1. Initial dictionary. Add slacks \(s_1,s_2,s_3\ge0\); the non-basic variables \(x_1,x_2,x_3,x_4\) start at \(0\): \[z=2x_1+4x_2+3x_3+x_4,\quad s_1=12-3x_1-x_2-x_3-4x_4,\] \[s_2=7-x_1+3x_2-2x_3-3x_4,\quad s_3=10-2x_1-x_2-3x_3+x_4.\]
  2. Entering variable. Pick a non-basic variable with a positive objective coefficient; \(x_2\) has the largest (\(4\)), so \(x_2\) enters.
  3. Ratio test. Raise \(x_2\) and see which basic hits \(0\) first: \(s_1\) allows \(12\), \(s_2\) only grows (coefficient \(+3\)), \(s_3\) allows \(10\). The tightest is \(10\), so \(s_3\) leaves.
  4. Solve for it. From the \(s_3\) row, \(x_2=10-2x_1-3x_3+x_4-s_3\).
  5. Substitute everywhere. Plug this into \(z,s_1,s_2\): \[z=40-6x_1-9x_3+5x_4-4s_3,\quad s_2=37-7x_1-11x_3-3s_3,\quad s_1=2-x_1+2x_3-5x_4+s_3.\]

(The printed solution writes \(-4x_4\) in the \(s_1\) row, a small slip — substituting \(-x_2\) into the original \(-4x_4\) adds another \(-x_4\), giving \(-5x_4\).)
