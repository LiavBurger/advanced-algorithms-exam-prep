Goal Relax the maximum-matching integer program to an LP and write it in standard form (minimize, equalities, nonnegative variables).

Strategy Drop the integrality constraint, flip the objective to a minimization, and add a slack variable to each inequality.

Key idea Standard form needs equalities, so every "\(\le 1\)" constraint gets its own nonnegative slack that absorbs the leftover.

Why this move "Form suitable for simplex" is code for standard form, and the only two things not yet in that shape are the max objective and the inequality constraints.

  1. Max to min. Turn \(\max\sum_{(u,v)\in E}x_{u,v}\) into \(\min\big(-\sum_{(u,v)\in E}x_{u,v}\big)\); negating the objective keeps the same optimizer.
  2. Inequalities to equalities. For each vertex \(v\), add a slack \(s_v\ge 0\): \(\sum_{u:(u,v)\in E}x_{u,v}+s_v=1\). Here \(s_v=1-\sum_u x_{u,v}\) just measures how far \(v\) is from being fully matched.
  3. Write it compactly. With \(A_G\) the \(|V|\times|E|\) incidence matrix (column \((u,v)\) has \(1\) in rows \(u,v\)), the LP is \(\min -\mathbf{1}^\top x\) s.t. \(A_G x + I s=\mathbf{1},\ x,s\ge 0\).

Negate the objective and let one slack per vertex soak up the slack, and the matching LP is already in the shape simplex wants.
