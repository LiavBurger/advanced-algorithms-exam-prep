We first give a randomized algorithm that is a \(2/3\)-approximation in expectation, then derandomize it.

Randomized algorithm: assign each vertex \(v\in V\) independently to one of \(V_1,V_2,V_3\), each with probability \(1/3\).

Fix an edge \((u,v)\in E\). It crosses the cut when \(u\) and \(v\) land in different sets. Whatever set \(u\) is assigned to, \(v\) lands in that same set with probability exactly \(1/3\), so \((u,v)\) crosses the cut with probability \(1-1/3=2/3\). For edge \(e\) let \(Y_e\) be an indicator random variable for the event that \(e\) crosses the cut, so \(\mathbb{E}[Y_e]=2/3\). By linearity of expectation the number of crossing edges has expectation \[\mathbb{E}[\text{ALG}]=\sum_{e\in E}\mathbb{E}[Y_e]=\frac23|E|.\] Since the optimum can cut at most all \(|E|\) edges, \(\mathrm{OPT}\le|E|\), so \(\mathbb{E}[\text{ALG}]=\tfrac23|E|\ge\tfrac23\mathrm{OPT}\), a \(2/3\)-approximation in expectation.

Derandomization (conditional expectations, as seen in class): process the vertices one at a time. For the current vertex, try each of the three sets and compute the conditional expectation of the number of crossing edges given the assignments already fixed plus this tentative choice (this is a simple count that can be evaluated efficiently), and permanently place the vertex in the set that gives the largest conditional expectation. Each step can only keep the conditional expectation from dropping, so it never falls below the initial value \(\tfrac23|E|\). When all vertices are placed, the value equals the actual number of crossing edges, which is therefore at least \(\tfrac23|E|\ge\tfrac23\mathrm{OPT}\). This deterministic algorithm runs in polynomial time and achieves a \(2/3\)-approximation.

Intuition. With three bins a random edge stays inside its bin only \(1/3\) of the time, so \(2/3\) of the edges cross on average, and greedily keeping that average up makes it deterministic.
