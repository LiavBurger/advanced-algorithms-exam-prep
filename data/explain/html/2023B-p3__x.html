We generalize the maximal-matching \(2\)-approximation for vertex cover to triples. The algorithm:

  1. Set \(C=\varnothing\).
  2. While edges remain: pick any edge \(\{u,v,w\}\), add all three of \(u,v,w\) to \(C\), and erase every edge containing at least one of \(u,v,w\).
  3. Return \(C\).

This runs in polynomial time, since each round removes at least the picked edge. It returns a valid cover: the loop ends only when no edge is left, and every erased edge had one of its vertices placed in \(C\).

Let \(k\) be the number of rounds. Each round adds exactly \(3\) vertices, so \(|C|=3k\). When an edge is picked, every other edge sharing a vertex with it is erased, so later picks share no vertex with earlier ones; the \(k\) picked edges are pairwise vertex-disjoint. Any valid cover must contain a vertex from each picked edge, and since these \(k\) edges share no vertices, that forces \(k\) distinct vertices. Hence \(\mathrm{OPT}\ge k\), and

\[ |C|=3k\le 3\,\mathrm{OPT}, \]

so the algorithm is a \(3\)-approximation.

Alternatively, use LP rounding: write \(\min\sum_v x_v\) with \(x_u+x_v+x_w\ge 1\) for every edge and \(x_v\in\{0,1\}\), relax to \(0\le x_v\le 1\), solve to get an optimal fractional \(x^*\), and round \(x_v\) to \(1\) exactly when \(x^*_v\ge\tfrac13\). Each edge's three values sum to at least \(1\), so one is at least \(\tfrac13\) and is rounded up, keeping the edge covered; and each rounded-up variable had \(x^*_v\ge\tfrac13\), so the cost grows by at most a factor \(3\).

Intuition. The picked edges are disjoint, so the optimum pays at least one vertex each while we pay three, and a triple costs three where a pair cost two.
