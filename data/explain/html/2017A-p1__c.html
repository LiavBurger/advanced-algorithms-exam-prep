Claim True — \(E[2x-y]=2E[x]-E[y]\) always holds.

Strategy apply linearity of expectation, and note it needs no independence.

Key idea expectation is a weighted sum over outcomes, and sums split apart regardless of how the variables relate.

Why this move the statement is a linear combination of two random variables, which is the exact form linearity of expectation covers.

  1. State the rule. For any random variables \(x,y\) on the same sample space and constants \(a,b\), \(E[ax+by]=aE[x]+bE[y]\). With \(a=2,\ b=-1\) this is precisely \(E[2x-y]=2E[x]-E[y]\).
  2. Note independence is irrelevant. Linearity comes straight from the definition \(E[2x-y]=\sum_{\omega}\Pr[\omega]\bigl(2x(\omega)-y(\omega)\bigr)\), and a sum always splits term by term. Independence is only needed for products like \(E[xy]=E[x]E[y]\), never for a linear combination — so the identity holds even for dependent \(x,y\).
