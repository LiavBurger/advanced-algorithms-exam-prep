The simplex algorithm needs every inequality turned into an equality by adding a nonnegative slack/surplus variable, after which the "slack" variables are expressed as functions of the original ones (the dictionary/slack form used to read off a starting vertex).

  1. The first constraint \(2x_1-x_2\ge -5\) is a "\(\ge\)" inequality. Subtract a nonnegative surplus \(s_1\ge 0\) to make it an equality: \(2x_1-x_2-s_1=-5\).
  2. The second constraint \(3x_1-x_2+2x_3\le 9\) is a "\(\le\)" inequality. Add a nonnegative slack \(s_2\ge 0\): \(3x_1-x_2+2x_3+s_2=9\).
  3. Keeping all variables nonnegative, \(s_i,x_i\ge 0\), the standard (equality) form is \[\max\ 5x_1-7x_2+2x_3\ \text{ s.t. } 2x_1-x_2-s_1=-5,\ \ 3x_1-x_2+2x_3+s_2=9.\]
  4. Now solve each equation for its slack to get the dictionary form (slacks basic, original variables nonbasic). From line one, \(s_1=2x_1-x_2+5=5+2x_1-x_2\); from line two, \(s_2=9-3x_1+x_2-2x_3\).
\[\max\ 5x_1-7x_2+2x_3\quad\text{s.t.}\quad s_1=5+2x_1-x_2,\qquad s_2=9-3x_1+x_2-2x_3,\qquad s_i,x_i\ge 0.\]

This is exactly the form simplex runs on: the basic variables \(s_1,s_2\) are written in terms of the nonbasic \(x_1,x_2,x_3\), so setting the nonbasic variables to \(0\) reads off a candidate vertex.
