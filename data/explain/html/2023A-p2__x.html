Goal Write an integer program for Minimum Dominating Set and justify the variables and constraints.

Strategy Use one \(0/1\) variable per vertex for "selected", minimize the total selected, and add one coverage constraint per vertex.

Key idea "\(v\) is dominated" means \(v\) or one of its neighbors is chosen, which is a single \(\ge 1\) inequality.

Why this move Selection problems map naturally to \(0/1\) indicator variables, and each "must be covered" requirement becomes a linear lower-bound constraint.

  1. Variables. For each vertex \(v\in V\) let \(x_v\in\{0,1\}\), where \(x_v=1\) means \(v\) is in the dominating set. An assignment encodes the set \(D=\{v:x_v=1\}\).
  2. Objective. The size of \(D\) is \(\sum_{v\in V}x_v\), so minimize \(\sum_{v\in V}x_v\).
  3. Coverage constraints. Each vertex must be chosen or have a chosen neighbor: \[x_v+\sum_{u:(u,v)\in E}x_u\ge 1\qquad\text{for all }v\in V.\]
  4. Why it corresponds. A feasible \(0/1\) solution gives \(D=\{v:x_v=1\}\); each constraint guarantees \(v\in D\) or a neighbor is in \(D\), so \(D\) dominates. Conversely any dominating set is feasible, so minimizing the objective finds a minimum dominating set.
