Goal compute the diameter of a strongly connected digraph in time asymptotically below \(n^3\).

Strategy turn "reachable within \(k\) steps" into positivity of a matrix power, then binary-search the smallest \(k\) that connects all pairs, using fast matrix multiplication.

Key idea with \(B=A+I\), the entry \((B^k)_{i,j}>0\) exactly when \(d(i,j)\le k\), so the diameter is the smallest \(k\) making \(B^k\) all-positive.

Why this move distances become an all-or-nothing positivity test that is monotone in \(k\), which invites binary search, and matrix powers cost \(O(n^\omega)\) with \(\omega<3\) — beating the naive \(n^3\).

  1. Reachability via powers. \((A^k)_{i,j}\) counts length-\(k\) walks; adding \(I\) lets walks "wait", so with \(B=A+I\), \((B^k)_{i,j}>0\) iff there is a walk of length at most \(k\), i.e. \(d(i,j)\le k\).
  2. Bounded diameter. Strong connectivity makes every distance finite, and a shortest path repeats no vertex, so \(d(i,j)\le n-1\); the diameter is at most \(n\).
  3. Binary search. The diameter is the smallest \(m\) with all entries of \(B^m\) positive. Test \(m\): if \(B^m\) is all-positive the diameter is \(\le m\), else \(>m\); recurse on the right half of \([1,n]\). That is \(O(\log n)\) tests.
  4. Cost. Each power comes from repeated squaring in \(O(n^\omega\log n)\), and scanning for positivity is \(O(n^2)\); precomputing \(B^{2^i}\) for all \(i\le\log n\) once lets each search step reuse a stored power, giving \(O(n^\omega\log n)\) overall.

Since \(\omega<3\), \(O(n^\omega\log n)\) is comfortably below \(n^3\), so the diameter is found faster than the naive all-pairs approach.
