We bring the LP to the equality (dictionary) form simplex runs on by adding one nonnegative variable to each inequality.

The "\(\ge\)" constraint \(2x_1-x_2\ge -5\) loses a surplus \(s_1\ge 0\): \(2x_1-x_2-s_1=-5\).

The "\(\le\)" constraint \(3x_1-x_2+2x_3\le 9\) gains a slack \(s_2\ge 0\): \(3x_1-x_2+2x_3+s_2=9\).

So the equality form is, with all variables \(\ge 0\),

\[\max\ 5x_1-7x_2+2x_3 \quad\text{s.t.}\quad 2x_1-x_2-s_1=-5,\quad 3x_1-x_2+2x_3+s_2=9,\quad s_i,x_i\ge 0.\]

Solving each equation for its slack gives the dictionary form simplex starts from:

\[s_1=5+2x_1-x_2,\qquad s_2=9-3x_1+x_2-2x_3.\]

Intuition. Simplex only works on equalities, so each inequality trades its gap for one nonnegative slack variable.
