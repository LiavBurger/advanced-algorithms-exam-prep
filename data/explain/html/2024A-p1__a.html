Claim False: if a standard-form LP \((P)\) and its dual \((D)\) are both feasible, the optimum of \((P)\) cannot be strictly greater than the optimum of \((D)\).

Strategy Quote strong duality, which forces the two optimal values to be equal.

Key idea When both programs are feasible there is no duality gap, so a strict inequality is impossible.

Why this move Any T/F about the gap between a primal and its dual optimum is really a question about which duality theorem applies, and "both feasible" is exactly the trigger for strong duality.

  1. Set the convention. Take \((P)=\min c^\top x\) s.t. \(Ax=b,\ x\ge 0\), with dual \((D)=\max b^\top y\) s.t. \(A^\top y\le c\).
  2. Weak duality gives one direction. Always \(\mathrm{opt}(P)\ge \mathrm{opt}(D)\), so the only question is whether the inequality can be strict.
  3. Strong duality closes the gap. If both \((P)\) and \((D)\) are feasible, both optima are finite and equal: \(\mathrm{opt}(P)=\mathrm{opt}(D)\).
  4. Conclude. Equal values leave no room for "strictly greater," so the statement is false.

Once both sides are feasible, the primal and dual meet at the same value, so neither can beat the other.
