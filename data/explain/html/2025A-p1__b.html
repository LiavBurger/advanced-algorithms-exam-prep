The claim is true. We compute \(f(x)^n\) by repeated squaring, and each polynomial multiplication is done with FFT, which multiplies two degree-\(D\) polynomials in \(O(D\log D)\) arithmetic operations.

  1. Since \(n\) is a power of \(2\), write \(f^n = ((\cdots((f^2)^2)^2\cdots)^2)\): square \(\log n\) times. Starting from \(f = f^1\), squaring gives \(f^2\), then \(f^4\), then \(f^8\), up to \(f^n\). That is exactly \(\log n\) multiplications, not \(n\).
  2. Track the degree. The polynomial before the \(i\)-th squaring is \(f^{2^{i-1}}\), which has degree \(n\cdot 2^{i-1}\); we multiply it by itself. So the operands of the \(i\)-th squaring have degree on the order of \(n\cdot 2^{i}\). One FFT multiplication of degree-\(D\) polynomials costs \(O(D\log D)\), giving cost \(O\!\left(n\,2^{i}\log(n\,2^{i})\right)\) for step \(i\).
  3. Sum over all squarings: \(\displaystyle\sum_{i=1}^{\log n} O\!\left(n\,2^{i}\log(n\,2^{i})\right)\).
  4. Simplify the logarithm. Because \(2^{i}\le n\) throughout, \(\log(n\,2^{i}) = \log n + i \le 2\log n = O(\log n)\). Pull that factor out: \[\sum_{i=1}^{\log n} O\!\left(n\,2^{i}\log n\right) = O(n\log n)\cdot\sum_{i=1}^{\log n} 2^{i}.\]
  5. The geometric sum is \(\sum_{i=1}^{\log n} 2^{i} = 2^{\log n + 1} - 2 = O(n)\). Therefore the total is \(O(n\log n)\cdot O(n) = O(n^2\log n)\).

So the coefficients of \(f(x)^n\) are computed in \(O(n^2\log n)\) arithmetic operations, matching the stated bound. The whole cost is dominated by the final squaring, whose operands have degree \(\Theta(n^2)\).
