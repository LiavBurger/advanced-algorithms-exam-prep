We compute the diameter \(\max_{u\ne v}d(u,v)\) of a strongly connected digraph in time \(o(n^3)\) using fast matrix multiplication (exponent \(\omega<3\)) and binary search over the diameter value. Let \(A\) be the adjacency matrix.

  1. Reachability via powers. \((A^k)_{i,j}\) counts walks of length exactly \(k\) from \(i\) to \(j\). Set \(B=A+I\). Then \((B^k)_{i,j}>0\) iff there is a walk of length at most \(k\) from \(i\) to \(j\) — the added identity lets a walk "stay put", so reaching in \(\le k\) steps is captured. Equivalently \((B^k)_{i,j}>0\iff d(i,j)\le k\).
  2. Finite, bounded diameter. Since \(G\) is strongly connected every \(d(i,j)\) is finite, and a shortest path never repeats a vertex, so \(d(i,j)\le n-1
  3. Binary search. The diameter is the smallest \(m\) for which \((B^{m})_{i,j}>0\) for all \(i,j\). Test a candidate \(m\): if all entries of \(B^{m}\) are positive the diameter is \(\le m\), otherwise it is \(>m\); recurse on the appropriate half of \([1,n]\). This is \(O(\log n)\) tests.
  4. Cost. Each \(B^k\) (with \(k\le n\)) is computed by repeated squaring in \(O(n^{\omega}\log n)\), and scanning all entries for positivity is \(O(n^2)\), negligible. Total \(O(n^{\omega}\log^2 n)\).

Sharper: precompute \(B^{2^i}\) for all \(0\le i\le\log n\) once, in \(O(n^{\omega}\log n)\) total. Then each of the \(O(\log n)\) binary-search steps only multiplies by an already-stored power, so the whole search also runs in \(O(n^{\omega}\log n)\).

Since \(\omega<3\), \(O(n^{\omega}\log n)=o(n^3)\), as required.
