Suppose \(x^*\) satisfies \(Ax^*=c\) and \(x^*\ge 0\). We show it is feasible for both \((P)\) and its dual \((D)\) with equal objective value, which forces optimality.

Feasible for \((P)\): the primal needs \(Ax\ge c\) and \(x\ge 0\). Since \(Ax^*=c\) we have \(Ax^*\ge c\), and \(x^*\ge 0\) is given.

Feasible for \((D)\): recall \((D)\) is \(\max c^Tz\) s.t. \(Az\le c,\ z\ge 0\). Take \(z=x^*\); from \(Ax^*=c\) we get \(Ax^*\le c\), and \(x^*\ge 0\). So \(x^*\) is dual-feasible too.

Equal objective values: the primal value at \(x^*\) is \(c^Tx^*\), and the dual value at \(z=x^*\) is also \(c^Tx^*\). By weak duality every primal-feasible value is at least every dual-feasible value \((\min\ge\max)\). Here a feasible primal point and a feasible dual point attain the same value \(c^Tx^*\), so neither can be improved past it. Hence \(x^*\) attains the primal minimum and is optimal for \((P)\) (and by the same token \(z=x^*\) is optimal for \((D)\)).

Intuition. The equality \(Ax^*=c\) satisfies both \(\ge c\) and \(\le c\) at once, so \(x^*\) plays both roles and pins the two objectives together.
