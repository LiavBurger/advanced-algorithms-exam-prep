We must decide whether the subspace \(V=\operatorname{span}(B_1,\dots,B_k)\subseteq\mathbb{R}^{n\times n}\) contains an invertible matrix, i.e. whether some \(\sum_{i=1}^k x_i B_i\) is invertible. The idea is to test invertibility at a random point and use the Schwartz–Zippel lemma.

  1. Algorithm. Draw \(\alpha_1,\dots,\alpha_k\) independently and uniformly from \(\{1,2,\dots,10n\}\); answer "yes" iff \(\sum_{i=1}^k \alpha_i B_i\) is invertible (checked in polynomial time via a determinant / Gaussian elimination).
  2. Key polynomial. Let \(P(x_1,\dots,x_k):=\det\!\big(\sum_{i=1}^k x_i B_i\big)\). Each entry of \(\sum_i x_i B_i\) is a linear form in the \(x_i\), and a determinant of an \(n\times n\) matrix is a degree-\(n\) polynomial in its entries; hence \(P\) has total degree at most \(n\). A matrix is invertible iff its determinant is nonzero, so \(\sum_i x_i B_i\) is invertible exactly when \(P(x)\ne 0\).
  3. No false "yes". If \(V\) contains no invertible matrix then \(P\equiv 0\), the tested matrix is always singular, and we correctly answer "no".
  4. Rare false "no". If \(V\) does contain an invertible matrix, there is an assignment with \(P\ne 0\), so \(P\) is a nonzero polynomial of degree \(\le n\). By Schwartz–Zippel, for random \(\alpha\) drawn from a set \(S\) of size \(10n\), \[\Pr[P(\alpha)=0]\ \le\ \frac{\deg P}{|S|}\ \le\ \frac{n}{10n}\ =\ \frac{1}{10}.\]

So when an invertible matrix exists the algorithm says "yes" with probability at least \(9/10\), and it never errs otherwise: a one-sided-error, polynomial-time randomized decider. (The success probability can be boosted by independent repetitions.)
