Claim the running time is \(T(m,n)=\Theta(m+n)\).

Strategy unroll the recurrence one level at a time and sum the per-level costs, which shrink geometrically.

Key idea each level halves both dimensions, so its work is half of the level above; a geometric series in \(\tfrac12\) sums to at most twice the top level.

Why this move there is only a single chain of recursive calls (no branching), so the total is just the sum down that chain, and a halving series is the classic thing to add up.

  1. Cost per level. Write the per-call work \(\Theta(m+n)\) as \(c(m+n)\). The top level costs \(c(m+n)\); the recursive call is on a \(\lfloor m/2\rfloor\times\lfloor n/2\rfloor\) matrix, costing \(c\!\left(\tfrac m2+\tfrac n2\right)=\tfrac12 c(m+n)\); the next is \(\tfrac14 c(m+n)\), and so on.
  2. Sum the levels. \[T(m,n)=c(m+n)\left(1+\tfrac12+\tfrac14+\tfrac18+\cdots\right).\]
  3. Bound the geometric series. The bracket has ratio \(\tfrac12\), so it is at most \(2\), giving \(T(m,n)\le 2c(m+n)=O(m+n)\).
  4. Match with a lower bound. The very first level already does \(c(m+n)\) work, so \(T(m,n)=\Omega(m+n)\). Together this pins it to \(\Theta(m+n)\) — the top level sets the size and everything below adds only a constant factor.
