Claim True: for a bipartite graph \(G\), whether the number of perfect matchings is odd can be decided efficiently.

Strategy Compare the matching count (the permanent) with the determinant, and notice they agree once we work mod \(2\).

Key idea Mod \(2\) the sign \((-1)^{\mathrm{sgn}(\sigma)}\) disappears, so the determinant equals the matching count in parity.

Why this move The permanent is hard to compute, but it differs from the determinant only by per-term signs, and signs vanish mod \(2\), turning a hard count into an easy determinant.

  1. Count matchings. With \(A\) the \(n\times n\) biadjacency matrix (\(A_{i,j}=1\) if left \(i\) joins right \(j\)), each perfect matching is a permutation \(\sigma\) using only real edges, so their number is \(\displaystyle\sum_{\sigma\in S_n}\prod_{i=1}^{n} A_{i,\sigma(i)}\).
  2. Write the determinant. The determinant is the same sum with signs: \(\det(A)=\displaystyle\sum_{\sigma\in S_n}(-1)^{\mathrm{sgn}(\sigma)}\prod_{i=1}^{n} A_{i,\sigma(i)}\).
  3. Kill the signs mod 2. Since \(-1\equiv 1 \pmod 2\), the two sums match modulo \(2\). So \(\det(A)\bmod 2 = 1\) exactly when the number of perfect matchings is odd.
  4. Compute efficiently. The determinant is computable in polynomial time (e.g. Gaussian elimination), so output \(\det(A)\bmod 2\).

Parity forgives the signs, so the easy determinant hands us the odd-or-even answer the hard count would have given.
