We estimate the versatility \(R(G)\), the fraction of the \(3^n\) colorings that are legal, by sampling colorings and reporting the empirical legal-fraction. The only tools needed are a legality check and a Chernoff (Hoeffding) bound.

  1. The algorithm. Pick \(t\) independent, uniformly random colorings \(c_1,\dots,c_t : V\to\{1,2,3\}\) (choose each vertex's color uniformly). For each \(c_i\), check legality by scanning all edges and verifying \(c_i(u)\neq c_i(v)\); this takes linear time. Output \(A(G)=\frac1t\sum_{i=1}^{t} X_i\), the fraction that are legal.
  2. Expectation. Let \(X_i\) be an indicator random variable for the event that \(c_i\) is legal. A uniform coloring is legal with probability equal to (number of legal colorings)\(/3^n=R(G)\), so \(\mathbb E[X_i]=R(G)\). With \(X=\sum_i X_i\) we get \(\mathbb E[X]=tR(G)\), and the output \(X/t\) has mean \(R(G)\) — it is an unbiased estimator.
  3. Concentration. The \(X_i\) are independent and lie in \([0,1]\), so the additive Chernoff/Hoeffding bound gives \[ \Pr\!\Big[\,\big|A(G)-R(G)\big|\ge \tfrac1n\,\Big]=\Pr\!\Big[\big|\tfrac{X}{t}-\tfrac{\mathbb E[X]}{t}\big|\ge \tfrac1n\Big]\le e^{-O(t/n^2)}. \] The exponent \(t/n^2\) comes from the deviation \(\varepsilon=1/n\) entering the bound as \(\varepsilon^2 t\).
Take \(t=O(n^3)\): then \(t/n^2=O(n)\), so the failure probability is \(e^{-O(n)}\le 2^{-n}\). The algorithm samples \(O(n^3)\) colorings and checks each in linear time, so it runs in polynomial time and outputs an estimate within \(1/n\) of \(R(G)\) with probability at least \(1-2^{-n}\).
