Claim True: there is a polynomial-time algorithm that, given \(v_1,\dots,v_k\in\mathbb{R}^n\), finds an orthonormal basis of their span.

Strategy Run Gram-Schmidt to get an orthogonal basis, then normalize, and note every step is a cheap vector computation.

Key idea Subtracting from each vector its projections onto the earlier ones makes them mutually orthogonal.

Why this move "Orthonormal basis of a span" is the textbook job of Gram-Schmidt, and the only thing to check is that it runs in polynomial time.

  1. Reduce to independent vectors. If the \(v_i\) are dependent, greedily keep a maximal independent subset (each independence test is a rank computation, polynomial time); it spans the same subspace.
  2. Orthogonalize. Set \(\tilde b_1=v_1\) and \(\tilde b_i=v_i-\sum_{j=1}^{i-1}\mu_{i,j}\,\tilde b_j\) with \(\mu_{i,j}=\dfrac{\langle v_i,\tilde b_j\rangle}{\langle \tilde b_j,\tilde b_j\rangle}\).
  3. Check orthogonality. The coefficient \(\mu_{i,j}\) is chosen exactly so that \(\langle \tilde b_i,\tilde b_j\rangle=0\) for every \(j
  4. Normalize. Divide each \(\tilde b_i\) by its length to get unit vectors, giving an orthonormal basis.

The whole thing is just a bounded number of inner products and subtractions, so it finishes quickly and hands back the basis we wanted.
