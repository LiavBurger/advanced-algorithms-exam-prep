The statement is true: the Gram–Schmidt process constructs an orthonormal basis, and every operation it performs is a polynomial-time vector computation.

  1. First reduce to independent inputs. If \(v_1,\dots,v_k\) are linearly dependent, greedily keep a maximal linearly independent subset (add vectors one at a time, dropping any that lies in the span of those already kept — an independence test is a rank computation, done in polynomial time). The kept vectors span the same subspace, so assume \(v_1,\dots,v_k\) are independent.
  2. Build an orthogonal basis by removing, from each new vector, its components along the ones already produced.
