The algorithm: pick values \(\alpha_1,\dots,\alpha_k\) independently and uniformly at random from \(\{1,\dots,10n\}\), form the matrix \(\sum_{i=1}^k\alpha_i B_i\), and answer "yes" if and only if it is invertible (a determinant check, done in polynomial time).

Correctness rests on one observation: \(\sum_i x_i B_i\) is invertible if and only if \(P(x_1,\dots,x_k):=\det\!\big(\sum_i x_i B_i\big)\ne 0\). The entries of this matrix are linear in the \(x_i\), and a determinant of an \(n\times n\) matrix has degree \(n\), so \(P\) is a polynomial of degree at most \(n\). Deciding whether an invertible matrix lies in the span is therefore the same as deciding whether \(P\) is not the zero polynomial.

If the span contains no invertible matrix, then every \(\sum_i x_i B_i\) is singular, so \(P\equiv 0\), every random evaluation is \(0\), and the algorithm always correctly says "no".

If the span does contain an invertible matrix, then some assignment makes \(P\) nonzero, so \(P\) is a nonzero polynomial of degree at most \(n\). By the Schwartz-Zippel lemma, a random assignment from a set of size \(10n\) makes \(P=0\) with probability at most \(n/(10n)=1/10\). So the algorithm says "yes" with probability at least \(9/10\).

The algorithm never errs on "no" instances and errs with probability at most \(1/10\) on "yes" instances; repeating it a few times and answering "yes" if any run does makes the error shrink fast, below \(2^{-n}\).

Intuition. "Some combination is invertible" means the determinant polynomial is not identically zero, and a random point almost never lands on a nonzero polynomial's roots.
