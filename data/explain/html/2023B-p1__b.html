True. A single pivoting step runs in polynomial time in the input length.

As seen in class, one pivoting step consists of a bounded amount of work. It computes the reduced cost vector and selects a coordinate \(i\) to bring into the basis; it runs the ratio test to select a coordinate \(j\) to remove from the basis; and it updates the basis using some matrix inversions and matrix multiplications. Each of these is a standard linear-algebra operation on matrices and vectors whose dimensions are at most the number of variables and constraints, so each runs in time polynomial in the input length. A step performs only a constant number of such operations, so the whole pivoting step is polynomial. The statement is therefore true.

Intuition. One pivot is just a bit of linear algebra on the current basis; it is the possible number of pivots, not the cost of one, that is the real concern.
