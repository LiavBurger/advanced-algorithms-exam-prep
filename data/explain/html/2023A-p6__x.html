Goal In \(O(n\log n)\) time compute the sumset \(A+B\) and, for each \(c\), how many pairs \((a,b)\) sum to it.

Strategy Encode each set as an indicator polynomial, multiply the two, and read off the coefficients.

Key idea The coefficient of \(x^k\) in the product counts exactly the pairs \(i\in A,\ j\in B\) with \(i+j=k\).

Why this move "How many ways does each value arise as a sum" is a convolution, and convolution is polynomial multiplication — which FFT does in \(O(n\log n)\).

  1. Encode as polynomials. Let \(f_A(x)=\sum_{i\in A}x^i\) and \(f_B(x)=\sum_{j\in B}x^j\); the coefficient of \(x^i\) is \(1\) exactly when \(i\) is in the set.
  2. Multiply. In \(g=f_A\cdot f_B\), the coefficient of \(x^k\) is \(\sum_{i+j=k}a_i b_j\), where each \(a_i b_j\) is \(1\) precisely when \(i\in A\) and \(j\in B\).
  3. Interpret. So that coefficient counts the ways to write \(k=i+j\) with \(i\in A,\ j\in B\): \(k\in A+B\) exactly when it is positive, and the value is the number of representations.
  4. Cost. Both polynomials have degree at most \(n\), so FFT multiplies them in \(O(n\log n)\); building them and scanning the coefficients is \(O(n)\).
