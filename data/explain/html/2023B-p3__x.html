Both standard 2-approximations for vertex cover in ordinary graphs generalize to a 3-approximation on a 3-uniform hypergraph, where each edge is a triple \(\{u,v,w\}\) and a cover must hit every triple. We give the combinatorial one in full and note the LP version.

  1. Greedy algorithm. Start with \(C=\varnothing\). While \(E\neq\varnothing\): pick an arbitrary edge \(\{u,v,w\}\), add all three vertices \(u,v,w\) to \(C\), and erase every edge that contains at least one of \(u,v,w\). Each iteration deletes at least the picked edge, so the loop ends in polynomial time.
  2. Output size. Let \(k\) be the number of iterations. Each adds exactly \(3\) vertices, so \(|C|=3k\).
  3. Lower bound on \(\mathrm{OPT}\). The \(k\) edges that were picked are pairwise disjoint: when an edge is picked, every other edge sharing a vertex with it is erased, so a later-picked edge shares no vertex with earlier ones. Any valid cover must contain a vertex from each picked edge; since these \(k\) edges are vertex-disjoint, that forces \(k\) distinct vertices. Hence \(\mathrm{OPT}\ge k\).
  4. Ratio. Combining, \(|C|=3k\le 3\,\mathrm{OPT}\), a 3-approximation.
\[ |C|=3k\ \le\ 3\,\mathrm{OPT},\qquad\text{since the }k\text{ picked edges are disjoint and }\mathrm{OPT}\ge k . \]

LP-rounding alternative. The IP is \(\min\sum_{v}x_v\) subject to \(x_u+x_v+x_w\ge1\) for every edge \(\{u,v,w\}\) and \(x_v\in\{0,1\}\). Relax to \(0\le x_v\le1\), solve for an optimal fractional \(x^{*}\), and round \(x_v\) to \(1\) iff \(x^{*}_v\ge\tfrac13\). Feasibility: each edge's three fractional values sum to \(\ge1\), so at least one is \(\ge\tfrac13\) and gets rounded up, covering the edge. Cost: rounding only raises a variable when \(x^{*}_v\ge\tfrac13\), i.e. \(1\le 3x^{*}_v\), so the rounded cost is at most \(3\sum_v x^{*}_v\le 3\,\mathrm{OPT}\) — the class analysis with \(3\) in place of \(2\).
