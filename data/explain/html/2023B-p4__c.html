Claim With the subtour-elimination constraints added, every feasible IP solution is a Hamiltonian cycle.

Strategy Assume a feasible solution were more than one cycle, then show the new constraint on one cycle's vertex set is violated.

Key idea A cycle on a proper vertex subset \(Q\) uses \(|Q|\) internal edges, but the constraint caps that at \(|Q|-1\).

Why this move Part (b) showed the only failure mode is disjoint subtours, so the natural fix is a constraint that forbids any cycle from closing inside a proper subset.

  1. Start from the structure. The degree constraints already force any feasible solution to be a vertex-disjoint union of directed cycles covering all of \(V\).
  2. Suppose two or more cycles. Pick one cycle and let \(Q_0\) be its vertex set; since another cycle exists, \(Q_0\subsetneq V\) is a proper subset.
  3. Count its internal edges. That cycle uses exactly \(|Q_0|\) edges, all with both endpoints in \(Q_0\), so \(\sum_{u\in Q_0}\sum_{v\in Q_0}x_{u,v}=|Q_0|\).
  4. Hit the contradiction. The subtour constraint for \(Q_0\) demands this be \(\le|Q_0|-1\), but \(|Q_0|>|Q_0|-1\) — contradiction.

So no cycle can close on a proper subset; the only option left is one cycle through all vertices — a Hamiltonian cycle. With part (a), the correspondence is now exact.
