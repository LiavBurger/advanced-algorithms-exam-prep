Goal Write knapsack as a binary integer linear program.

Strategy Give each item a 0/1 "take it or not" variable, then express total value and total weight as linear sums of those variables.

Key idea A 0/1 vector \(x\) is exactly a subset of items, so maximizing \(\sum b_i x_i\) under \(\sum w_i x_i\le W\) is the problem itself.

Why this move "Choose a subset" is naturally a yes/no decision per item, which is precisely what binary variables encode.

  1. Variables. One variable \(x_i\) per item, forced to \(\{0,1\}\): \(x_i=1\) means item \(i\) is chosen, \(x_i=0\) means it is left out.
  2. Objective. The total value of the chosen set is \(\sum_i b_i x_i\), which we maximize.
  3. Capacity. The total weight \(\sum_i w_i x_i\) must not exceed \(W\), giving \(\sum_i w_i x_i \le W\).
  4. Assemble. \[\max \sum_i b_i x_i \quad\text{s.t.}\quad \sum_i w_i x_i \le W,\qquad x_i\in\{0,1\}\ \forall i.\] The integrality \(x_i\in\{0,1\}\) is what forbids taking a fraction of an item, keeping the model faithful.
