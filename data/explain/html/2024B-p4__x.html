Let \(A\) be the adjacency matrix of \(G\) and set \(B=A+I\). Then \((A^k)_{i,j}\) counts walks of length exactly \(k\) from \(i\) to \(j\); adding the identity lets a walk "wait", so \((B^k)_{i,j}>0\) exactly when there is a walk of length at most \(k\), that is, when \(d(i,j)\le k\). Since \(G\) is strongly connected every distance is finite, and a shortest path repeats no vertex, so the diameter is at most \(n\). Hence the diameter is the smallest \(m\) for which every entry of \(B^m\) is positive.

The algorithm:

  1. Precompute \(B^{2^i}\) for every \(0\le i\le\log n\) by repeated squaring, storing them.
  2. Binary-search the smallest \(m\in[1,n]\) with \(B^m\) all-positive: to test a value \(m\), multiply the stored powers to form \(B^m\) and check whether all entries are positive; if so the diameter is \(\le m\), otherwise it is \(>m\), and recurse on the appropriate half.
  3. Return that smallest \(m\), which is the diameter.

Runtime: precomputing the powers is \(O(\log n)\) matrix multiplications, each \(O(n^\omega)\) with fast matrix multiplication, so \(O(n^\omega\log n)\). The binary search has \(O(\log n)\) steps, each reusing stored powers, and each positivity check costs \(O(n^2)\), which is negligible. The total is \(O(n^\omega\log n)\), and since \(\omega<3\) this is asymptotically below \(n^3\).

Intuition. Powers of \(A+I\) detect "reachable within \(k\) steps", so binary-search the smallest \(k\) that connects every pair.
