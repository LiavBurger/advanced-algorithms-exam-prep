The vertex is \(x_1=3,\ x_2=0,\ x_3=0,\ s_1=11,\ s_2=0\).

The basis is \(\{x_1,s_1\}\), so the nonbasic variables \(x_2,x_3,s_2\) are all \(0\). Substituting into the two equality constraints, each collapses to a single unknown.

From \(3x_1-x_2+2x_3+s_2=9\) we get \(3x_1=9\), so \(x_1=3\).

From \(2x_1-x_2-s_1=-5\) with \(x_2=0\) we get \(6-s_1=-5\), so \(s_1=11\).

Both basic values are nonnegative, so this is a feasible vertex: \(x_1=3,\ x_2=0,\ x_3=0,\ s_1=11,\ s_2=0\).

Intuition. A basis just means setting the other variables to \(0\) and solving the equations for the ones that remain.
