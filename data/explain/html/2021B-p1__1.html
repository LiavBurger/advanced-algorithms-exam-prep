Goal formulate maximum semi-matching in the bipartite graph as a \(0/1\) integer program.

Strategy one binary variable per edge, maximize how many edges are chosen, and cap each vertex's degree — \(1\) on the \(V_1\) side, \(2\) on the \(V_2\) side.

Key idea a semi-matching is just a degree-capped edge set, and the only twist from ordinary matching is that \(V_2\)-vertices are allowed two edges instead of one.

Why this move every rule defining a semi-matching is a per-vertex degree bound, which is a linear inequality, so the model writes itself once you set an edge variable.

  1. Choose variables. For each edge \(e\in E\), \(x_e\in\{0,1\}\), with \(1\) meaning \(e\) is selected.
  2. Objective. Largest semi-matching means the most edges: \(\max\sum_{e\in E}x_e\).
  3. Cap the \(V_1\) side. Each \(v\in V_1\) may touch at most one chosen edge: \(\sum_{e\ni v}x_e\le 1\).
  4. Cap the \(V_2\) side. Each \(v\in V_2\) may touch at most two: \(\sum_{e\ni v}x_e\le 2\).

Any feasible \(0/1\) vector respects both caps, so it is a semi-matching, and its objective counts its edges — an optimal solution is a maximum semi-matching.
