Claim True: two \(4\times 4\) matrices can be multiplied with at most \(49\) multiplications.

Strategy View each \(4\times 4\) matrix as a \(2\times 2\) matrix of \(2\times 2\) blocks and run Strassen once at the block level.

Key idea Strassen multiplies \(2\times 2\) matrices with \(7\) products instead of \(8\); applying it recursively, the block products themselves each cost \(7\).

Why this move A \(4\times 4\) is naturally a \(2\times 2\) grid of \(2\times 2\) blocks, so one recursion level of Strassen is the obvious lever once you want to beat the naive \(64\).

  1. Block the matrices. Split each \(4\times 4\) matrix into four \(2\times 2\) blocks, so it looks like a \(2\times 2\) matrix whose entries are \(2\times 2\) matrices.
  2. Outer Strassen. Multiplying these two block matrices with Strassen needs only \(7\) block multiplications rather than \(8\) (the extra additions of blocks cost no scalar multiplications).
  3. Inner cost. Each block multiplication is a genuine \(2\times 2\) product, again done by Strassen with \(7\) scalar multiplications.
  4. Count. Total scalar multiplications are \(7\times 7=49\), which meets the bound \(49\) — one level of recursion is exactly what buys the savings over \(64\).
