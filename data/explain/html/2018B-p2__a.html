Approximation ratio \(1\) would mean the greedy always returns a maximum independent set. To refute this we exhibit, for every \(n\ge3\), a graph where the min-degree greedy is fooled into stopping after picking just two vertices, while a much larger independent set exists.

  1. The graph. On \(2n+1\) vertices \(x,\ v_1,\dots,v_n,\ w_1,\dots,w_n\) put edges: \(x v_i\) for all \(i\) (a star from \(x\) to the \(v\)'s); \(v_i w_j\) for all \(i,j\) (complete bipartite between \(v\)'s and \(w\)'s); and \(w_i w_j\) for all \(i\ne j\) (a clique on the \(w\)'s).

  3. What greedy does. It first takes \(x\) (min degree) and deletes \(x\) together with all its neighbors, the \(v_i\)'s. What remains is just the clique \(w_1,\dots,w_n\). It then takes some \(w_i\) and deletes it and all its neighbors — the entire rest of the clique — so the graph empties and the algorithm halts, returning \(\{x,w_i\}\) of size \(2\).
  4. The optimum is far bigger. There are no edges among the \(v_i\)'s, so \(\{v_1,\dots,v_n\}\) is an independent set of size \(n\); hence \(\mathrm{OPT}\ge n\).
The greedy returns an independent set of size \(2\) while \(\mathrm{OPT}\ge n\), so the ratio is at least \(n/2\), which grows without bound. The claim of approximation ratio \(1\) is false.
