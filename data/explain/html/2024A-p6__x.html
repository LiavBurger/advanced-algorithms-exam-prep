Claim there is a polynomial-time randomized algorithm deciding whether the span of \(B_1,\dots,B_k\) contains an invertible matrix.

Strategy plug random values into \(\sum_i x_i B_i\) and check invertibility; correctness rests on the determinant being a low-degree polynomial that is nonzero somewhere exactly when an invertible combination exists.

Key idea "some combination is invertible" is the same as "the polynomial \(P(x)=\det(\sum_i x_i B_i)\) is not the zero polynomial", so this is a polynomial-identity test.

Why this move invertibility is \(\det\ne 0\), a polynomial condition, and testing whether a polynomial is identically zero is exactly what a random evaluation plus Schwartz–Zippel handles.

  1. Algorithm. Draw \(\alpha_1,\dots,\alpha_k\) independently and uniformly from \(\{1,\dots,10n\}\); answer "yes" iff \(\sum_i \alpha_i B_i\) is invertible (a determinant check, polynomial time).
  2. The polynomial. Let \(P(x_1,\dots,x_k)=\det(\sum_i x_i B_i)\). Its entries are linear in the \(x_i\) and a determinant has degree \(n\), so \(\deg P\le n\), and \(\sum_i x_i B_i\) is invertible iff \(P(x)\ne 0\).
  3. No false "yes". If the span has no invertible matrix then \(P\equiv 0\), every tested matrix is singular, and we correctly say "no".
  4. Rare false "no". If an invertible matrix exists then \(P\) is a nonzero degree-\(\le n\) polynomial, and by Schwartz–Zippel over a set of size \(10n\), \(\Pr[P(\alpha)=0]\le n/(10n)=1/10\).

So the algorithm answers "yes" with probability at least \(9/10\) when an invertible matrix exists and never errs otherwise; repeating a few times drives the error way down.
