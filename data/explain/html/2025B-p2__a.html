We use one binary variable per set. For each subset \(S_i\) let \(x_i\in\{0,1\}\), where \(x_i=1\) means \(S_i\) is included in the cover. We minimize the total weight of chosen sets, and for each element \(j\) we require that at least one chosen set contains it, which is a linear "\(\ge 1\)" constraint over the sets holding \(j\). The program is

\[\min\ \sum_{i=1}^m c_i x_i\quad\text{s.t.}\quad \sum_{i:\,S_i\ni j}x_i\ge 1\ \ \text{for every }1\le j\le n,\qquad x_i\in\{0,1\}\ \ \text{for every }1\le i\le m.\]

Each element constraint guarantees that some chosen set covers element \(j\), so a feasible \(0/1\) vector is a valid cover and its objective is that cover's weight; an optimal solution is a minimum-weight set cover.

Intuition. Switch on sets at cheapest total weight so that every element is hit at least once.
