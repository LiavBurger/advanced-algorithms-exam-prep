Goal Describe a polynomial 3-approximation for minimum hitting set when every subset has size at most \(3\).

Strategy Sweep the subsets in any order; whenever one is not yet hit, throw all of its (at most \(3\)) elements into \(X\).

Key idea Grabbing an entire unhit subset both guarantees coverage and keeps the grabbed subsets disjoint, which is what caps the cost.

Why this move This mirrors the maximal-matching idea behind the vertex-cover 2-approximation: hit greedily, and the "size at most 3" bound turns factor 2 into factor 3.

  1. Algorithm. Start with \(X=\emptyset\). Process the subsets \(D\in C\) in arbitrary order. When you reach \(D\), if \(X\cap D=\emptyset\), add all of \(D\): \(X\leftarrow X\cup D\); otherwise do nothing.
  2. It hits everything. When we finish a subset \(D\) it satisfies \(X\cap D\ne\emptyset\) — either it was already hit, or we just added all of it.
  3. Cheap and disjoint. Each add inserts at most \(|D|\le 3\) elements, and we add \(D\) only when it currently shares nothing with \(X\), so the added subsets are pairwise disjoint — the fact that drives the ratio in part (b).

So a simple one-pass greedy runs in polynomial time and returns a valid hitting set.
