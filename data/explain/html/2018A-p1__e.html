Answer: Monte Carlo. The distinction is about which resource is fixed versus random:

  1. A Las Vegas algorithm always returns a correct answer; only its running time is random.
  2. A Monte Carlo algorithm has a fixed (bounded) running time but may return a wrong answer with some probability.

Karger's randomized min-cut contracts a uniformly random edge repeatedly until two vertices remain, outputting the surviving cut. It always halts within the same number of contractions (bounded runtime), but it can output a non-minimum cut: a single run finds a fixed minimum cut only with probability \(\ge \binom{n}{2}^{-1}=\tfrac{2}{n(n-1)}\), because it succeeds only if it never contracts an edge of that cut. Fixed time, possibly wrong answer — that is Monte Carlo. (Repeating \(O(n^2\log n)\) times drives the failure probability down, but each run is still Monte Carlo.)
