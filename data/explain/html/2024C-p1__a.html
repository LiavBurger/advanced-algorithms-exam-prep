Claim True: a standard-form polytope \(P=\{x:Ax=b,\ x\ge 0\}\subseteq\mathbb{R}^n\) has at most \(2^n\) vertices.

Strategy Use the class characterization of vertices by their support, then count how many supports are possible.

Key idea A vertex is pinned down by which coordinates are nonzero, and there are only \(2^n\) possible sets of nonzero coordinates.

Why this move "At most \(2^n\)" screams "one per subset of \(n\) things," so we look for a way to attach each vertex to a subset of the columns.

  1. Recall the vertex test. From class, \(y\in P\) is a vertex exactly when \(A_y\), the submatrix of columns where \(y_i>0\), has full column rank (those columns are linearly independent).
  2. A vertex is fixed by its support. If two vertices had the same support \(S\), both would solve \(A_S z_S=b\); independent columns make that solution unique, so the two vertices coincide. Hence "which coordinates are positive" determines the vertex.
  3. Count the supports. The support is a subset of the \(n\) columns, and an \(n\)-element set has \(2^n\) subsets.
  4. Conclude. Distinct vertices give distinct subsets, so there are at most \(2^n\) vertices.

Every vertex is tagged by "which coordinates are on," and there are only \(2^n\) such tags, so that many is the ceiling.
