Claim the LP optimum is at least \(n/2\).

Strategy exhibit one concrete feasible point whose value is \(n/2\); the optimum can only be higher.

Key idea setting every \(x_v=\tfrac12\) satisfies every edge constraint exactly, and the objective sums to \(n/2\).

Why this move to lower-bound a maximization LP you never need the true optimum — any feasible solution gives a valid bound, so reach for the simplest symmetric guess.

  1. Propose a point. Let \(x_v=\tfrac12\) for all \(v\in V\).
  2. Check feasibility. Each edge gives \(x_u+x_v=\tfrac12+\tfrac12=1\le 1\), and every \(x_v=\tfrac12\ge 0\). Feasible.
  3. Compute its value. \(\sum_{v\in V}x_v=n\cdot\tfrac12=\tfrac n2\).
  4. Conclude. The optimum is the best over all feasible points, so it is at least this one's value, i.e. \(\ge n/2\). (Worth noting: the true integer answer can be as small as \(1\), e.g. on a clique — so the relaxation can overshoot by a factor of about \(n/2\).)
