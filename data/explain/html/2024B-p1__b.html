Claim True: there is an efficient algorithm that, given a standard-form LP and a point \(y\), decides whether \(y\) is a vertex.

Strategy Check feasibility, then apply the class characterization of a vertex via linear independence of the support columns, which reduces to a rank computation.

Key idea Being a vertex is a purely algebraic condition — the columns of \(A\) on the positive coordinates of \(y\) must be linearly independent — and rank is polynomial to compute.

Why this move "Is this point a vertex" invites the standard-form vertex test from class, turning a geometric question into a rank check you can actually run.

  1. Feasibility check. For the polytope \(\{x:Ax=b,\ x\ge 0\}\), verify \(Ay=b\) and \(y\ge 0\); both are trivially polynomial, and if either fails \(y\) is not a vertex.
  2. Vertex characterization. Let \(A_y\) be the submatrix of \(A\) with the columns where \(y_i>0\). From class, a feasible \(y\) is a vertex iff \(A_y\) has full column rank (those columns are independent).
  3. Compute the rank. Run Gaussian elimination on \(A_y\) and compare its rank to the number of positive coordinates; equality means full column rank.
  4. Conclude. So \(y\) is a vertex exactly when it is feasible and \(A_y\) has full column rank — each step polynomial, so the test is efficient.
