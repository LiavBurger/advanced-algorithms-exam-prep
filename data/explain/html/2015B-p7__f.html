Reading the dual with \(y_{uv}\in\{0,1\}\): each \(y_{uv}\) decides whether edge \((u,v)\) is chosen, the objective \(\min\sum_{(u,v)\in E}y_{uv}\) minimizes the number of chosen edges, and the constraint \(\sum_{u:(u,v)\in E}y_{uv}\ge 1\) says every vertex \(v\) is touched by at least one chosen edge. A set of edges that touches every vertex is an edge cover, so this ILP is the minimum edge cover problem.

Intuition. "Every vertex is touched by some chosen edge" is exactly what an edge cover means.
