True. Let \(A\) be the \(n\times n\) biadjacency matrix of the bipartite graph \(G\), with \(A_{i,j}=1\) if left vertex \(i\) is joined to right vertex \(j\) and \(0\) otherwise. The number of perfect matchings of \(G\) is

\[\sum_{\sigma\in S_n}\prod_{i=1}^{n}A_{i,\sigma(i)},\]

since each permutation \(\sigma\) with all \(A_{i,\sigma(i)}=1\) is exactly a perfect matching. The determinant is the same sum but with signs:

\[\det(A)=\sum_{\sigma\in S_n}(-1)^{\operatorname{sgn}(\sigma)}\prod_{i=1}^{n}A_{i,\sigma(i)}.\]

Working modulo \(2\), we have \(-1\equiv 1\), so all the signs disappear and the two sums are equal mod \(2\). Therefore \(\det(A)\bmod 2\) equals the number of perfect matchings mod \(2\); it is \(1\) exactly when that number is odd. The determinant is computable in polynomial time (for example by Gaussian elimination), so the algorithm that computes \(\det(A)\) and outputs it mod \(2\) efficiently decides whether the number of perfect matchings in \(G\) is odd.

Intuition. Mod \(2\) the pesky signs in the determinant vanish, so the easy-to-compute determinant equals the hard-to-compute matching count.
