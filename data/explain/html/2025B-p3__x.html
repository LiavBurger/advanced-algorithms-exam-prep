Claim For a basic feasible solution \(x\) with basis \(B\), if the reduced cost vector satisfies \(\tilde c_N\ge 0\) then \(x\) is optimal.

Strategy Rewrite the objective using the equality constraints so its whole dependence on the nonbasic variables is captured by \(\tilde c_N\), then compare \(x\) to any feasible point.

Key idea After substituting out the basic variables, \(c^Tx=(\text{constant})+\tilde c_N^Tx_N\); with \(\tilde c_N\ge 0\) and \(x_N\ge 0\), you can only go up from the constant.

Why this move Reduced costs are literally the objective's coefficients on the free variables, so expressing the cost in terms of them turns "is this optimal" into a sign check.

  1. Solve for basic variables. From \(A_Bx_B+A_Nx_N=b\) and \(A_B\) invertible, \(x_B=A_B^{-1}b-A_B^{-1}A_Nx_N\), valid at every feasible point.
  2. Substitute into the objective. Then \[c^Tx=c_B^Tx_B+c_N^Tx_N=c_B^TA_B^{-1}b+\big(c_N^T-c_B^TA_B^{-1}A_N\big)x_N=c_B^TA_B^{-1}b+\tilde c_N^Tx_N,\] since the bracket is exactly the reduced cost \(\tilde c_N^T\).
  3. Value at \(x\). At the basic feasible solution the nonbasic variables vanish, \(x_N=0\), so \(c^Tx=c_B^TA_B^{-1}b\).
  4. Any feasible point is at least as costly. For any feasible \(y\ge 0\), the same identity gives \(c^Ty=c_B^TA_B^{-1}b+\tilde c_N^Ty_N\). Since \(\tilde c_N\ge 0\) and \(y_N\ge 0\), the extra term is \(\ge 0\), so \(c^Ty\ge c_B^TA_B^{-1}b=c^Tx\).
  5. Conclude. So \(x\) has the smallest objective value among all feasible points — nonnegative reduced costs mean there is nowhere cheaper to go, hence \(x\) is optimal.
