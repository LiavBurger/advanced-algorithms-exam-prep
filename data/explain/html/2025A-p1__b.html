True. We compute \(f(x)^n\) by repeated squaring, using an FFT-based multiplication for each squaring, and the total cost is \(O(n^2\log n)\).

Since \(n\) is a power of \(2\), we reach \(f^n\) through the chain \(f^2, f^4, f^8,\dots,f^n\), squaring the current polynomial each time. This is only \(\log n\) multiplications.

In the \(i\)-th squaring we multiply a polynomial of degree about \(n\cdot 2^i\) by itself. Multiplying two polynomials of degree \(D\) with FFT costs \(O(D\log D)\), so this step costs \(O(n\,2^i\log(n\,2^i))\).

Summing over the \(\log n\) steps, and using \(2^i\le n\) so that \(\log(n\,2^i)=O(\log n)\), \[\sum_{i=1}^{\log n} O\!\left(n\,2^i\log(n\,2^i)\right)=\sum_{i=1}^{\log n} O(n\,2^i\log n)=O(n\log n)\sum_{i=1}^{\log n}2^i=O(n^2\log n).\] The last sum is a geometric series bounded by \(2n\). So the coefficients of \(f^n\) are computed in \(O(n^2\log n)\) operations, and the statement is true.

Intuition. Squaring reaches the \(n\)-th power in only \(\log n\) multiplications, and the final, largest one already costs \(O(n^2\log n)\).
