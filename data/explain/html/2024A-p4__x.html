We use one \(0/1\) variable per Boolean variable and one per clause; the clause variable is allowed to be \(1\) only when at least one literal of the clause is satisfied, and we maximize the total weight of satisfied clauses.

Variables: for each variable \(x_i\) of the formula \(\varphi\) take \(y_i\in\{0,1\}\), where \(y_i=1\) means \(x_i\) is true. For each clause \(C_j\) take \(z_j\in\{0,1\}\), intended to be \(1\) exactly when \(C_j\) is satisfied. Let \(C_j^{+}\) be the set of variables appearing in positive literals of \(C_j\), and \(C_j^{-}\) those in negative literals.

The integer linear program is \[\max\ \sum_{j=1}^{m} w_j z_j \quad\text{s.t.}\quad z_j\le \sum_{i\in C_j^{+}} y_i+\sum_{i\in C_j^{-}}(1-y_i)\ \ (1\le j\le m),\qquad y_i,z_j\in\{0,1\}.\]

The right-hand side counts the satisfied literals of \(C_j\): a positive literal on \(x_i\) is satisfied exactly when \(y_i=1\), contributing \(y_i\); a negative literal on \(x_i\) is satisfied exactly when \(y_i=0\), contributing \(1-y_i\). So the constraint says: if no literal is satisfied the sum is \(0\) and forces \(z_j=0\); if some literal is satisfied the sum is at least \(1\) and permits \(z_j=1\). Since \(w_j\ge 0\) in a maximization, an optimal solution sets \(z_j=1\) whenever it is allowed, so \(z_j=1\) if and only if \(C_j\) is satisfied.

Therefore every feasible solution corresponds to a real solution of the problem: the \(y_i\) form a truth assignment, and the objective \(\sum_j w_j z_j\) equals the total weight of the clauses that this assignment satisfies. Maximizing it solves weighted Max-SAT.

Intuition. Encode truth as \(0/1\), let each clause "count" its satisfied literals, and let \(z_j\) turn on only when that count is positive.
