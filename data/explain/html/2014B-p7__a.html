Bin packing input: items \(1,\dots,n\) with weights \(w_i\); pack all items into as few bins as possible, each bin holding total weight \(\le 1\). We model it as an ILP.

  1. Bound the number of bins. There is always a valid packing using at most \(n\) bins — put each item in its own bin (each holds one item of weight \(\le 1\), assuming weights are \(\le 1\)). So we may index candidate bins \(j=1,\dots,n\) and never need more.
  2. Variables. Two families of 0/1 variables. \(x_{ij}=1\) iff item \(i\) is placed in bin \(j\); \(y_j=1\) iff bin \(j\) is "open" (used at all). Both are forced into \(\{0,1\}\).
  3. Objective. Minimize the number of open bins, \(\min\sum_{j=1}^n y_j\).
  4. Each item packed. Every item must land in at least one bin: \(\sum_{j=1}^n x_{ij}\ge 1\) for all \(i\). (At the optimum this is exactly one bin.)
  5. Only open bins receive items. If item \(i\) is in bin \(j\) then bin \(j\) must be open: \(y_j \ge x_{ij}\) for all \(i,j\). This links the \(x\) and \(y\) variables so the objective actually counts every bin we use.
  6. Capacity. Each bin's total weight is at most \(1\): \(\sum_{i=1}^n x_{ij} w_i \le 1\) for all \(j\).

Full ILP: \[\min \sum_{j=1}^n y_j \ \text{ s.t. }\ \sum_{j=1}^n x_{ij}\ge 1\,(\forall i),\quad y_j\ge x_{ij}\,(\forall i,j),\quad \sum_{i=1}^n x_{ij}w_i\le 1\,(\forall j),\quad x_{ij},y_j\in\{0,1\}.\]
