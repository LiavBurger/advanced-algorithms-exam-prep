Goal give a randomized coloring with \(\mathrm{Disc}_h(\mathcal F)\le C\sqrt{n\log m}\) with high probability.

Strategy color every element red/blue independently at random; bound one set's discrepancy with Chernoff, then union-bound over all \(m\) sets.

Key idea a random \(\pm1\) sum concentrates tightly around \(0\), so a single set's discrepancy exceeds \(C\sqrt{n\log m}\) only with tiny probability.

Why this move discrepancy is exactly the absolute value of a sum of independent \(\pm1\) terms, which is the textbook setup for a Chernoff/Hoeffding tail bound.

  1. Encode colors as \(\pm1\). Set \(X_i=+1\) for red, \(-1\) for blue, chosen independently and uniformly. Then \(E[X_i]=0\) and a set's discrepancy is \(\mathrm{Disc}_h(S)=\bigl|\#\text{red}-\#\text{blue}\bigr|=\bigl|\sum_{i\in S}X_i\bigr|\).
  2. Fix one set. Fix \(S\) with \(s=|S|\le n\). Since \(C\sqrt{n\log m}\ge C\sqrt{s\log m}\), exceeding the larger threshold implies exceeding the smaller: \(\Pr[\mathrm{Disc}_h(S)\ge C\sqrt{n\log m}]\le \Pr[|\sum_{i\in S}X_i|\ge C\sqrt{s\log m}]\).
  3. Chernoff on the \(\pm1\) sum. Using \(\Pr[|\sum X_i|\ge t]\le 2e^{-t^2/(2s)}\) with \(t=C\sqrt{s\log m}\), the exponent is \(\tfrac{C^2 s\log m}{2s}=\tfrac{C^2}{2}\log m\). Picking \(C\) large enough drives this below \(\tfrac1{10m^2}\) — the error shrinks fast as \(C\) grows.
  4. Union bound. Over all \(m\) sets, \(\Pr[\exists S:\ \mathrm{Disc}_h(S)\ge C\sqrt{n\log m}]\le m\cdot\tfrac1{10m^2}=\tfrac1{10m}\). So with probability at least \(1-\tfrac1{10m}\) every set is below \(C\sqrt{n\log m}\), and one simple random coloring does the job.
