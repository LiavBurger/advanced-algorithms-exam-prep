The relaxation LP1 is obtained by dropping integrality, replacing \(x_v\in\{0,1\}\) with \(x_v\ge 0\): \[ \min \sum_{v\in V} x_v \quad\text{s.t.}\quad x_u+x_v\ge 1 \ \ \forall uv\in E,\qquad x_v\ge 0 \ \ \forall v\in V. \]

The constraint \(x_v\le 1\) is redundant here. The objective is a minimization and every constraint on \(x_v\) is a lower bound, so no optimal solution ever needs a coordinate above \(1\): if some optimal solution had \(x_v>1\), lowering it to \(1\) still satisfies every edge constraint (an endpoint equal to \(1\) already makes \(x_u+x_v\ge 1\)) and strictly decreases the objective. Hence we may omit \(x_v\le 1\) without changing the optimum.

Intuition. Relaxing means allowing fractional vertices in \([0,1]\); since we are minimizing, the algorithm never wants a value above \(1\), so the upper bound is free.
