We use one binary variable per edge and cap the degree at each vertex. For each edge \(uv\in E\) let \(x_{uv}\in\{0,1\}\), where \(x_{uv}=1\) means the edge is in the matching. We want the heaviest matching, and a matching is a set of edges using each vertex at most once, which is a linear inequality at every vertex. The program is

\[\max\ \sum_{uv\in E}x_{uv}\,w(uv)\quad\text{s.t.}\quad \sum_{uv\ni v}x_{uv}\le 1\ \ \forall v\in V,\qquad x_{uv}\in\{0,1\}\ \ \forall uv\in E.\]

Any feasible \(0/1\) vector touches each vertex at most once, so it is exactly a matching, and its objective value is that matching's total weight; an optimal solution is a maximum-weight matching.

Intuition. Put an on/off switch on each edge and forbid any vertex from being used twice.
