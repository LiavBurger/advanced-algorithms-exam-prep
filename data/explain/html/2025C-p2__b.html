Claim the sets whose dual constraint is tight, \(\mathcal F=\{S_i:\sum_{j\in S_i}y^{*}_j=c_i\}\), form a set cover.

Strategy suppose some element is uncovered and show you could then improve the dual, contradicting optimality of \(y^{*}\).

Key idea an uncovered element sits only in slack (non-tight) constraints, so its dual variable has room to grow — and growing it raises the objective.

Why this move "an optimal solution can't be improved" is the lever, so we look for slack that would let us push a variable up.

  1. Assume not a cover. Suppose element \(j_0\) is in no set of \(\mathcal F\). Then every set \(S_i\) containing \(j_0\) is outside \(\mathcal F\), so its constraint is slack: \(\sum_{j\in S_i}y^{*}_j
  2. Its variable has room. The dual variable \(y_{j_0}\) appears only in constraints of sets that contain \(j_0\), and all of those are strict inequalities. Constraints of sets avoiding \(j_0\) don't involve \(y_{j_0}\) at all.
  3. Push it up. Pick \(\varepsilon>0\) smaller than every one of those positive slacks and set \(y_{j_0}\gets y^{*}_{j_0}+\varepsilon\). All constraints \((2)\) still hold and \(y\ge0\), so the new point is feasible.
  4. Contradiction. The objective \(\sum_j y_j\) went up by \(\varepsilon>0\), beating \(y^{*}\) — impossible for an optimum. So no element is uncovered, and \(\mathcal F\) is a set cover.
