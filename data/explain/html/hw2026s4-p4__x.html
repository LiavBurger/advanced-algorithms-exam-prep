Max-2-LIN has variables \(x_1,\dots,x_n\in\{-1,1\}\) and two constraint types: \(x_ix_j=-1\) (asking \(x_i\neq x_j\)) and \(x_ix_j=+1\) (asking \(x_i=x_j\)); we maximise the number satisfied. Let \(E_-\) be the pairs carrying a \(-1\) constraint and \(E_+\) the pairs carrying a \(+1\) constraint. We reuse the Goemans–Williamson SDP method from class, tweaking the analysis to cover the \(E_+\) terms.

  1. Integer program. For \((i,j)\in E_-\) the term \(\frac{1-x_ix_j}{2}\) equals \(1\) exactly when \(x_ix_j=-1\), and for \((i,j)\in E_+\) the term \(\frac{1+x_ix_j}{2}\) equals \(1\) exactly when \(x_ix_j=+1\); each is the indicator that its constraint is satisfied. So we maximise \(\sum_{(i,j)\in E_-}\frac{1-x_ix_j}{2}+\sum_{(i,j)\in E_+}\frac{1+x_ix_j}{2}\) over \(x\in\{-1,1\}^n\). The \(E_-\) part alone is the Max-Cut integer program; \(E_+\) adds the agreement terms.
  2. SDP relaxation. Relax each \(x_i\) to a unit vector \(v_i\in\mathbb R^n\) and each product \(x_ix_j\) to the inner product \(\langle v_i,v_j\rangle\). This is a relaxation: any \(\pm1\) assignment is recovered by placing every \(v_i\) at \(\pm\) a fixed unit vector, so \(\mathrm{SDPOPT}\ge\mathrm{OPT}\).
  3. Random-hyperplane rounding. Draw a uniformly random hyperplane through the origin with normal \(r\) and set \(x_i=\operatorname{sign}\langle r,v_i\rangle\). Writing \(\theta_{ij}=\angle(v_i,v_j)\), the random-hyperplane fact from class gives \(\Pr[x_i\neq x_j]=\theta_{ij}/\pi\) and \(\Pr[x_i=x_j]=1-\theta_{ij}/\pi\).
  4. Expected value vs. SDP value. By linearity of expectation, \(\mathbb E[\mathrm{ALG}]=\sum_{E_-}\frac{\theta_{ij}}{\pi}+\sum_{E_+}\bigl(1-\frac{\theta_{ij}}{\pi}\bigr)\), while, using \(\langle v_i,v_j\rangle=\cos\theta_{ij}\), \(\mathrm{SDPOPT}=\sum_{E_-}\frac{1-\cos\theta_{ij}}{2}+\sum_{E_+}\frac{1+\cos\theta_{ij}}{2}\). We compare the two sums term by term.
  5. The two per-term inequalities. For \((i,j)\in E_-\) this is the Max-Cut situation, where class established \[\frac{\theta}{\pi}\ \ge\ \alpha\cdot\frac{1-\cos\theta}{2}\quad\text{for all }\theta\in[0,\pi],\qquad \alpha=\frac{2}{\pi}\min_{0<\theta\le\pi}\frac{\theta}{1-\cos\theta}=0.878\ldots\] For \((i,j)\in E_+\) we need \(1-\frac{\theta}{\pi}\ge\alpha\cdot\frac{1+\cos\theta}{2}\). Substitute \(\theta'=\pi-\theta\), which again ranges over \([0,\pi]\); then \(1-\frac{\theta}{\pi}=\frac{\pi-\theta}{\pi}=\frac{\theta'}{\pi}\) and \(\frac{1+\cos\theta}{2}=\frac{1+\cos(\pi-\theta')}{2}=\frac{1-\cos\theta'}{2}\). The inequality becomes \(\frac{\theta'}{\pi}\ge\alpha\cdot\frac{1-\cos\theta'}{2}\) — exactly the Max-Cut inequality at \(\theta'\), so it holds with the same constant \(\alpha\).
  6. Conclusion. Every term satisfies (rounded probability) \(\ge\alpha\cdot\)(SDP contribution). Summing over all constraints, \(\mathbb E[\mathrm{ALG}]\ge\alpha\cdot\mathrm{SDPOPT}\ge\alpha\cdot\mathrm{OPT}\) with \(\alpha=0.878\ldots\) Thus the same SDP relaxation with random-hyperplane rounding is a \(0.878\)-approximation for Max-2-LIN.
