Monte Carlo. Karger's randomized min-cut algorithm always runs in a fixed (polynomial) number of steps, but it may return a cut that is not minimum — it outputs a minimum cut only with some probability. An algorithm whose running time is fixed but whose answer can be wrong is Monte Carlo. (A Las Vegas algorithm is the other way around: always correct, but with random running time.)

Intuition. It can be wrong but is never slow, and that trade-off is exactly what "Monte Carlo" means.
