The algorithm is the simplest possible: color each element \(i\in\{1,\dots,n\}\) red or blue independently and uniformly at random. We show this achieves \(\mathrm{Disc}_h(\mathcal F)\le C\sqrt{n\log m}\) with high probability, for a suitably large constant \(C\).

  1. Encode a color as \(\pm1\). For each \(i\) let \(X_i=+1\) if \(i\) is red and \(X_i=-1\) if blue. Then \(E[X_i]=0\), the \(X_i\) are independent, and for a set \(S\) the discrepancy is \(\mathrm{Disc}_h(S)=\bigl|\#\text{red}-\#\text{blue}\bigr|=\bigl|\sum_{i\in S}X_i\bigr|\).
  2. Fix one set and bound its discrepancy. Fix \(S\in\mathcal F\) and let \(s=|S|\le n\). Because the target threshold \(C\sqrt{n\log m}\ge C\sqrt{s\log m}\), the event of exceeding the larger threshold is contained in that of exceeding the smaller one: \[ \Pr\!\left[\mathrm{Disc}_h(S)\ge C\sqrt{n\log m}\right]\le\Pr\!\left[\Bigl|\textstyle\sum_{i\in S}X_i\Bigr|\ge C\sqrt{s\log m}\right].\]
  3. Apply Chernoff/Hoeffding for a \(\pm1\) sum of \(s\) terms: \(\Pr[|\sum_{i\in S}X_i|\ge t]\le 2e^{-t^2/(2s)}\). With \(t=C\sqrt{s\log m}\) the exponent is \(t^2/(2s)=\tfrac{C^2 s\log m}{2s}=\tfrac{C^2}{2}\log m\), i.e. the bound is \(e^{-\Omega(C^2\log m)}\). Choosing \(C\) large enough makes this at most \(\tfrac1{10m^2}\).
  4. Union bound over all \(m\) sets. \[ \Pr\!\left[\exists S\in\mathcal F:\ \mathrm{Disc}_h(S)\ge C\sqrt{n\log m}\right]\le m\cdot\frac{1}{10m^2}=\frac{1}{10m}.\]

So with probability at least \(1-\tfrac1{10m}\) every set has discrepancy below \(C\sqrt{n\log m}\), giving \(\mathrm{Disc}_h(\mathcal F)\le C\sqrt{n\log m}\) with high probability.
