When do I reach for this?

You must prove that some object with a desired property exists, but you have no idea how to construct it. The trick: build a random object, compute the expected quality, and note that something must be at least as good as the average.

  • "Prove there exists an assignment satisfying \(\ge\) (fraction) of the clauses" → random assignment + linearity.
  • "Show a coloring / partition / vector with property P exists" → make it random, bound \(\mathbb{E}[\text{quality}]\), conclude.
  • Want it with high probability, not just existence → add Chernoff + union bound.

Core idea

Theorem Averaging (first moment). A random variable always attains a value at least its mean and one at most its mean: \[ \Pr\big[X\ge \mathbb{E}[X]\big]>0 \quad\text{and}\quad \Pr\big[X\le \mathbb{E}[X]\big]>0. \] So if \(\mathbb{E}[X]=\mu\), there exists an outcome with \(X\ge \mu\) (and one with \(X\le\mu\)). No construction needed.
EXPECTED QUALITY VIA LINEARITY
Write the quality as a sum of indicators (one per clause / edge / constraint): \[ \mathbb{E}[\#\text{satisfied}]=\sum_j \Pr[\text{clause }j\text{ satisfied}]. \] compute the average score of a random object piece by piece
Definition De-randomization (method of conditional expectations). Once \(\mathbb{E}[X]\ge\mu\), fix the variables one at a time, each time keeping the conditional expectation \(\ge\mu\): since \(\mathbb{E}[X]=p\,\mathbb{E}[X\mid x_1{=}1]+(1-p)\,\mathbb{E}[X\mid x_1{=}0]\), at least one branch is \(\ge\mathbb{E}[X]\). This turns the existence proof into a deterministic algorithm.

Worked example — the thinking

2017B P4. Prove every 3-SAT formula with \(m\) clauses has an assignment satisfying at least \(m/2\) clauses.

  1. Randomize. Set each variable to \(0/1\) independently with probability \(1/2\). Now the number satisfied, \(X\), is a random variable.
  2. Score one clause. A clause of \(k\) literals fails only if all its literals are false: \(\Pr[\text{clause satisfied}]=1-2^{-k}\ge 1-2^{-1}=\tfrac12\) (here \(k\ge1\); for 3-literal clauses it is \(7/8\)).
  3. Sum by linearity. \(\mathbb{E}[X]=\sum_{j=1}^m \Pr[\text{clause }j\text{ sat}]\ge m/2\). Dependence between clauses is irrelevant — linearity does not care.
  4. Invoke averaging. Some assignment satisfies \(X\ge \mathbb{E}[X]\ge m/2\). Done — and conditional expectations make it constructive.
Traps. Averaging gives existence of one good outcome, not that a random object is good with high probability — for "w.h.p." you need Chernoff + union bound. \(\mathbb{E}[X]\ge\mu\) only yields an object with \(X\ge\mu\); to get \(X\le\mu\) use the other side. Beware the true/false framing: "at most \(7m/8\) clauses" is false because the average already guarantees \(7m/8\), so a better-than-average assignment beats it.

Checklist

  1. Define a natural random object (uniform assignment / coloring / vector).
  2. Write the quality \(X\) as a sum of indicators.
  3. Compute each \(\Pr[\text{piece good}]\) and add by linearity to get \(\mathbb{E}[X]\).
  4. Conclude an outcome with \(X\ge\mathbb{E}[X]\) (or \(\le\)) exists.
  5. Optional: de-randomize by conditional expectations, or upgrade to w.h.p. with Chernoff.
