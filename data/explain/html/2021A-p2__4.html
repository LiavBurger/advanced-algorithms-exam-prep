The claim is that when all caps are \(c_j=1\) and all courses have the same size \(|U_j|=u\), solving the LP relaxation of the primal optimally and then rounding "\(x_i\ge \tfrac1u\mapsto 1\), else \(0\)" always gives a feasible integral solution. This is false; the fix is to exhibit an instance where the optimal fractional solution sits exactly at the threshold \(1/u\), so rounding pushes too many variables up to \(1\) and breaks a cap.

  1. Simplest counterexample. Take \(A=\{a_1,a_2\}\), \(m=1\), \(U_1=A\), so \(u=2\) and \(c_1=1\). The only constraint is \(x_1+x_2\le 1\). The fractional optimum sets \(x_1=x_2=\tfrac12\), with value \(1\); it is optimal because the single constraint caps the sum at \(1\), so no feasible point beats value \(1\).
  2. Apply the rounding: the threshold is \(1/u=1/2\), and both variables equal \(\tfrac12\ge\tfrac12\), so both round to \(1\). Now \(x_1+x_2=2>1\), violating the cap — the rounded solution is infeasible.
  3. A second, "tighter" counterexample. Take \(A=\{a_1,a_2,a_3,a_4\}\), \(m=4\), \(U_j=A\setminus\{a_j\}\), so \(u=3\) and every \(c_j=1\). Setting \(x_i=\tfrac13\) for all \(i\) is feasible (each constraint sums \(3\cdot\tfrac13=1\le 1\)) with value \(4/3\); it is optimal because any higher-value solution would force three variables to sum to more than \(1\), which some constraint forbids.
  4. Rounding with threshold \(1/u=1/3\): every \(x_i=\tfrac13\ge\tfrac13\) rounds to \(1\). Then each constraint \(\sum_{a_i\in U_j}x_i\) equals \(3>1\), again infeasible.
False: in both instances the optimal fractional solution puts every variable exactly at the rounding threshold \(1/u\), so all of them round up to \(1\) and every cap-\(1\) constraint is violated.
