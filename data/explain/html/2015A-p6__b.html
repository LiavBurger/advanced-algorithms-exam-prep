Goal If the last item to open a new bin had weight \(1/k\), lower-bound the load of every bin except that last one by \(1-\tfrac1k\).

Strategy Use why a new bin gets opened at all: the item didn't fit anywhere else.

Key idea A \(1/k\) item is opened into a new bin only when every existing bin has less than \(1/k\) free — meaning each was already more than \(1-\tfrac1k\) full.

Why this move The algorithm opens a bin only as a last resort, so the opening event itself certifies that all other bins are nearly full.

  1. Read the opening event. When this \(1/k\) item was placed in a new bin, it fit in no existing bin, so every existing bin had free space below \(1/k\).
  2. Turn free space into load. Free space under \(1/k\) means each such bin was filled to more than \(1-\tfrac1k\).
  3. Loads never drop. This was the last opening event, so later items only add to existing bins; no bin's load decreases afterward.

So in the final packing, every bin other than the last-opened holds items of total weight at least \(1-\tfrac1k\).
