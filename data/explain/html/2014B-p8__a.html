Claim The integer program IP1 is the minimum vertex cover problem.

Strategy Read off what each piece of the program — variables, constraints, objective — means on the graph.

Key idea A \(0/1\) vector \(x\) picks a vertex set \(S=\{v:x_v=1\}\), and the edge constraint \(x_u+x_v\ge1\) says every edge has an endpoint in \(S\) — a vertex cover.

Why this move Naming an ILP is done by translating its ingredients into graph language, so we interpret each line directly.

  1. Variables = chosen set. Each \(x_v\in\{0,1\}\) marks whether \(v\) is selected, so a solution is a subset \(S\subseteq V\).
  2. Constraints = covering. For edge \(uv\), \(x_u+x_v\ge1\) holds iff at least one endpoint is chosen — exactly "\(S\) covers every edge."
  3. Objective = smallest set. Minimizing \(\sum_v x_v\) minimizes \(|S|\).

Covering every edge with as few vertices as possible is the minimum vertex cover of \(G\).
