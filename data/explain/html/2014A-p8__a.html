Algorithm: set each variable to \(0\) or \(1\) independently and uniformly at random. We show its expected number of satisfied clauses is at least \(\tfrac78\mathrm{OPT}\).

Fix a clause. It has \(3\) literals from distinct variables (no two literals in a clause share a variable), so their truth values are independent, each false with probability \(1/2\). The clause is unsatisfied only when all three literals are false, which happens with probability \((1/2)^3=1/8\); hence it is satisfied with probability \(1-1/8=7/8\).

For clause \(i\), let \(X_i\) be an indicator random variable for the event that clause \(i\) is satisfied, so \(\mathbb{E}[X_i]=7/8\), and let \(X=\sum_{i=1}^m X_i\) count the satisfied clauses. Even though clauses may share variables, by linearity of expectation \[\mathbb{E}[X]=\sum_{i=1}^m \mathbb{E}[X_i]=\frac{7m}{8}.\] Since no assignment can satisfy more than all \(m\) clauses, \(\mathrm{OPT}\le m\), and therefore \(\mathbb{E}[X]=\tfrac{7}{8}m\ge\tfrac{7}{8}\mathrm{OPT}\). So the algorithm is a \(7/8\)-approximation in expectation.

Intuition. A random clause fails only if all three coin flips go wrong (\(1/8\)), so on average \(7/8\) of the clauses are satisfied, and expectations add up even when clauses overlap.
