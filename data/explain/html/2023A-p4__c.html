Claim Adding integrality \(y_v\in\{0,1\}\) to the dual LP from part (b) gives the minimum vertex cover problem.

Strategy Read the integral variables as "pick this vertex," then interpret the edge constraint and the objective.

Key idea The constraint \(y_u+y_v\ge 1\) on \(\{0,1\}\) values says every edge has at least one chosen endpoint, which is exactly a vertex cover.

Why this move Once variables are forced to \(0/1\), an LP becomes a combinatorial selection problem, so we just translate each piece back into graph language.

  1. Read the variables. With \(y_v\in\{0,1\}\), let \(S=\{v:y_v=1\}\) be the chosen vertices.
  2. Read the constraint. For edge \((u,v)\), \(y_u+y_v\ge 1\) forces at least one endpoint into \(S\), so \(S\) touches every edge, i.e. \(S\) is a vertex cover.
  3. Read the objective. \(\min\sum_v y_v=\min|S|\), the smallest such cover, so this is minimum vertex cover.
  4. Duality picture. The primal was fractional maximum matching and this dual is fractional minimum vertex cover, so LP duality gives max fractional matching \(=\) min fractional vertex cover.

For bipartite graphs the LPs even have integral optima, so matching and cover values coincide, which is Konig's theorem falling right out of duality.
