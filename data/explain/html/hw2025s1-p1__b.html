We show \(\mathsf{RP}\subseteq\mathsf{BPP}\) (and symmetrically \(\mathsf{coRP}\subseteq\mathsf{BPP}\)) by amplifying the one-sided-error algorithm. Recall \(\mathsf{BPP}=\mathsf{BPP}(1/3,2/3)\): we need an algorithm that accepts \(x\in A\) with probability \(\ge 2/3\) and accepts \(x\notin A\) with probability \(\le 1/3\).

  1. The \(\mathsf{RP}\) guarantee. Let \(A\in\mathsf{RP}\) via \(M\): if \(x\notin A\) then \(M\) accepts with probability \(0\) (never a false accept), and if \(x\in A\) then \(M\) accepts with probability at least \(1/2\). The only failure mode is a false reject on an \(x\in A\).
  2. Amplify by repetition. Define \(M'\): run \(M\) twice with fresh, independent randomness and accept iff at least one run accepts. This can only turn rejects into an accept, never the reverse.
  3. No-instances stay safe. If \(x\notin A\), each run accepts with probability \(0\), so \(M'\) accepts with probability \(0\le 1/3\).
  4. Yes-instances get boosted. If \(x\in A\), each run rejects with probability at most \(1/2\), and by independence both reject with probability at most \(\tfrac12\cdot\tfrac12=\tfrac14\). Hence \(M'\) accepts with probability at least \(1-\tfrac14=\tfrac34\ge\tfrac23\).

So \(M'\) is a \(\mathsf{BPP}(1/3,2/3)\) algorithm for \(A\), giving \(A\in\mathsf{BPP}\); thus \(\mathsf{RP}\subseteq\mathsf{BPP}\). The proof that \(\mathsf{coRP}\subseteq\mathsf{BPP}\) is analogous: a \(\mathsf{coRP}\) algorithm never falsely rejects \(x\in A\) and rejects \(x\notin A\) with probability \(\ge 1/2\); running it twice and rejecting iff at least one run rejects makes the two-sided error at most \(1/4\) on both sides, meeting the \(\mathsf{BPP}\) gap.
