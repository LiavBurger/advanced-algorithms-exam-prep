We reduce the problem to Steiner tree by merging all senders into a single terminal.

  1. Add one artificial vertex \(v\) to \(G\), and connect \(v\) to every sender \(s\in S\) with an edge of cost \(0\); call the resulting graph \(G'\).
  2. On \(G'\), run the \(2\)-approximation algorithm for Steiner tree (seen in the problem sets) with required terminals \(R\cup\{v\}\).
  3. Output the returned subgraph, dropping the artificial vertex \(v\) and its zero-cost edges.

In \(G'\), a subgraph connects all of \(R\cup\{v\}\) if and only if every receiver has a path to \(v\); and since \(v\) is attached only to senders, any path from a receiver to \(v\) must use a zero-cost edge \((s,v)\), so it is exactly a path from that receiver to some sender (and conversely any receiver-to-sender path extends to \(v\) for free). Hence minimum-cost subgraphs connecting every receiver to some sender correspond exactly to minimum-cost Steiner trees for \(R\cup\{v\}\), and because the added edges cost \(0\), the optimal Steiner-tree cost equals the optimal cost of the original problem.

The Steiner-tree algorithm returns a solution of cost at most twice the optimal Steiner tree, i.e. at most twice the optimum of our problem; removing the free artificial edges leaves a subgraph of the original graph of the same cost. So this is a \(2\)-approximation, and it runs in polynomial time as it is a single call to the polynomial Steiner-tree approximation.

Intuition. Gluing all senders to one free hub turns "reach some sender" into "reach the hub," which is exactly a Steiner tree we already know how to 2-approximate.
