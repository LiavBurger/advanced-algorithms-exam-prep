Goal Write bin packing as an integer linear program and explain the variables.

Strategy Use 0/1 variables for "item in bin" and "bin open," minimize open bins, and add constraints for coverage, linkage, and capacity.

Key idea Two families of indicators — \(x_{ij}\) placing items and \(y_j\) opening bins — let the objective count exactly the bins actually used.

Why this move Packing is a set of yes/no placements, so binary variables model it directly; the \(y_j\ge x_{ij}\) link is what ties usage to the count we minimize.

  1. Bound the bins. There's always a packing into at most \(n\) bins (one item per bin), so index candidate bins \(j=1,\dots,n\).
  2. Variables. \(x_{ij}=1\) iff item \(i\) goes in bin \(j\); \(y_j=1\) iff bin \(j\) is open (used at all). Both are in \(\{0,1\}\).
  3. Objective. Minimize the number of open bins, \(\min\sum_{j=1}^n y_j\).
  4. Each item packed. \(\sum_{j=1}^n x_{ij}\ge 1\) for every \(i\) (at optimum exactly one bin).
  5. Only open bins used. If item \(i\) is in bin \(j\) then \(j\) must be open: \(y_j\ge x_{ij}\) for all \(i,j\). This links the two variable families so the objective really counts every bin we use.
  6. Capacity, then assemble. Each bin holds weight \(\le 1\): \(\sum_{i=1}^n x_{ij}w_i\le 1\) for all \(j\). Altogether \[\min \sum_{j} y_j \ \text{ s.t. }\ \sum_{j} x_{ij}\ge 1,\ \ y_j\ge x_{ij},\ \ \sum_{i} x_{ij}w_i\le 1,\ \ x_{ij},y_j\in\{0,1\}.\]
