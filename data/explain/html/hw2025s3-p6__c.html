This is the converse direction: if \(A=B^TB\) for some matrix \(B\), then \(A\) is positive semidefinite.

  1. Rewrite the quadratic form. Fix an arbitrary \(v\in\mathbb R^n\). Using \(A=B^TB\) and the transpose rule \((Bv)^T=v^TB^T\), \[v^TAv=v^TB^TBv=(Bv)^T(Bv)=\|Bv\|_2^2.\]
  2. Conclude non-negativity. A squared Euclidean norm is always \(\ge 0\), so \(v^TAv=\|Bv\|_2^2\ge 0\). Since this holds for every \(v\), by definition \(A\) is positive semidefinite.
