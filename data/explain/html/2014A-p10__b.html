The vertex is \(x_1=10,\;s_2=6\), with \(x_2=x_3=s_1=0\).

The basis is \(\{x_1,s_2\}\), so we set the three non-basic variables to \(0\): \(x_2=x_3=s_1=0\). Now solve the two equations for the basic variables. From the first equation,

\[ x_1=10-2x_2-s_1=10 . \]

From the second equation \(2x_1+x_2-x_3-s_2=14\), so

\[ s_2=-14+2x_1+x_2-x_3=6-3x_2-x_3-2s_1=6 . \]

Both basic values are \(\ge 0\), so this is a valid basic feasible solution: the vertex \((x_1,x_2,x_3)=(10,0,0)\) with \(s_1=0,\;s_2=6\).

Intuition. Fix the non-basic variables at \(0\) and the two equations pin down the two basic ones.
