Claim the running time is \(\Theta(n)\).

Strategy collect all the costs into one recurrence, then read the answer off the master theorem.

Key idea the \(3\) subproblems of size \(n/4\) shrink faster than the linear work per call, so the top-level \(\Theta(n)\) dominates.

Why this move a recurrence of the shape \(T(n)=aT(n/b)+f(n)\) is exactly what the master theorem is built to solve, so we just line up the pieces.

  1. Write the recurrence. There are \(a=3\) calls on size \(n/4\), so \(b=4\). The non-recursive work is the divide step \(\Theta(n)\) plus the combine step \(O(n^{2/3})\); since \(n\) dominates \(n^{2/3}\), that total is \(f(n)=\Theta(n)\). So \(T(n)=3T(n/4)+\Theta(n)\).
  2. Compare the two costs. The recursion-tree cost is \(n^{\log_4 3}\approx n^{0.79}\), while the top-level work is \(\Theta(n)=\Theta(n^{1})\). Since \(1>\log_4 3\), the linear term is polynomially larger.
  3. Read off the answer. The work is dominated by the top of the tree, so \(T(n)=\Theta(n)\). The base case \(n<500\) solved in \(500^3=O(1)\) only affects bounded inputs and does not change the asymptotics. Intuitively, all the recursive pieces together cost less than the single linear pass at the top.
