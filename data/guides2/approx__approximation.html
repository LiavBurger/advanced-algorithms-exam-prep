What you are actually being asked to do

An approximation algorithm returns a legal solution fast, together with a proof of how far it can be from the optimum. You never know OPT — that is the whole point (the problem is NP-hard). So the entire game is:

The one definition For a minimization problem, ALG is an \(\alpha\)-approximation (\(\alpha\ge 1\)) if on every input \[ \text{OPT} \le \text{ALG} \le \alpha\cdot\text{OPT}. \] For a maximization problem (\(\alpha\le 1\)) it is \[ \alpha\cdot\text{OPT} \le \text{ALG} \le \text{OPT}. \] You do not need ALG to contain an optimal solution — only to be provably close in value.

Because OPT is unknown, you can never compare to it directly. Instead you sandwich it between two quantities you can compute or reason about. This is the master pattern that every problem below is a special case of.

Pattern 1: Lower-bound OPT, upper-bound ALG
Find a quantity \(Q\) (matching size, LP value, sum of weights, an edge count) that you can control on both sides. Show \(Q \le \text{OPT}\) (min) and \(\text{ALG} \le c\cdot Q\). Chaining gives \(\text{ALG}\le c\cdot Q\le c\cdot\text{OPT}\). For maximization, flip: \(\text{ALG}\ge c\cdot Q\ge c\cdot\text{OPT}\).every approximation proof — pick the right bridge \(Q\)
Pattern 2: Greedy / maximal
Build the solution by a simple rule (pick an uncovered edge, the min-degree vertex, sets in ratio order) until nothing is left. The lower bound almost always comes from a disjointness / packing argument: the objects you greedily grabbed are pairwise "independent," so OPT must pay for each separately.vertex cover, hitting set \(|D|\le d\), independent set on max-degree-\(\Delta\) graphs
Pattern 3: LP-rounding (IP → relax → round)
Three mechanical steps: (i) write the problem as a 0/1 integer program; (ii) relax \(x_i\in\{0,1\}\) to \(0\le x_i\le 1\) and solve the LP in poly-time — this gives \(\text{OPT}_{LP}\le\text{OPT}\); (iii) round the fractional \(x^*\) to a legal integral solution and bound how much rounding costs.any problem with a natural 0/1 IP: set cover, hitting set, knapsack
Pattern 4: Local / combinatorial structure
Exploit a graph object you can compute exactly: a matching, an MST, a minimum cycle cover, or a primal-dual pair. These give clean lower bounds — e.g. a metric TSP tour contains a Hamiltonian cycle whose two perfect matchings each cost \(\le\text{OPT}/2\).TSP / Christofides, TSP with weights 1–2, Steiner tree, primal-dual set cover

Worked example — the maximal pattern in full

2014A P9. Prove any maximal matching \(M\) (one you cannot add another edge to) is a 2-approximation for maximum matching \(M^*\).

  1. Trivial upper bound. \(M\) is a matching, so \(|M|\le|M^*|=\text{OPT}\) — never worse than optimal.
  2. Lower bound via disjointness. Every edge of \(M^*\) must touch a vertex saturated by \(M\); otherwise that edge could be added to \(M\), contradicting maximality.
  3. Count. \(M\) saturates \(2|M|\) vertices, and each is an endpoint of at most one \(M^*\)-edge (\(M^*\) is a matching). So \(|M^*|\le 2|M|\).
  4. Chain. \[ \tfrac12\,\text{OPT}=\tfrac12|M^*|\le|M|\le|M^*|=\text{OPT}, \] a \(1/2\)-approximation for the (maximization) matching problem.
  5. Free corollary — Vertex Cover 2-approx. Output \(V(M)\), both endpoints of every matched edge. It is a cover (any uncovered edge would extend \(M\)), the matched edges are disjoint so \(\text{OPT}_{VC}\ge|M|\), and \[ \text{ALG}=2|M|\le 2\cdot\text{OPT}_{VC}. \] Same maximal object, mirrored as a min problem.

The problems, mapped to patterns

  • Greedy/maximal: hitting set with \(|D|\le d\) → \(d\)-approx by disjoint sets (2018A P2, hypergraph VC 2023B P3); min-degree greedy independent set → \((\Delta+1)\)-approx (2018B P2, hw2025 s5 P2).
  • LP-rounding: hitting set — since \(|T_j|\le d\) and \(\sum_{i\in T_j}x_i^*\ge1\), some \(x_i^*\ge 1/d\); round up those, cost grows \(\le d\times\) → \(d\)-approx (2024B P5). Knapsack as BIP/LP/dual (2017B P2). Randomized rounding for set cover: each set with prob \(x_i^*\) gives \(\mathbb{E}[|S|]=\text{OPT}_{LP}\le\text{OPT}\), each element covered w.p. \(\ge 1-1/e\), repeat \(T=\ln(n/\epsilon)\) rounds → \(O(\log n)\)-approx by union bound (hw2026 s4 P3).
  • Random assignment / probabilistic: MAX-3SAT — for each clause let \(Y_c\) be an indicator r.v. for the event "clause \(c\) is satisfied"; \(\mathbb{E}[Y_c]=7/8\), so by linearity \(\mathbb{E}[\text{ALG}]=\tfrac78 m\ge\tfrac78\text{OPT}\), then derandomize by conditional expectations (2014A P8). Max Triple Cut \(2/3\) (2023A P3).
  • Combinatorial: TSP min-weight matching \(\le\text{OPT}/2\) (2015B P3); Christofides path-TSP \(1.5\) (2017A P3); weights-1–2 TSP via min cycle cover → \(4/3\) (2021A P3); Steiner reduction (2014A P5).
  • Primal-dual: set cover — solve the dual, pick sets with tight constraints; complementary slackness gives an \(f\)-approx (2025C P2).
  • Greedy/local, other: bin packing additive-1 for \(1/m\) weights (2015A P6); greedy MAX-3-COL \(2/3\) (2021B P3).
Traps. (1) A greedy ratio must be proven, not assumed — "sort by ratio" fails on knapsack and max cut, and you are often asked to refute a claimed ratio with a counterexample (2016A P5, 2017B P2a, 2018B P2a). (2) Rounding up is safe for min-covering constraints but can violate a knapsack capacity — always re-check feasibility after rounding. (3) \(\text{OPT}_{LP}\le\text{OPT}\) only for a minimization IP; the inequality flips for maximization. (4) Metric/triangle-inequality assumptions are what make MST- and matching-based TSP bounds valid — state them.

Checklist for ANY approximation question

  1. Min or max? Fix the target direction of the inequality \(\text{OPT}\le\text{ALG}\le\alpha\,\text{OPT}\) (or the flip).
  2. Legality first. Prove ALG always outputs a feasible solution before touching the ratio.
  3. Choose the bridge \(Q\). Matching / LP value / packing count / MST — the thing you can bound against OPT.
  4. Lower-bound OPT. \(Q\le\text{OPT}\) (min) via disjointness or LP relaxation; \(Q\ge\text{OPT}\) for the max side.
  5. Upper-bound ALG. \(\text{ALG}\le c\cdot Q\) — count what the algorithm pays.
  6. Chain and read off \(\alpha=c\). State the ratio and confirm the running time is polynomial.
