We turn "does a common basis exist?" into "is a certain determinant polynomial nonzero?", then decide the latter by polynomial identity testing. Here \(U,V\in\mathbb{R}^{n\times m}\) have rank \(n\), and a common basis is a size-\(n\) set \(B\) with both \(U_B\) and \(V_B\) nonsingular.

  1. Build the polynomial. With variables \(y_1,\dots,y_m\), let \(Y=\operatorname{diag}(y_1,\dots,y_m)\) and \(D=UYV^\top=(UY)(V^\top)\).
  2. Cauchy–Binet. For an \(n\times m\) matrix and an \(m\times n\) matrix, \(\det(AC)=\sum_{B\in\binom{[m]}{n}}\det(A_B)\det(C^B)\), where \(A_B\) keeps the columns of \(A\) in \(B\) and \(C^B\) the rows of \(C\) in \(B\). Take \(A=UY,\ C=V^\top\).
  3. Evaluate the factors. Since \(Y\) is diagonal, \(UY\) is \(U\) with column \(j\) scaled by \(y_j\); the determinant is linear in each column, so \(\det((UY)_B)=\big(\prod_{j\in B}y_j\big)\det(U_B)\). Also \((V^\top)^B=(V_B)^\top\), so \(\det((V^\top)^B)=\det(V_B)\). Hence \[\det(D)=\sum_{B\in\binom{[m]}{n}}\Big(\prod_{j\in B}y_j\Big)\det(U_B)\det(V_B).\]
  4. Read off coefficients. Distinct \(B\)'s give distinct squarefree monomials \(\prod_{j\in B}y_j\), so nothing cancels: the coefficient of \(\prod_{j\in B}y_j\) is exactly \(\det(U_B)\det(V_B)\).

Equivalence. \(B\) is a common basis \(\iff U_B,V_B\) are rank \(n\) \(\iff\det(U_B),\det(V_B)\neq 0\iff\) the coefficient of \(\prod_{j\in B}y_j\) is nonzero. Therefore a common basis exists \(\iff\det(D)\) is not the zero polynomial. Each monomial uses \(n\) distinct variables, so \(\deg\det(D)\le n\).

Algorithm (PIT via Schwartz–Zippel). Fix \(S=\{1,\dots,10n\}\); draw \(\alpha_1,\dots,\alpha_m\) independently and uniformly from \(S\); set \(Y'=\operatorname{diag}(\alpha_i)\), form \(D'=UY'V^\top\), compute \(\det(D')\) by Gaussian elimination, and output "yes" iff \(\det(D')\neq 0\).

If there is no common basis, \(\det(D)\equiv 0\), so \(\det(D')=0\) always and we correctly answer "no." If there is one, \(\det(D)\) is a nonzero polynomial of degree \(\le n\), so by Schwartz–Zippel \(\Pr[\det(D')=0]\le \tfrac{n}{|S|}=\tfrac{n}{10n}=0.1\); we answer "yes" with probability \(\ge 0.9\). Error \(\le 0.1\), and every step runs in time polynomial in \(n,m\).
