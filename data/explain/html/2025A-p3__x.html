For each job \(1\le i\le n\) and machine \(1\le j\le m\), introduce a boolean variable \(x_{i,j}\in\{0,1\}\) where \(x_{i,j}=1\) means job \(i\) is assigned to machine \(j\). Add one more variable \(T\) representing the makespan (the load of the machine that finishes last), which we minimize. The program is \[ \begin{aligned} \text{minimize}\quad & T\\ \text{subject to}\quad & \sum_{j=1}^{m} x_{i,j}=1 && \text{for all } 1\le i\le n,\\ & \sum_{i=1}^{n} x_{i,j}\,p_i \le T && \text{for all } 1\le j\le m,\\ & x_{i,j}\in\{0,1\} && \text{for all } 1\le i\le n,\ 1\le j\le m. \end{aligned} \]

The first set of constraints says each job is assigned to exactly one machine. The second set says the load of every machine, \(\sum_i x_{i,j}p_i\), is at most \(T\). Since we minimize \(T\) subject to it being an upper bound on all machine loads, at the optimum \(T\) equals the maximum machine load, so the optimal \(T\) is exactly the minimum makespan.

Intuition. "Minimize the maximum load" is not linear on its own, so we introduce one ceiling variable \(T\) above every load and just push it down.
