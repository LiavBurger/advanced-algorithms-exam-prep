Goal Compute the boolean product \(A\circ B\) in time \(o(n^3)\).

Strategy Cast the boolean OR-of-ANDs as an ordinary integer matrix product, run fast matrix multiplication, then threshold each entry at \(0\).

Key idea The boolean entry \((A\circ B)_{i,j}\) is \(1\) exactly when the integer inner product \(\sum_k A_{i,k}B_{k,j}\) is positive.

Why this move Fast matrix multiplication only exists over rings, not for boolean OR/AND directly — so we borrow it by turning the logic into arithmetic.

  1. Logic to arithmetic. Treat entries as integers. For each \(k\), \(A_{i,k}\wedge B_{k,j}\) equals the product \(A_{i,k}B_{k,j}\), and the OR over \(k\) is true iff the sum \((A\cdot B)_{i,j}=\sum_{k=1}^n A_{i,k}B_{k,j}\) is strictly positive.
  2. Equivalence. So \((A\circ B)_{i,j}=1 \iff (A\cdot B)_{i,j}>0\), where \(A\cdot B\) is the standard integer product (a nonnegative sum that is \(0\) only if every term is \(0\)).
  3. Multiply fast. Compute \(C=A\cdot B\) with fast matrix multiplication in \(O(n^\omega)\), where \(\omega<3\) (about \(2.37\)); this dominates the cost.
  4. Threshold. Output the matrix with entry \(1\) where \(C_{i,j}>0\) and \(0\) otherwise, scanning all entries in \(O(n^2)\). Total \(O(n^\omega)=o(n^3)\), as required.
