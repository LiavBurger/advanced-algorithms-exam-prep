The relaxed primal is: minimize \(\sum_{i=1}^{m} c_i x_i\) subject to \(\sum_{i:\,S_i \ni j} x_i \ge 1\) for every \(j\), and \(x_i \ge 0\) for every \(i\). We put this in standard equality form and read off its dual, and the dual turns out to be exactly (D).

Let \(A\) be the \(n \times m\) incidence matrix with \(A_{j,i} = 1\) if \(j \in S_i\) and \(A_{j,i} = 0\) otherwise, let \(c = (c_1,\dots,c_m)\), and let \(\mathbf{1}\) be the all-ones vector. Row \(j\) of \(A x\) is \(\sum_{i:\,S_i \ni j} x_i\), so the \(n\) covering constraints are exactly \(A x \ge \mathbf{1}\), and the relaxed primal is

\[ \text{minimize } c^{\top} x \quad \text{subject to } A x \ge \mathbf{1}, \; x \ge 0. \]

To reach standard form we turn each \(\ge\) into an equality by subtracting a nonnegative slack vector \(s \ge 0\), so \(A x - s = \mathbf{1}\), i.e. \(-A x + s = -\mathbf{1}\). Writing the two variable blocks together,

\[ \text{minimize } c^{\top} x \quad \text{subject to } [\,-A \mid I\,]\begin{bmatrix} x \\ s \end{bmatrix} = -\mathbf{1}, \; x,s \ge 0, \]

where the cost vector for \((x,s)\) is \((c,\mathbf{0})\) since the slacks carry no cost.

For a standard-form primal "minimize \(b^{\top} z\) subject to \(M z = d,\ z \ge 0\)", the dual is "maximize \(d^{\top} y\) subject to \(M^{\top} y \le b\)", with \(y\) unrestricted in sign (one dual variable per equality constraint, here one \(y_j\) per element \(j\)). Plugging in \(d = -\mathbf{1}\), \(M = [\,-A \mid I\,]\), and \(b = (c,\mathbf{0})\), the dual is

\[ \text{maximize } -\mathbf{1}^{\top} y \quad \text{subject to } \begin{bmatrix} -A^{\top} \\ I \end{bmatrix} y \le \begin{bmatrix} c \\ \mathbf{0} \end{bmatrix}, \; y \text{ free}. \]

The top block \(-A^{\top} y \le c\) has, in row \(i\), the entry \(\sum_{j:\,j \in S_i} (-y_j) \le c_i\); the bottom block \(I y \le \mathbf{0}\) says \(y_j \le 0\) for every \(j\).

Now substitute \(y \mapsto -y\) (allowed because \(y\) is free). The objective \(-\mathbf{1}^{\top} y\) becomes \(\mathbf{1}^{\top} y = \sum_{j=1}^{n} y_j\); the top block becomes \(\sum_{j:\,j \in S_i} y_j \le c_i\) for every \(i\); and \(y_j \le 0\) becomes \(y_j \ge 0\) for every \(j\). This is precisely

\[ \text{maximize } \sum_{j=1}^{n} y_j \quad \text{subject to } \sum_{j:\,j \in S_i} y_j \le c_i \text{ for all } i,\; y_j \ge 0 \text{ for all } j, \]

which is exactly (D). Hence (D) is the dual of the LP relaxation.

Intuition. One dual variable per element, and its constraints say the total charge packed onto any set must not exceed that set's cost.
