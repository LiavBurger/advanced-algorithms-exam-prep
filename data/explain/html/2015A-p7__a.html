Add slack variables \(s_1,s_2,s_3\ge0\), one per inequality, to get the starting dictionary (the non-basic variables \(x_1,x_2,x_3,x_4\) are set to \(0\)):

\[z=2x_1+4x_2+3x_3+x_4,\] \[s_1=12-3x_1-x_2-x_3-4x_4,\] \[s_2=7-x_1+3x_2-2x_3-3x_4,\] \[s_3=10-2x_1-x_2-3x_3+x_4.\]

For the first pivot I choose an entering variable with a positive objective coefficient; \(x_2\) has the largest (\(4\)), so \(x_2\) enters. Now I raise \(x_2\) and check which basic variable reaches \(0\) first: the \(s_1\) row allows \(x_2\le 12\), the \(s_2\) row has coefficient \(+3\) so it never binds, and the \(s_3\) row allows \(x_2\le 10\). The tightest bound is \(10\), so \(s_3\) leaves the basis.

Solving the \(s_3\) row for \(x_2\):

\[x_2=10-2x_1-3x_3+x_4-s_3.\]

Substituting this into the other rows gives the dictionary after the first pivot:

\[z=40-6x_1-9x_3+5x_4-4s_3,\] \[s_1=2-x_1+2x_3-5x_4+s_3,\] \[s_2=37-7x_1-11x_3-3s_3,\] \[x_2=10-2x_1-3x_3+x_4-s_3.\]

Intuition. One pivot swaps a zero variable for the constraint that blocks it first, then rewrites everything in the new set of zero variables.
