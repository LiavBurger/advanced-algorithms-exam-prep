Set \(x_v=\tfrac12\) for every \(v\in V\). This is feasible: for each edge \((u,v)\) we have \(x_u+x_v=\tfrac12+\tfrac12=1\le 1\), and \(x_v=\tfrac12\ge 0\). Its objective value is

\[\sum_{v\in V}x_v=\sum_{v\in V}\tfrac12=\frac{n}{2}.\]

The LP is a maximization, so its optimum is at least the value of any feasible solution. We exhibited a feasible solution of value \(n/2\), hence the LP optimum is at least \(n/2\).

Intuition. Half a unit on every vertex satisfies each edge exactly, and there are \(n\) of them.
