True. Strassen's algorithm multiplies two \(2\times 2\) matrices using only \(7\) multiplications (instead of \(8\)). We use it twice, nested.

Split each \(4\times 4\) matrix into four \(2\times 2\) blocks, so it becomes a \(2\times 2\) matrix whose entries are \(2\times 2\) blocks. Multiply these two block matrices with Strassen at the block level: this uses \(7\) block multiplications (the block additions cost no scalar multiplications). Each of those block multiplications is itself a product of two \(2\times 2\) matrices, which we again do by Strassen with \(7\) scalar multiplications.

In total the number of scalar multiplications is \(7\times 7=49\), so \(49\) multiplications suffice.

Intuition. Nest Strassen once: \(7\) block products, each an inner \(2\times 2\) product costing \(7\), gives \(49\).
