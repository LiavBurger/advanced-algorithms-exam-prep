False. In the simplex algorithm as presented in class, the algorithm moves to a different vertex only when it can strictly improve (decrease) the objective value. So a move to a different vertex always strictly changes the objective, and it never moves to a different vertex whose value equals the current one.

The only place equal values appear is degeneracy: when the current basic feasible solution is degenerate, a pivot step may change the basis while the actual point stays the same. But that is a change of basis at the same vertex, not a move to a different vertex. Hence the described behavior — moving to a different vertex with the same objective value — does not happen, and the statement is false.

Intuition. A real move to a new vertex always strictly improves the objective; equal-value steps are just basis swaps that stay at the same point.
