Alice holds \(a\in\{0,1\}^n\) and Bob holds \(b\in\{0,1\}^n\); we read each string as an integer in \([0,2^n-1]\) written in binary. We want a randomized protocol deciding whether \(a=b\) using only \(O(\log n)\) bits of communication, with small one-sided error. Two protocols achieve this.

  1. Protocol 1 — random prime modulus. Alice picks a uniformly random prime \(p\in[1,n^{10}]\) and sends Bob both \(p\) and \(a\bmod p\), in binary. Since \(p\le n^{10}\), each of these is at most \(n^{10}\) and needs \(O(\log n)\) bits. Bob computes \(b\bmod p\) and declares "equal" iff \(a\bmod p=b\bmod p\).
  2. No error when \(a=b\). If \(a=b\) then \(a\equiv b\pmod p\) for every \(p\), so Bob always (correctly) declares "equal".

  4. Protocol 2 — polynomial fingerprint. Fix a prime \(p\) with \(n^2\le p\le n^3\) (one exists for large \(n\)). Interpret the inputs as polynomials over \(\mathbb F_p\): \(a(x)=\sum_{i=1}^n a_ix^{i-1}\) and \(b(x)=\sum_{i=1}^n b_ix^{i-1}\). Alice picks a uniform \(t\in\mathbb F_p\) and sends the single field element \(a(t)\), which takes \(\log p=O(\log n)\) bits. Bob computes \(b(t)\) and declares "equal" iff \(a(t)=b(t)\).
  5. Error analysis. If \(a=b\), the polynomials are identical, so \(a(t)=b(t)\) for every \(t\). If \(a\neq b\), then \(a-b\) is a nonzero polynomial of degree at most \(n-1\), so it has at most \(n-1\) roots in \(\mathbb F_p\); hence \[\Pr_{t\in\mathbb F_p}[a(t)=b(t)]=\Pr_{t\in\mathbb F_p}[(a-b)(t)=0]\le\frac{n-1}{p}\le\frac1n,\] using \(p\ge n^2\). This bounds the probability of a wrong "equal" answer.
