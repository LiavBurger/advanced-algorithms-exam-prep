We compute the transitive closure \(G^*\) of a directed graph in \(o(n^3)\) time by expressing reachability as a Boolean matrix power and evaluating it with fast (integer) matrix multiplication and repeated squaring.

  1. Reachability as matrix powers. Let \(A\) be the Boolean adjacency matrix and \(M:=A\vee I\) (add self-loops). Working over the Boolean semiring (\(\wedge\) for product, \(\vee\) for sum), we claim \((M^k)_{u,v}=1\) iff there is a walk \(u\to v\) of length \(\le k\). Induct on \(k\): the base \(M^0=I\) says there is a length-\(0\) walk iff \(u=v\); the step is \((M^{k+1})_{u,v}=\bigvee_w (M^k)_{u,w}\wedge M_{w,v}\), which is \(1\) iff some \(w\) has a walk \(u\to w\) of length \(\le k\) and an edge or self-loop \(w\to v\), i.e. a walk \(u\to v\) of length \(\le k+1\). The self-loops in \(M\) let strictly shorter walks still count.
  2. Which power to take. By definition \((u,v)\in E^*\) iff there is a directed walk \(u\to v\). Any walk can be shortened to a simple path by deleting internal cycles, and a simple path visits at most \(n\) vertices, so it has length \(\le n-1\). Hence \((u,v)\in E^*\) iff there is a walk of length \(\le n-1\), i.e. iff \((M^{n-1})_{u,v}=1\). Therefore \(E^*=M^{\,n-1}\).
  3. Compute the power fast. Evaluate \(M^{n-1}\) by repeated squaring, which uses \(O(\log n)\) Boolean matrix multiplications.
  4. Boolean via integer multiplication. Multiply the two \(\{0,1\}\)-matrices over the integers and threshold each entry to \(\{0,1\}\); every integer-product entry lies in \(\{0,\dots,n\}\), fitting in \(O(\log n)\) bits, so one Boolean multiplication costs \(O(n^{\omega})\), where \(\omega\) is the matrix-multiplication exponent.

Total running time is \(O(n^{\omega}\log n)\). Since \(\omega<3\), we have \(n^{\omega}\log n/n^3=\log n/n^{3-\omega}\to 0\), so this is \(o(n^3)\), as required.
