There always exists a packing into at most \(n\) bins (\(n\) is the number of items), so we may use \(n\) candidate bins. Introduce a variable \(y_j\in\{0,1\}\) indicating whether bin \(j\) is open, and a variable \(x_{ij}\in\{0,1\}\) indicating whether item \(i\) is packed in bin \(j\). The integer linear program is: \[\min \sum_{j=1}^{n} y_j\] subject to \[\sum_{j=1}^{n} x_{ij}\ge 1 \quad \forall i=1,\dots,n \qquad\text{(each item is packed into some bin)}\] \[y_j\ge x_{ij} \quad \forall i,j \qquad\text{(an item can be placed only in an open bin)}\] \[\sum_{i=1}^{n} x_{ij}\,w_i \le 1 \quad \forall j=1,\dots,n \qquad\text{(no bin exceeds capacity \(1\))}\] \[x_{ij},\,y_j\in\{0,1\}.\] The objective counts the open bins, which we minimize.

Intuition. One switch per item-bin pair and one per bin; open as few bins as possible while every item lands somewhere and no bin overflows.
