Goal write the integer program for weighted set cover.

Strategy one binary variable per set saying whether we take it, minimize the total cost of taken sets, and demand every element be covered by at least one.

Key idea "covering element \(j\)" means at least one chosen set contains \(j\), which is a linear "\(\ge 1\)" constraint over the sets holding \(j\).

Why this move the pick/don't-pick decision on each set is naturally binary, and the coverage requirement is one inequality per element — the standard ILP shape.

  1. Choose variables. For each set \(S_i\), \(x_i\in\{0,1\}\), with \(1\) meaning \(S_i\) is in the cover.
  2. Objective. Cheapest family: \(\min\sum_{i=1}^m c_i x_i\).
  3. Coverage constraints. For each element \(j\), the chosen sets containing it must number at least one: \(\sum_{i:\,S_i\ni j}x_i\ge 1\).
  4. Integrality. \(x_i\in\{0,1\}\) for all \(i\).

Each element constraint guarantees some chosen set covers it, so a feasible \(0/1\) vector is a valid cover and its objective is that cover's cost — the optimum is a minimum-weight set cover.
