The statement is true. The solution connects a determinant condition to an eigenvalue, and then invokes a spectral characterization of bipartiteness proved in class.

  1. A determinant is zero exactly when the matrix is singular, i.e. has a non-trivial kernel. So \(\det(A+I)=0\) means there is a nonzero vector \(v\) with \((A+I)v=0\).
  2. Expand: \((A+I)v=Av+v=0\), hence \(Av=-v\). By definition this says \(v\) is an eigenvector of \(A\) with eigenvalue \(-1\). So \(-1\) is an eigenvalue of the normalized adjacency matrix \(A\).
  3. Recall the spectral facts about the normalized adjacency matrix of a graph: all its eigenvalues lie in \([-1,1]\), the largest is \(+1\) (with multiplicity one when the graph is connected), and the smallest possible value \(-1\) is attained if and only if the graph is bipartite. This is the theorem proved in class.
  4. Since we just showed \(-1\) is an eigenvalue of \(A\), the "only if" direction of that theorem forces \(G\) to be bipartite.
The chain is: \(\det(A+I)=0\) \(\Rightarrow\) \(-1\) is an eigenvalue of \(A\) \(\Rightarrow\) (by the class theorem) \(G\) is bipartite. Connectivity is used implicitly so that the spectral characterization applies cleanly.
