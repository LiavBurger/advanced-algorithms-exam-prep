False. Ratio \(1\) would mean the greedy always returns a maximum independent set, so one family of bad graphs refutes it.

For any \(n\ge 3\) take \(2n+1\) vertices \(x,\ v_1,\dots,v_n,\ w_1,\dots,w_n\), with edges \(xv_i\) for all \(i\), \(v_iw_j\) for all \(i,j\), and \(w_iw_j\) for all \(i\ne j\) (so the \(w\)'s form a clique). The degrees are

\[ \deg(x)=n,\qquad \deg(v_i)=n+1,\qquad \deg(w_i)=2n-1 . \]

For \(n\ge 3\), \(x\) is the unique minimum-degree vertex, so the algorithm grabs \(x\) first and deletes \(x\) together with all its neighbors, the \(v_i\)'s. Only the \(w\)-clique remains; it picks one \(w_i\), which deletes the whole clique. The graph is now empty, so the algorithm stops with \(\{x,w_i\}\), of size \(2\).

But the \(v_i\)'s have no edges among themselves, so \(\{v_1,\dots,v_n\}\) is an independent set of size \(n\), giving \(\mathrm{OPT}\ge n\). Thus the algorithm returns \(2\) while \(n\) was available, and the ratio \(n/2\) grows without bound, so ratio \(1\) cannot hold.

Intuition. Chasing the single smallest-degree vertex drags in neighbors whose removal destroys a large independent set sitting right there.
