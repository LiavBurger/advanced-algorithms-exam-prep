Let \(y^{*}\) be an optimal solution of (D), and let the chosen family be all sets \(S_i\) whose constraint (2) is tight, i.e. \(\sum_{j:\,j \in S_i} y^{*}_j = c_i\). We show this family covers every element. Suppose not, and derive a contradiction with the optimality of \(y^{*}\).

Assume the chosen family is not a set cover, so some element \(j_0\) lies in no chosen set. Every set \(S_i\) that contains \(j_0\) is therefore not chosen, which means its constraint is not tight: it is strict,

\[ \sum_{j:\,j \in S_i} y^{*}_j < c_i \qquad \text{for every } i \text{ with } j_0 \in S_i. \]

(If any such \(S_i\) had a tight constraint it would be in the family, and then \(j_0\) would be covered.)

Now nudge \(y^{*}\) by raising only the coordinate of \(j_0\): set \(y'_{j_0} = y^{*}_{j_0} + \varepsilon\) and \(y'_j = y^{*}_j\) for all \(j \ne j_0\), for a small \(\varepsilon > 0\). Check feasibility for (D). The variable \(y_{j_0}\) appears only in the constraints of sets that contain \(j_0\), and every one of those constraints was strict. So we can pick \(\varepsilon\) small enough that all of them still hold; concretely, take any

\[ 0 < \varepsilon \le \min_{i:\,j_0 \in S_i}\Big(c_i - \sum_{j:\,j \in S_i} y^{*}_j\Big), \]

which is positive because each of those slacks is positive. Every constraint not involving \(j_0\) is unchanged, and \(y'_{j_0} = y^{*}_{j_0} + \varepsilon \ge 0\), so \(y'\) is feasible.

But the objective strictly increases: \(\sum_{j=1}^{n} y'_j = \sum_{j=1}^{n} y^{*}_j + \varepsilon > \sum_{j=1}^{n} y^{*}_j\). This contradicts \(y^{*}\) being optimal for the maximization (D).

Therefore no such uncovered \(j_0\) exists: every element is contained in some tight set, so the family of tight sets is a set cover.

Intuition. If an element were uncovered, all sets touching it have slack, so we could raise that element's dual value and beat the optimum.
