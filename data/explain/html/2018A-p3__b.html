Goal Write the LP relaxation of the matching ILP and drop any redundant constraint.

Strategy Replace \(x_e\in\{0,1\}\) by \(0\le x_e\le 1\), then notice the upper bounds \(x_e\le 1\) are already forced by the vertex equalities.

Key idea A single edge value cannot exceed the sum at its endpoint, which equals \(1\), so \(x_e\le 1\) comes for free.

Why this move "Relax and remove redundant constraints" is the standard LP-relaxation exercise — swap integrality for an interval, then prune what other constraints already imply.

  1. Relax integrality. Replace \(x_e\in\{0,1\}\) with \(0\le x_e\le 1\), keeping the vertex equalities \(\sum_{uv\in E} x_{uv} = 1\).
  2. Upper bound is redundant. For edge \(e=uv\), the endpoint equality at \(u\) is \(\sum_{uw\in E} x_{uw} = 1\), and it contains the term \(x_{uv}\). Since every term is nonnegative, \(x_{uv}\le 1\) automatically.
  3. Prune it. So each \(x_e\le 1\) follows from the vertex equality plus \(x_e\ge 0\) and can be removed.

The clean relaxation is \[\min \sum_{e\in E} w(e)\,x_e \quad\text{s.t.}\quad \forall v\in V:\ \sum_{uv\in E} x_{uv} = 1,\qquad \forall e\in E:\ x_e\ge 0.\] Only the vertex equalities and nonnegativity remain.
