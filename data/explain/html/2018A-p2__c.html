Goal Give a 3-competitive online algorithm for hitting set when each subset has size at most \(3\).

Strategy Run the exact same greedy, treating the online arrival order as the "arbitrary order" the offline version already allows.

Key idea The offline greedy never uses knowledge of future subsets and never undoes a choice, so it works unchanged when subsets arrive one at a time.

Why this move When an offline algorithm processes items in any order with irrevocable decisions, it is already an online algorithm — no redesign needed.

  1. Algorithm. Keep \(X\). When a subset \(D\) arrives, if \(X\cap D=\emptyset\) add all of \(D\); otherwise leave \(X\) unchanged.
  2. Order doesn't matter. Part (a)'s analysis allowed arbitrary processing order and never looked ahead, so let that order be the arrival order.
  3. Requirements met. After each arriving \(D\) we have \(X\cap D\ne\emptyset\), so \(X\) hits everything seen so far, and additions are never removed.

The final \(X\) is exactly what the offline greedy would build on that sequence, so its bound \(|X|\le 3\,\mathrm{OPT}\) carries over and the algorithm is 3-competitive.
