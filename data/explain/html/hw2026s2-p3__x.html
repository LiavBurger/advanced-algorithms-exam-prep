Recall the common-basis problem: given \(U,V\in\mathbb R^{n\times m}\) of rank \(n\) (with \(n\le m\)), a set \(B\subseteq[m]\) is a common basis if the \(n\times n\) column-submatrices \(U_B,V_B\) both have rank \(n\), i.e. \(\det(U_B)\neq0\) and \(\det(V_B)\neq0\). We design a randomized algorithm that finds such a \(B\) when one exists.

  1. Encode common bases in a determinant (from Problem Set 1). With \(Y=\mathrm{diag}(y_1,\dots,y_m)\), the Cauchy–Binet formula gives \[\det(UYV^T)=\sum_{B\in\binom{[m]}{n}}\Bigl(\prod_{j\in B}y_j\Bigr)\det(U_B)\det(V_B),\] multilinear in \(y\); the coefficient of the monomial \(\prod_{j\in B}y_j\) is \(\det(U_B)\det(V_B)\), which is nonzero exactly when \(B\) is a common basis.
  2. Isolate a unique common basis. By the Isolation Lemma (Mulmuley–Vazirani–Vazirani), drawing weights \(w_1,\dots,w_m\) uniformly from \(\{1,\dots,2m\}\), the nonempty family of common bases has a unique minimum-weight member \(B^*\) with probability at least \(\tfrac12\); set \(W^*=\sum_{j\in B^*}w_j\).
  3. Reduce to one variable. Substituting \(y_j\leftarrow x^{w_j}\) collapses the determinant to the univariate polynomial \(Q(x)=\sum_B x^{w(B)}\det(U_B)\det(V_B)\), where \(w(B)=\sum_{j\in B}w_j\) and \(\deg Q\le 2mn\) (each \(w_j\le2m\), and \(|B|=n\)). When isolation succeeds, \(x^{W^*}\) is the lowest-degree surviving term: its coefficient is \(\det(U_{B^*})\det(V_{B^*})\neq0\), while any other \(B\) with \(w(B)=W^*\) is not a common basis and contributes \(0\).
  4. Algorithm. Sample the \(w_j\); recover \(Q\) by evaluating \(\det(UYV^T)\) at \(2mn+1\) distinct points and interpolating. If \(Q\equiv0\), output "no common basis". Otherwise let \(W^*\) be the smallest exponent with nonzero coefficient; for each \(j\), recompute the polynomial \(Q^{(j)}\) obtained by setting \(y_j=0\) and let \(W^{(j)}\) be its smallest nonzero-coefficient exponent (\(\infty\) if \(Q^{(j)}\equiv0\)). Output \(B=\{j:W^{(j)}>W^*\}\).
  5. Correctness and amplification. When isolation succeeds: for \(j\in B^*\), zeroing \(y_j\) deletes \(B^*\)'s term and every remaining common basis has weight \(>W^*\), so \(W^{(j)}>W^*\); for \(j\notin B^*\), \(B^*\)'s term survives, so \(W^{(j)}=W^*\). Hence the output equals \(B^*\), a common basis. If isolation fails the output may not be valid — but \(B\) is a common basis iff \(\det(U_B),\det(V_B)\neq0\), checkable in \(O(n^\omega)\). Running \(k=\lceil\log_2(1/\delta)\rceil\) independent trials and returning the first \(B\) that passes fails only if all \(k\) miss, with probability \(\le2^{-k}\le\delta\).
Total time: \(O(m)\) polynomials, each interpolated from \(O(mn)\) determinant evaluations of \(n\times n\) matrices, giving \(O(m^2 n^{\omega+1})\).
