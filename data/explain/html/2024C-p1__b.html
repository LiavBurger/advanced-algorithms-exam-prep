Claim True: for a nonzero polynomial \(f(x_1,\dots,x_n)\) of degree \(d\) over \(\mathbb{Q}\), some point in \(\{1,\dots,d+1\}^n\) gives \(f\neq 0\).

Strategy Bound the chance a random point from that grid is a root, and show it stays below \(1\).

Key idea If the fraction of roots is strictly less than everything, a non-root must exist.

Why this move A grid of size \(d+1\) per variable against a degree-\(d\) polynomial is the exact setup Schwartz-Zippel was built for.

  1. Sample from the grid. Draw each \(\alpha_i\) independently and uniformly from \(S=\{1,\dots,d+1\}\), so \(|S|=d+1\).
  2. Apply Schwartz-Zippel. The lemma bounds the chance of hitting a root: \(\displaystyle\Pr[f(\alpha_1,\dots,\alpha_n)=0]\le \frac{d}{d+1}\).
  3. Note it is below one. Since \(\dfrac{d}{d+1}<1\), the event \(f\neq 0\) has strictly positive probability.
  4. Existence follows. A positive-probability event over a finite grid cannot be empty, so some concrete \((\alpha_1,\dots,\alpha_n)\) with \(f\neq 0\) exists.

A nonzero polynomial simply cannot vanish everywhere on a grid this wide; some grid point escapes being a root.
