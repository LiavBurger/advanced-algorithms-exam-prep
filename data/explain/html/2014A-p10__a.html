Goal rewrite the LP with equality constraints so simplex can run on it.

Strategy turn each inequality into an equation by adding one non-negative variable that absorbs the gap between the two sides.

Key idea a "\(\le\)" leaves room below the bound, so we add slack; a "\(\ge\)" overshoots the bound, so we subtract surplus.

Why this move simplex only knows how to walk between vertices of a system of equalities in non-negative variables, so the first thing you always do is manufacture that form.

  1. The \(\le\) constraint. \(x_1+2x_2\le 10\) may fall short of \(10\), so add slack \(s_1\ge 0\): \(x_1+2x_2+s_1=10\). Then \(s_1=10-(x_1+2x_2)\ge 0\) exactly when the original held.
  2. The \(\ge\) constraint. \(2x_1+x_2-x_3\ge 14\) may exceed \(14\), so subtract surplus \(s_2\ge 0\): \(2x_1+x_2-x_3-s_2=14\).
  3. Leave the objective alone. The new variables get coefficient \(0\), so \(\max\,2x_1+5x_2+2x_3\) is unchanged, and every variable stays \(\ge 0\).

Putting it together:

\[ \max\; 2x_1+5x_2+2x_3 \quad\text{s.t.}\quad \begin{aligned} &x_1+2x_2+s_1=10,\\ &2x_1+x_2-x_3-s_2=14,\\ &x_i,\,s_i\ge 0 . \end{aligned} \]

Two equations in five non-negative variables — the shape simplex wants, with a basis (here \(s_1,s_2\)) and the rest set to \(0\).
