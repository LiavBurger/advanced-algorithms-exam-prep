The claim is true: this Christofides variant is a \(1.5\)-approximation for metric Path-TSP. Recall the algorithm: build a minimum spanning tree \(T\); let \(S\) be its odd-degree vertices; let \(M\) be a minimum-cost matching pairing all of \(S\) except exactly two vertices; find an Euler path in \(T\cup M\) and shortcut repeats into a Hamilton path. Let OPT be the optimal Hamilton path.

  1. An Euler path exists. \(S\) is nonempty (every leaf of \(T\) has degree \(1\), hence is odd). Adding \(M\) flips the parity of every matched vertex, so in \(T\cup M\) exactly the two unmatched vertices of \(S\) remain odd; all others are even. A connected graph with exactly two odd-degree vertices has an Euler path (the hint), so \(T\cup M\) has one.
  2. Bounding \(T\). OPT is a Hamilton path, which is in particular a spanning tree; since \(T\) is a minimum spanning tree, \(\mathrm{cost}(T)\le\mathrm{cost}(\mathrm{OPT})\).
  3. Bounding \(M\). As shown in class, \(|S|\) is even; write its vertices as \(v_1,v_2,\dots,v_{2k}\) in the order they appear along OPT. Form two matchings: \(M_1\) pairs \(v_1v_2, v_3v_4,\dots,v_{2k-3}v_{2k-2}\), and \(M_2\) pairs \(v_2v_3, v_4v_5,\dots,v_{2k-2}v_{2k-1}\). Each of \(M_1,M_2\) leaves exactly two vertices of \(S\) unmatched, so each is a candidate for \(M\).
  4. Triangle inequality. Along OPT the vertices of \(S\) appear in order, so OPT contains vertex-disjoint subpaths \(v_1\!\to\!v_2,\ v_2\!\to\!v_3,\ \dots,\ v_{2k-1}\!\to\!v_{2k}\). By the triangle inequality each matching edge \(v_iv_{i+1}\) costs at most the length of the OPT subpath between them. The edges of \(M_1\) and \(M_2\) together use each of these subpaths at most once, so \(\mathrm{cost}(M_1)+\mathrm{cost}(M_2)\le\mathrm{cost}(\mathrm{OPT})\).
  5. Pick the cheaper. Since \(M\) is a minimum such matching, \(\mathrm{cost}(M)\le\min(\mathrm{cost}(M_1),\mathrm{cost}(M_2))\le\tfrac12(\mathrm{cost}(M_1)+\mathrm{cost}(M_2))\le \mathrm{OPT}/2\).

Therefore \(\mathrm{cost}(T\cup M)=\mathrm{cost}(T)+\mathrm{cost}(M)\le \mathrm{OPT}+\mathrm{OPT}/2 = \tfrac32\,\mathrm{OPT}\). Shortcutting repeated vertices only removes cost (triangle inequality), so the returned Hamilton path costs at most \(\tfrac32\,\mathrm{OPT}\), proving the \(1.5\)-approximation.
