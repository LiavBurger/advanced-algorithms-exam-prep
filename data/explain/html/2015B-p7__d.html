We want a \(100\)-vertex graph on which the maximum independent set has size exactly \(1\). Take the clique \(K_{100}\): the complete graph where every pair of the \(100\) vertices is joined by an edge.

  1. Any two distinct vertices \(u,v\) are adjacent (that is what "complete" means). So no set containing two vertices can be independent — every such pair is an edge, violating independence.
  2. Therefore every independent set has at most one vertex.
  3. A single vertex is trivially independent (there is no pair inside it to form an edge), so size \(1\) is achievable.

Hence the ILP optimum \(\max\sum_v x_v\) equals \(1\). Combined with part (c), on \(K_{100}\) the LP optimum is \(\ge 50\) while the ILP optimum is \(1\): a large integrality gap.
