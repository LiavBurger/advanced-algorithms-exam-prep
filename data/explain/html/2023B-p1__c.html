The statement is false: no nonzero five-variable polynomial can vanish at every integer point. The Schwartz–Zippel lemma provides an explicit non-root, contradicting the claim.

  1. Set up. Suppose \(f(x_1,\dots,x_5)\) is a nonzero polynomial and let \(d\) be its total degree. We want an integer assignment where \(f\) does not vanish.
  2. Pick a finite grid. Take the set \(S=\{1,2,\dots,d+1\}\), which has \(|S|=d+1\) integer values. Consider assignments \((\alpha_1,\dots,\alpha_5)\) drawn from \(S^5\), i.e. each variable ranges over \(S\).
  3. Apply Schwartz–Zippel. For a nonzero polynomial of degree \(d\) and a uniformly random point of \(S^5\), the lemma bounds the probability of hitting a root by \(\Pr[f=0] \le \dfrac{d}{|S|} = \dfrac{d}{d+1} < 1\).
  4. Conclude a non-root exists. Since the probability of being a root is strictly less than \(1\), some point \((\alpha_1,\dots,\alpha_5)\in S^5\) satisfies \(f(\alpha_1,\dots,\alpha_5)\neq 0\).
The values \(\alpha_1,\dots,\alpha_5\in\{1,\dots,d+1\}\) are integers, so we have exhibited an integer assignment on which \(f\) is nonzero. Hence a nonzero polynomial cannot vanish on every integer assignment, and the statement is false.
