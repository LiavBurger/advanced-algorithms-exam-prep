We model "choose a minimum-weight set \(S\) that dominates every vertex". Introduce one binary variable per vertex: \(x_v\in\{0,1\}\), with \(x_v=1\) meaning \(v\in S\). A \(0/1\) assignment is then the same as a subset \(S\subseteq V\).

  1. Objective. The weight of \(S\) is \(\sum_{v\in S}w_v=\sum_{v\in V}w_v x_v\) (terms with \(x_v=0\) drop out). We minimize it: \(\min\sum_{v\in V}w_v x_v\).
  2. Domination constraint. A vertex \(v\) is dominated iff \(v\in S\) or some neighbor of \(v\) is in \(S\); equivalently, at least one vertex of the closed neighborhood \(N(v)\cup\{v\}\) is chosen. In LP terms: \(\displaystyle\sum_{u\in N(v)\cup\{v\}}x_u\ge 1\), for every \(v\in V\). With \(0/1\) values this sum is \(\ge 1\) exactly when at least one of those vertices has \(x_u=1\).
  3. Integrality. \(x_v\in\{0,1\}\) makes it an integer program (and encodes the yes/no membership).

So the ILP is \(\min\sum_{v}w_v x_v\) s.t. \(\sum_{u\in N(v)\cup\{v\}}x_u\ge 1\ \forall v\in V,\ x_v\in\{0,1\}\). Every feasible \(0/1\) vector is a dominating set of that weight, and conversely, so optimal ILP value = minimum weight dominating set.
