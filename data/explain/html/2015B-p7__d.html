Take \(G=K_{100}\), the complete graph on \(100\) vertices, in which every pair of vertices is joined by an edge. Any independent set can contain at most one vertex: if it contained two vertices \(u,v\), the edge \((u,v)\) would make \(x_u+x_v=2>1\), violating the constraint. A single vertex is trivially independent, so the maximum independent set — the optimum of the ILP in (a) — has size exactly \(1\).

Intuition. In a clique everyone is everyone's neighbor, so you can keep only one vertex.
