The LP relaxation LP1 is obtained from IP1 by dropping the integrality requirement: replace each constraint \(x_v\in\{0,1\}\) with the continuous constraint \(x_v\ge 0\). The relaxed program is

\[ \min \sum_{v\in V} x_v \quad\text{s.t.}\quad x_u+x_v\ge 1 \ \ \forall\, uv\in E,\qquad x_v\ge 0 \ \ \forall\, v\in V. \]

  1. Why only \(x_v\ge 0\). A relaxation must enlarge the feasible region. The box \(\{0,1\}\) becomes the interval \([0,1]\), which is described by \(x_v\ge 0\) together with \(x_v\le 1\). We keep the lower bound but can safely omit the upper bound.
  2. Why \(x_v\le 1\) is redundant. The objective is a minimization and every constraint on \(x_v\) is a lower bound (edge constraints and \(x_v\ge 0\)). If some optimal solution had \(x_v>1\), lowering that coordinate down to \(1\) keeps all edge constraints satisfied — an endpoint value of \(1\) already satisfies \(x_u+x_v\ge 1\) — and strictly decreases the objective. So no optimal solution ever needs a coordinate above \(1\); imposing \(x_v\le 1\) does not change the optimum.
Thus LP1 with just \(x_v\ge 0\) has the same optimal value as the version with \(0\le x_v\le 1\), which is why the upper bound is called redundant.
