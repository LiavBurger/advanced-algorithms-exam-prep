When do I reach for this?

Whenever a question says "write the dual", "prove the optimum is at least / at most \(k\)", "show \(x^\ast\) is optimal without solving", or hands you an infeasible/unbounded LP. The one idea underneath everything: the dual is the best certificate for a bound on the primal. Every dual-feasible point is a proof; strong duality says the best proof is tight.

  • "Write the dual" → the mechanical recipe below.
  • "Prove OPT \(\ge k\)" (a \(\min\)) → exhibit ONE feasible dual point of value \(k\); weak duality does the rest.
  • "Show \(x^\ast\) is optimal" → build a matching dual \(y^\ast\) with equal value, or check complementary slackness.
  • "(P) infeasible, (D) feasible \(\Rightarrow\) ?" → (D) is unbounded, via Farkas.

Core tools

PRIMAL / DUAL PAIR
\[ \text{(P)}\ \min c^\top x,\ Ax=b,\ x\ge 0 \qquad \text{(D)}\ \max b^\top y,\ A^\top y\le c \] The dual variable \(y\) is free (one per equality constraint). The dual of the dual is the primal. "write the dual"
WEAK / STRONG DUALITY
Weak: for all feasible \(x,y\), \[ b^\top y\ \le\ c^\top x \quad(\text{since } c^\top x\ge y^\top A x = y^\top b). \] Strong: if BOTH (P) and (D) are feasible then their optima are equal. "prove a bound", "reduce optimization to feasibility"
FARKAS' LEMMA
Exactly one holds: \[ \exists\,x\ge 0:\ Ax=b \qquad\text{OR}\qquad \exists\,y:\ A^\top y\ge 0,\ b^\top y<0. \] The \(y\) is a certificate of infeasibility. Variant II: \(Cx\le d\) unsolvable \(\Rightarrow\exists\,z\ge 0,\ z^\top C=0,\ z^\top d<0\). This is the engine that proves strong duality. "prove infeasible", "prove unbounded"
COMPLEMENTARY SLACKNESS
At a joint optimum, for each variable/constraint pair: \[ x_j>0\ \Rightarrow\ (A^\top y)_j=c_j, \qquad (A^\top y)_j"verify optimality of a given pair"

The dual, mechanically (memorize)

  1. Count. One dual variable per primal constraint; one dual constraint per primal variable.
  2. Flip the sense. \(\min\leftrightarrow\max\).
  3. Swap data. Primal RHS \(b\) becomes the dual objective; primal cost \(c\) becomes the dual RHS; use \(A^\top\) for the constraint matrix.
  4. Variable signs from primal constraint type (for a \(\min\) primal): primal "\(=\)" \(\to\) dual var free; primal "\(\ge\)" \(\to\) dual var \(\ge 0\); primal "\(\le\)" \(\to\) dual var \(\le 0\).
  5. Constraint sense from primal variable type: primal \(x_j\ge 0\) \(\to\) dual constraint is "\(\le\)"; primal \(x_j\) free \(\to\) dual constraint is "\(=\)".
  6. Sanity check with weak duality: dual value \(\le\) primal value at any feasible pair.

Worked example — the thinking

2015A P7. "Write the dual, then prove the dual optimum is at least 40." I never solve the LP.

  1. Write the dual by the recipe above (transpose, swap \(b\leftrightarrow c\), flip \(\min\)/\(\max\)).
  2. To bound the optimum, I only need ONE feasible point on the right side and read off its value; weak duality turns that single point into a proof of the bound. Producing a matching value on each side pins OPT exactly (strong duality).

The recurring exam pattern is "write the IP \(\to\) relax to LP \(\to\) dualize \(\to\) interpret". In 2023A P4 and 2014B P8 you relax maximum matching, transpose, and the dual is exactly vertex cover — König's theorem falls out. 2017A P6 does the same for hitting set, whose dual is set packing. 2025A P2 is a self-dual symmetric \(A\): show \(Ax^\ast=c,\ x^\ast\ge 0\) is optimal by matching primal and dual values. 2024C P6 is the pure Farkas move: (P) infeasible \(+\) (D) feasible \(\Rightarrow\) (D) unbounded — Farkas hands a direction \(y\) with \(A^\top y\ge 0,\ b^\top y<0\) along which \(b^\top y\to+\infty\).

Common traps

The dual of a \(\min\) is a \(\max\) — getting the direction backwards flips everything. — Wrong variable sign: equality \(\to\) free variable, inequality \(\to\) signed variable; a mismatch flips \(\le/\ge\) in the dual constraints. — Strong duality needs BOTH sides feasible; if one is infeasible you get the unbounded/infeasible relation, not equal optima (2023B P1 T/F). — Don't forget to transpose \(A\) and to swap \(b\) with \(c\). — Complementary slackness is an "iff at optimum" tool, not something you can assume mid-solve.

Checklist — write the dual

  1. Count: dual vars \(=\) #primal constraints, dual constraints \(=\) #primal vars.
  2. Swap \(\min\leftrightarrow\max\); move \(b\) into the objective, \(c\) into the RHS; use \(A^\top\).
  3. Set each dual variable's sign from its primal constraint type.
  4. Set each dual constraint's sense from its primal variable's sign.
  5. Verify with weak duality: dual value \(\le\) primal value.
