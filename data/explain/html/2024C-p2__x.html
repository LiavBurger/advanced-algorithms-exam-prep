Boolean product is defined by \((A\circ B)_{i,j}=\bigvee_{k=1}^n (A_{i,k}\wedge B_{k,j})\): entry \((i,j)\) is \(1\) iff some index \(k\) has both \(A_{i,k}=1\) and \(B_{k,j}=1\). Computing this directly costs \(\Theta(n^3)\). We beat that by reducing to ordinary integer matrix multiplication, which has fast \(O(n^\omega)\) algorithms with \(\omega<3\).

Key idea: a Boolean OR-of-ANDs is positive exactly when the corresponding integer inner product is positive. So run fast matrix multiplication over the integers, then threshold each entry at \(0\).
  1. Rewrite AND/OR as arithmetic. Treat the 0/1 entries as integers. For each \(k\), \(A_{i,k}\wedge B_{k,j}\) equals the integer product \(A_{i,k}B_{k,j}\) (it is \(1\) iff both are \(1\)). The OR over \(k\) is true iff at least one product is \(1\), i.e. iff the integer sum \((A\cdot B)_{i,j}=\sum_{k=1}^n A_{i,k}B_{k,j}\) is strictly positive.
  2. Equivalence. Hence \((A\circ B)_{i,j}=1 \iff (A\cdot B)_{i,j} > 0\), where \(A\cdot B\) is the standard integer matrix product. (The sum is a nonnegative integer; it is \(0\) iff every term is \(0\).)
  3. Compute \(C=A\cdot B\) fast. Run a fast matrix-multiplication algorithm over the integers in time \(O(n^\omega)\), where \(\omega<3\) (e.g. \(\omega\approx 2.37\)). This dominates the runtime.
  4. Threshold. Output the matrix whose \((i,j)\) entry is \(1\) if \(C_{i,j}>0\) and \(0\) otherwise. Scanning all \(n^2\) entries costs \(O(n^2)\).

Total time \(O(n^\omega)+O(n^2)=O(n^\omega)\), which is \(o(n^3)\) since \(\omega<3\), as required.
