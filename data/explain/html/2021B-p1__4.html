Claim False — rounding every \(x_e\ge\tfrac12\) up to \(1\) can produce an infeasible integer solution.

Strategy to break a "for all inputs" claim, exhibit one graph where the LP optimum, when rounded this way, overloads a vertex.

Key idea pile many edges onto a single capacity-\(2\) vertex: each gets fractional value \(\tfrac12\), and rounding them all up blows past the cap.

Why this move threshold rounding at \(\tfrac12\) has no built-in respect for the "\(\le 2\)" constraint, so a star where four half-valued edges meet one vertex is the natural place it fails.

  1. Pick the graph. \(V_1=\{a,b,c,d\}\), \(V_2=\{u\}\), \(E=\{au,bu,cu,du\}\): four edges all meeting \(u\).
  2. Give the fractional optimum. Set \(x_e=\tfrac12\) for all four. Each \(V_1\)-vertex carries \(\tfrac12\le 1\); vertex \(u\) carries \(4\cdot\tfrac12=2\le 2\). Feasible, value \(2\).
  3. Check it is optimal. The constraint at \(u\) caps the objective at \(2\), and this point hits \(2\).
  4. Round and fail. Every \(x_e=\tfrac12\ge\tfrac12\), so all become \(1\); now \(u\) has degree \(4>2\), which is not a semi-matching.

The rounding turned a legal fractional optimum into an illegal integer point, so the rule does not always work — whenever many edges crowd one vertex, rounding them all up breaks its cap.
