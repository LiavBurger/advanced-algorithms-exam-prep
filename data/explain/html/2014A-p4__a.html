Goal write the minimum-weight dominating set problem as an ILP.

Strategy one binary variable per vertex for membership, a cost objective, and one constraint per vertex saying it is dominated.

Key idea vertex \(v\) is dominated exactly when at least one vertex of its closed neighborhood \(N(v)\cup\{v\}\) is chosen.

Why this move "every vertex must have someone chosen nearby" is a covering condition, which turns directly into a \(\sum\ge 1\) constraint per vertex.

  1. Variables. \(x_v\in\{0,1\}\), with \(x_v=1\) meaning \(v\in S\). A \(0/1\) vector is the same as a subset \(S\subseteq V\).
  2. Objective. The weight of \(S\) is \(\sum_{v\in V}w_v x_v\) (unchosen vertices drop out), and we minimize it.
  3. Domination constraint. For every \(v\): \(\sum_{u\in N(v)\cup\{v\}}x_u\ge 1\). With \(0/1\) values this holds exactly when \(v\) itself or one of its neighbors is chosen.
  4. The ILP. \(\min\sum_{v}w_v x_v\) s.t. \(\sum_{u\in N(v)\cup\{v\}}x_u\ge 1\ \forall v,\ x_v\in\{0,1\}\). Every feasible \(0/1\) vector is a dominating set of that weight and vice versa, so the ILP optimum is the minimum weight dominating set.
