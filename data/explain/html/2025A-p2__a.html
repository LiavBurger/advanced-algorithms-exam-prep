Goal compute the dual of \((P)\): \(\min\, c^Tx\) s.t. \(Ax\ge c,\ x\ge 0\), with \(A\) symmetric.

Strategy rewrite \((P)\) in the equality "standard form" the dual recipe applies to, read off the dual mechanically, then simplify using \(A^T=A\).

Key idea because \(A\) is symmetric, the dual comes back looking almost exactly like the primal — same \(A\), same \(c\).

Why this move dualizing is just "plug into the recipe," but the recipe needs a fixed template (equalities with non-negative variables), so the real work is getting \((P)\) into that template first.

  1. Flip the inequalities. Multiply \(Ax\ge c\) by \(-1\) to get \(-Ax\le -c\), so every constraint faces the same way.
  2. Add slack to reach equalities. Introduce \(s\ge 0\) with \(-Ax+Is=-c\). Now \((P)\) reads \(\min c^Tx\) s.t. \(-Ax+Is=-c,\ x,s\ge 0\).
  3. Apply the dual recipe. For \(\min\{b^\top\xi: M\xi=d,\ \xi\ge0\}\) the dual is \(\max\{d^\top y: M^\top y\le b,\ y\text{ free}\}\). With \(\xi=(x,s)\), \(M=(-A\mid I)\), \(d=-c\), this gives \(-A^\top y\le c\) and \(y\le 0\), objective \(\max\,(-c)^\top y\).
  4. Use symmetry. Since \(A^T=A\), the \(x\)-constraint is \(-Ay\le c\). So the dual is \(\max\,-c^Ty\) s.t. \(-Ay\le c,\ y\le 0\).
  5. Tidy with a sign flip. Set \(z=-y\ge 0\); then \(-c^Ty=c^Tz\) and \(-Ay=Az\), giving the clean form \[(D)\quad \max\; c^Tz \quad\text{s.t.}\quad Az\le c,\ z\ge 0.\]

Notice \((D)\) is the mirror image of \((P)\): same \(A\), same \(c\), just \(\max\) with \(\le\) instead of \(\min\) with \(\ge\). Thanks to symmetry the problem is essentially self-dual — exactly what part (b) leans on.
