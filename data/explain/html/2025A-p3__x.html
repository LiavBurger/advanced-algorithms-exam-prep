Goal Write an integer linear program for Minimum Makespan: assign \(n\) jobs to \(m\) machines minimizing the heaviest machine's load.

Strategy Use \(0/1\) assignment variables, plus one extra variable \(T\) that upper-bounds every machine's load, and minimize \(T\).

Key idea "Minimize the maximum" isn't linear directly, but bounding every load by a single variable \(T\) and minimizing \(T\) achieves the same thing.

Why this move The standard trick for a min-max objective is to introduce an auxiliary ceiling variable and push all the maxima under it.

  1. Assignment variables. For each job \(i\) and machine \(j\) take \(x_{i,j}\in\{0,1\}\), with \(x_{i,j}=1\) meaning job \(i\) runs on machine \(j\).
  2. Makespan variable. Add \(T\), representing the load of the last-finishing machine, which we minimize.
  3. The program. \[ \begin{aligned} \text{minimize}\quad & T\\ \text{s.t.}\quad & \sum_{j=1}^{m} x_{i,j}=1 && 1\le i\le n,\\ & \sum_{i=1}^{n} x_{i,j}\,p_i \le T && 1\le j\le m,\\ & x_{i,j}\in\{0,1\} && \forall i,j. \end{aligned} \]

The first constraints put each job on exactly one machine; the second say every machine's load is at most \(T\). Minimizing \(T\) drives it down to the true maximum load, so the optimal \(T\) is the minimum makespan.
