The hint links rank to determinants: a matrix has rank \(\ge r\) iff it has some \(r\times r\) submatrix with nonzero determinant. The randomized algorithm exploits this together with Schwartz–Zippel.

Algorithm. For each starred entry \((i,j)\), independently replace it with a uniformly random integer from \(\{1,2,\dots,10n\}\); compute the rank \(r\) of the resulting numeric matrix (Gaussian elimination, polynomial time) and return \(r\).
  1. The answer we want. Let \(k\) be the number of stars, and for \(c\in\mathbb R^k\) let \(A_c\) be \(A\) with the stars set to \(c\). Let \(r'=\max_{c\in\mathbb R^k}\mathrm{rank}(A_c)\) be the true optimum, achieved by some \(c_0\). Since \(\mathrm{rank}(A_{c_0})=r'\), there exist row set \(T_1\) and column set \(T_2\) with \(|T_1|=|T_2|=r'\) whose \(r'\times r'\) submatrix has nonzero determinant.
  2. Set up a polynomial. Replace the stars by variables \(x_1,\dots,x_k\). The determinant of that \(T_1,T_2\) submatrix is a polynomial \(P(x_1,\dots,x_k)\). It is not the zero polynomial, because evaluating it at \((x_1,\dots,x_k)=c_0\) gives the nonzero determinant from step 1.
  3. Bound the degree. Each matrix entry is either a constant or a single variable, so it has degree \(\le1\); the determinant of an \(r'\times r'\) matrix is a sum of products of \(r'\) entries, hence \(\deg P\le r'\le n\).
  4. Schwartz–Zippel. For a nonzero polynomial of degree \(d\) evaluated at points chosen independently and uniformly from a set of size \(N\), the probability of hitting a root is \(\le d/N\). With \(d\le n\) and \(N=10n\), \[ \Pr_{\alpha_1,\dots,\alpha_k\in\{1,\dots,10n\}}\!\left[P(\alpha_1,\dots,\alpha_k)=0\right]\le\frac{n}{10n}=\frac1{10}.\]

Correctness & error. With probability \(\ge9/10\) the random substitution keeps that submatrix determinant nonzero, so the numeric matrix has rank \(\ge r'\); and it can never exceed \(r'\), which is the maximum over all real substitutions. Hence the algorithm returns exactly \(r'\) with probability at least \(9/10\) (error \(\le1/10\)). Running time is polynomial, since computing a rank via Gaussian elimination is polynomial.
