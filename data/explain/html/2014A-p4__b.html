Goal give an instance where the LP relaxation's optimum is strictly below the integer optimum.

Strategy use the \(4\)-cycle \(C_4\) with all weights \(1\); set three vertices to \(\tfrac12\) and one to \(0\).

Key idea fractional values let domination be "shared" across a closed neighborhood, meeting \(\sum\ge 1\) more cheaply than any integer choice can.

Why this move a short even cycle is the classic small gap example — each closed neighborhood overlaps its neighbors, so half-values pile up to exactly \(1\).

  1. Setup. On \(C_4\), each vertex has \(2\) neighbors, so its closed neighborhood has \(3\) vertices. Set one vertex to \(x=0\) and the other three to \(x=\tfrac12\).
  2. Feasibility. The zero vertex sees its two \(\tfrac12\) neighbors: \(0+\tfrac12+\tfrac12=1\ge 1\). Each \(\tfrac12\) vertex has at least two \(\tfrac12\) vertices in its closed neighborhood, so its sum is \(\ge 1\). All constraints hold.
  3. LP cost. \(3\cdot\tfrac12+0=\tfrac32\), so the LP optimum is \(\le\tfrac32\).
  4. Integer cost. One vertex dominates only itself and its \(2\) neighbors — \(3\) of the \(4\) vertices, missing the opposite corner — so a dominating set needs \(2\) vertices, cost \(2\). Hence LP \(=\tfrac32<2=\) ILP: not integral.
