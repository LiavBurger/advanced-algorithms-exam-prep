We now read the integer version of DLP1 — the dual — as a graph problem. Adding integrality means \(y_{uv}\in\{0,1\}\) for every edge, so an assignment picks a subset of edges \(M=\{uv : y_{uv}=1\}\).

  1. The variables. \(y_{uv}\in\{0,1\}\) indicates whether edge \(uv\) is selected. The point is thus a choice of an edge subset \(M\subseteq E\).
  2. The constraints. For each vertex \(v\), \(\sum_{u\in N(v)} y_{uv}\le 1\) says that among the edges incident to \(v\), at most one is selected. Equivalently, no two selected edges share an endpoint — exactly the definition of \(M\) being a matching.
  3. The objective. Maximizing \(\sum_{uv\in E} y_{uv}\) maximizes \(|M|\), the number of selected edges.
So the integer program corresponding to DLP1 asks for the largest set of pairwise non-adjacent edges: this is the maximum matching problem. It is the natural dual counterpart to the minimum vertex cover of part (a) — every edge in a matching must be covered by a distinct vertex, so matching size lower-bounds cover size.
