Goal build, in poly time, a bipartite graph that is \((C\log n,\tfrac1{100})\)-balanced with probability \(\ge 0.9\).

Strategy include each possible edge independently with probability \(\tfrac12\); show every subset pair has close-to-ideal edge count via Chernoff, then union-bound over all pairs.

Key idea for fixed \(S,T\) of size \(m\), \(|E(S,T)|\) is a sum of \(m^2\) independent coin flips with mean \(\tfrac12 m^2\), so it concentrates tightly; the threshold \(k=C\log n\) makes each subset's tiny failure probability survive the huge number of subsets.

Why this move "for every pair of subsets, an edge count near its average" is a demand for concentration over exponentially many events — exactly the Chernoff-plus-union-bound pattern.

  1. Algorithm & expectation. For every pair \((i,j)\in L\times R\), add the edge independently with probability \(\tfrac12\). Let \(X_{i,j}\) be an indicator for the event that \((i,j)\) is an edge, so its expectation is \(\tfrac12\). For fixed \(S,T\) of size \(m\), \(|E(S,T)|=\sum_{i\in S,j\in T}X_{i,j}\) has mean \(\tfrac12 m^2\) by linearity.
  2. Chernoff for one pair. The allowed deviation \(\tfrac1{100}m^2\) is a constant fraction of the mean, so Chernoff gives a fast-shrinking tail: \(\Pr\big[\,\big||E(S,T)|-\tfrac12 m^2\big|\ge\tfrac1{100}m^2\big]\le e^{-c m^2}\) for an absolute constant \(c>0\).
  3. Union bound over pairs of size \(m\). There are \(\binom{n}{m}^2\le n^{2m}\) choices of \(S,T\), so the chance any of them fails is \(\le n^{2m}e^{-c m^2}=e^{2m\ln n-c m^2}\).
  4. Choose \(C\). Writing the exponent as \(m(2\ln n-cm)\): once \(m\ge C\log n\) with \(C\) large enough, \(cm\) beats \(2\ln n\), driving this below \(\tfrac1{10n}\) for every such \(m\).
  5. Union bound over sizes. Summing over the at most \(n\) values \(m=k,\dots,n\) gives total failure \(\le n\cdot\tfrac1{10n}=\tfrac1{10}\). So with probability \(\ge 0.9\) the graph is balanced, and generating it is just \(O(n^2)\) coin flips — poly time. The takeaway: random edges are balanced almost surely, and requiring \(m\ge C\log n\) is exactly what lets one bound beat all \(n^{2m}\) subsets at once.
