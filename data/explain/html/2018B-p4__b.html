Claim The expectation is over the algorithm's random pivot choices.

Strategy Ask what probability space \(T(n)\) lives in, and name its only source of randomness.

Key idea The input is treated as fixed; the pivots are the coins, so averaging is over pivot sequences.

Why this move This is the direct follow-up to part (a): whenever we write \(\mathbb{E}[T(n)]\) we must say what is random, and here it is only the pivots.

  1. Input contributes nothing. The array is fixed and arbitrary; it carries no randomness.
  2. Pivots are the coins. At each recursive call the algorithm picks a pivot uniformly at random, and those choices decide which side we recurse on, hence how much work happens.
  3. State the answer. So \(T(n)\) is a function of the pivot sequence, and \(\mathbb{E}[T(n)]\) averages \(T(n)\) over all equally likely pivot sequences — the expectation is over the pivot choices.
