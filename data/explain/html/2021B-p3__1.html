Goal Design a \(2/3\)-approximation for MAX-3-COL: color \(V\) with \(\{a,b,c\}\) to maximize the total weight of legally colored edges (endpoints differently colored).

Strategy Think of the coloring as a partition of \(V\) into three classes \(A,B,C\), and place vertices one at a time, each into the class that adds the least illegal weight.

Key idea Putting \(v\) in a class makes exactly its edges to already-placed vertices of that class illegal, so greedily choosing the lightest of the three classes controls the damage.

Why this move This is the three-color version of the two-color greedy max-cut from Homework 2; whenever "maximize agreeing/differing edges" appears, sequential greedy placement is the natural reach.

  1. Initialize. Start with three empty color classes \(A=B=C=\varnothing\).
  2. Process in order. Go through the vertices in an arbitrary fixed order. For the current vertex \(v\) and each class \(X\in\{A,B,C\}\), let \(w(v,X)\) be the total weight of edges from \(v\) to vertices already in \(X\).
  3. Greedy placement. Add \(v\) to a class \(X\) minimizing \(w(v,X)\) — this makes only the edges from \(v\) into \(X\) illegal, so we add as little illegal weight as possible.
  4. Output the coloring. Once all vertices are placed, set \(c(v)=a\) for \(v\in A\), \(c(v)=b\) for \(v\in B\), \(c(v)=c\) for \(v\in C\). Coloring greedily by the lightest class is the whole algorithm.
