When do I reach for this?

Every exam has a "write an integer program for \(X\)" question, then follow-ups: relax it, and ask whether the relaxation is integral. The mental model: an IP is an LP plus "\(x\) integer", which is NP-hard; the LP relaxation is a poly-time lower bound (for min) that is sometimes exactly right — and TUM is the property that tells you when.

  • "Model \(X\) as an IP / BIP" → binary \(x_i\in\{0,1\}\) plus coverage / capacity / conflict constraints.
  • "Write the LP relaxation" → replace \(x\in\{0,1\}\) with \(0\le x\le 1\) (drop integrality).
  • "Is the relaxation integral / what is the integrality gap?" → ask whether the matrix is TUM; if not, find a fractional optimum.
  • "Why not just solve the IP directly?" → ILP is NP-hard; a poly-time solver \(\Rightarrow\) P \(=\) NP.

Core tools

IP BUILDING BLOCKS
"cover \(u\)" \(\to\ \sum_{i\in S(u)}x_i\ge 1\); "not both \(u,v\)" (conflict) \(\to\ x_u+x_v\le 1\); "exactly one bin" \(\to\ \sum_j x_{ij}=1\); "capacity" \(\to\ \sum_i w_i x_{ij}\le B\). \[ \text{ILP}=\text{LP}+\{x\in\mathbb{Z}^n\},\quad\text{NP-hard.} \] "model X as an IP/BIP"
LP RELAXATION & INTEGRALITY GAP
Relax \(x\in\{0,1\}\) to \(0\le x\le 1\). For a minimization, \[ \text{LP-OPT}\ \le\ \text{IP-OPT},\qquad \text{gap}=\frac{\text{IP-OPT}}{\text{LP-OPT}}. \] The relaxation is a poly-time bound; the gap measures how much you lose. "write the relaxation", "give the integrality gap"
TOTAL UNIMODULARITY (TUM)
Integer \(A\) is TUM if every square submatrix has \(\det\in\{0,+1,-1\}\). \[ A\text{ TUM},\ b\text{ integral}\ \Rightarrow\ \text{every vertex of }\{Ax=b,x\ge0\}\text{ is integral.} \] Then the LP relaxation already returns an integer optimum, so it solves the IP in poly time. "is the relaxation exact?"

Why TUM works, and the classic cases

Theorem A vertex has a basis \(B\) with \(x_B=A_B^{-1}b,\ x_N=0\). By Cramer's rule each \(x_j\) is a ratio of determinants; if \(A\) is TUM then \(\det A_B=\pm1\) and \(b\) is integral, so \(x_B\) is an integer vector. Hence all vertices are integral.
Definition Bipartite-matching and \(s\)-\(t\) flow constraint matrices are TUM. Consequences you should recognize on sight: fractional bipartite matching \(=\) integral matching; Max-Flow \(=\) Min-Cut; Max Bipartite Matching \(=\) Min Vertex Cover (König). General vertex cover, dominating set, set cover, independent set are not TUM.

Worked example — the thinking

2014A P4. "Write minimum-weight dominating set as an ILP, then give an instance where the LP relaxation is fractional."

  1. Variables: one binary \(x_v\) per vertex (\(1=\) in the set). Objective \(\min\sum_v w_v x_v\).
  2. Domination constraint: every vertex \(u\) must be covered by itself or a neighbor, i.e. \(x_u+\sum_{v\in N(u)}x_v\ge 1\). Add \(x_v\in\{0,1\}\).
  3. Relax: \(x_v\in\{0,1\}\to 0\le x_v\le 1\).
  4. Fractional witness: on a symmetric graph (a triangle / small clique) the LP can set every \(x_v=\tfrac12\); each covering constraint sums to \(\ge 1\), and the LP pays less than any integral solution. That difference is the integrality gap, and it exists precisely because this matrix is NOT TUM.

Same covering shape recurs in 2025B P2 (weighted set cover): "formulate \(\to\) relax \(\to\) round" gives an \(f\)-approximation by threshold-rounding at \(1/f\) (take every \(x_j\ge 1/f\)); each element of frequency \(\le f\) is still covered, and cost grows by at most \(f\). 2024A P4 (Max-SAT), 2024C P4 (bin packing), 2023A P2 (dominating set) are pure modeling. 2024B P1 is the complexity T/F: a poly-time ILP solver would settle independent set, so P \(=\) NP.

Common traps

Do not assume the relaxation is always integral — it is guaranteed only when the matrix is TUM (bipartite matching yes; dominating set / general vertex cover / set cover no). — "All entries are \(0/1\)" does NOT imply TUM; you need every square-submatrix determinant in \(\{0,\pm1\}\). — Rounding a fractional LP solution can break feasibility; naive thresholds do not always give a feasible integral point (2021A/2021B) — justify why your rounding stays feasible. — Do not drop the objective sense or forget that IP variables are integers, not merely bounded.

Checklist — IP + relaxation

  1. Pick variables (usually binary \(x_i\), or \(x_{ij}\) for assignments).
  2. Write objective and constraints from the building blocks (cover / capacity / conflict); justify each.
  3. Relax: \(x\in\{0,1\}\to 0\le x\le 1\).
  4. Is the matrix TUM with integral \(b\)? If yes → relaxation is exact, poly-time.
  5. If not TUM, expect an integrality gap: find a symmetric all-halves fractional witness, or round for an approximation and prove it stays feasible.
