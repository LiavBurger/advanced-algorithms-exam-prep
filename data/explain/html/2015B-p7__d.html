Goal describe a \(100\)-vertex graph whose maximum independent set has size exactly \(1\).

Strategy take the clique \(K_{100}\) — every pair of vertices joined by an edge.

Key idea if every pair is adjacent, no two vertices can sit together in an independent set, so an independent set can hold at most one vertex.

Why this move we want independence forced to be tiny, and the densest possible graph — the clique — makes every pair an obstacle.

  1. The graph. Let \(G=K_{100}\), the complete graph on \(100\) vertices.
  2. At most one vertex. Any two distinct \(u,v\) are adjacent, so any set with two vertices contains an edge and fails independence.
  3. One is achievable. A single vertex is trivially independent, so the maximum is exactly \(1\). (Together with part (c): here the LP optimum is \(\ge 50\) while the ILP optimum is \(1\) — a large integrality gap.)
