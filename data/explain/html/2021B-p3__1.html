We build a partition of \(V\) into three sets \(A,B,C\) (to be colored \(a,b,c\)), placing the vertices one at a time so that each vertex adds as little illegal weight as possible.

  1. Initialize \(A=B=C=\varnothing\).
  2. Go over the vertices in an arbitrary order. For the current vertex \(v\) and each set \(X\in\{A,B,C\}\), let \(w(v,X)\) be the total weight of edges connecting \(v\) to vertices already placed in \(X\).
  3. Add \(v\) to a set \(X\in\{A,B,C\}\) for which \(w(v,X)\) is minimal.
  4. After all vertices are placed, output the coloring \(c(v)=a\) for \(v\in A\), \(c(v)=b\) for \(v\in B\), and \(c(v)=c\) for \(v\in C\).

An edge is colored legally exactly when its endpoints are in different sets. When we place \(v\), the only edges it colors illegally are those to already-placed vertices of the same set, whose weight is \(w(v,X)\); by choosing the set of minimal \(w(v,X)\) we add the least possible illegal weight at each step. The algorithm runs in polynomial time, since each vertex is handled once and we only sum edge weights from \(v\) to the three groups.

Intuition. Color the vertices one by one, each time joining the color group it shares the least edge weight with.
