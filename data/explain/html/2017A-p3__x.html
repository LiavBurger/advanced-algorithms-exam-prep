True: the described algorithm is a \(1.5\)-approximation for metric Path-TSP. We show the Euler path exists, bound the tree cost by OPT, bound the matching cost by \(\mathrm{OPT}/2\) using two candidate matchings, and then combine and shortcut.

Euler path exists. The set \(S\) is not empty, since every leaf of \(T\) has degree \(1\), hence is odd. Adding the matching \(M\) flips the parity of every matched vertex, so in \(T\cup M\) the only vertices that remain odd are the two unmatched vertices of \(S\). A connected graph with exactly two odd-degree vertices has an Euler path, so \(T\cup M\) has one.

Tree cost. OPT is a spanning path, which in particular is a spanning tree, and \(T\) is a minimum spanning tree, so \(\mathrm{cost}(T)\le \mathrm{cost}(\mathrm{OPT})\).

Matching cost. We proved in class that \(|S|\) is even; write its vertices as \(v_1,v_2,\dots,v_{2k}\) in the order they appear along OPT. Let \(M_1\) pair \(v_1v_2, v_3v_4,\dots,v_{2k-3}v_{2k-2}\) and let \(M_2\) pair \(v_2v_3, v_4v_5,\dots,v_{2k-2}v_{2k-1}\). Each of \(M_1,M_2\) leaves exactly two vertices of \(S\) unmatched, so each is a valid candidate for the kind of matching \(M\) the algorithm computes. Now OPT contains the disjoint subpaths \(v_1\!\to\!v_2, v_2\!\to\!v_3,\dots,v_{2k-1}\!\to\!v_{2k}\), and by the triangle inequality each matching edge \(v_av_b\) costs at most the OPT-subpath between them. Since \(M_1\) and \(M_2\) together use each of these subpaths once, \(\mathrm{cost}(M_1)+\mathrm{cost}(M_2)\le \mathrm{OPT}\). Because \(M\) is a minimum-cost such matching, \(\mathrm{cost}(M)\le\min(\mathrm{cost}(M_1),\mathrm{cost}(M_2))\le \mathrm{OPT}/2\).

Combine. Therefore \(\mathrm{cost}(T\cup M)=\mathrm{cost}(T)+\mathrm{cost}(M)\le \mathrm{OPT}+\mathrm{OPT}/2=\tfrac32\mathrm{OPT}\). Shortcutting repeated vertices in the Euler path only removes edges and, by the triangle inequality, never increases cost, so the resulting Hamilton path costs at most \(\tfrac32\mathrm{OPT}\). The algorithm is a \(1.5\)-approximation.

Intuition. Walking the odd vertices in OPT's order splits OPT into subpaths that two alternating matchings cover once each, so the cheaper one costs at most \(\mathrm{OPT}/2\).
