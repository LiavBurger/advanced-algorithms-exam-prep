Goal give an efficient \(f\)-approximation for set cover, where every element lies in at most \(f\) sets.

Strategy solve the dual \((D)\), take the tight sets as the cover (valid by part b), then bound its cost against the LP optimum using frequency \(f\).

Key idea each chosen set's cost equals the sum of its elements' dual values, and when you re-sum by element, each \(y^{*}_j\) is counted at most \(f\) times.

Why this move tightness turns costs into dual sums, and swapping the summation order is the natural way to expose the frequency \(f\).

  1. Algorithm. Solve \((D)\) for an optimal \(y^{*}\) (an LP, so polynomial time) and output \(C=\) the sets whose constraint is tight. By part (b) this is a valid cover.
  2. Cost via tightness. Each \(S_i\in C\) is tight, so \(c_i=\sum_{j\in S_i}y^{*}_j\), and \[\sum_{S_i\in C}c_i=\sum_{S_i\in C}\sum_{j\in S_i}y^{*}_j.\]
  3. Swap the order. Grouping by element, each \(y^{*}_j\) is counted once per chosen set containing \(j\): \[\sum_{S_i\in C}\sum_{j\in S_i}y^{*}_j=\sum_{j=1}^n \bigl|\{S_i\in C:j\in S_i\}\bigr|\,y^{*}_j.\]
  4. Use frequency \(f\). Element \(j\) is in at most \(f\) sets, so each coefficient is \(\le f\), and since \(y^{*}_j\ge0\), \(\sum_{S_i\in C}c_i\le f\sum_j y^{*}_j=f\cdot\mathrm{LPOPT}\le f\cdot\mathrm{OPT}\) (the last step because the relaxation lower-bounds the integer optimum). So the cover costs at most \(f\) times optimal — an efficient \(f\)-approximation.
