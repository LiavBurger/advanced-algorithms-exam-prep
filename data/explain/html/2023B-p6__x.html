The algorithm is as simple as possible: color each element \(i\in\{1,\dots,n\}\) independently, uniformly at random red or blue. We show that with high probability this random coloring makes every set have small discrepancy, using the Chernoff bound on each set and a union bound over the \(m\) sets.

For each element \(i\), let \(X_i\) be a random variable equal to \(+1\) if \(i\) is colored red and \(-1\) if \(i\) is colored blue. The colors are chosen uniformly, so \(\mathbb{E}[X_i]=0\), and for a set \(S\) the discrepancy is exactly

\[ \mathrm{Disc}_h(S)=\Big|\,(\#\text{red in }S)-(\#\text{blue in }S)\,\Big|=\Big|\sum_{i\in S}X_i\Big|. \]

Fix one set \(S\in\mathcal F\) and let \(s=|S|\); note \(s\le n\). Since \(s\le n\) we have \(C\sqrt{n\log m}\ge C\sqrt{s\log m}\), so exceeding the larger threshold implies exceeding the smaller one. Thus, applying the Chernoff bound to the sum of the \(s\) independent \(\pm 1\) variables in \(S\),

\[ \Pr\!\left[\mathrm{Disc}_h(S)\ge C\sqrt{n\log m}\right] \le \Pr\!\left[\Big|\sum_{i\in S}X_i\Big|\ge C\sqrt{s\log m}\right] \le e^{-\Omega\!\left(C^2 s\log m/s\right)} = e^{-\Omega(C^2\log m)}. \]

By picking the absolute constant \(C\) large enough (it does not depend on \(n\) or \(m\)), this probability drops below \(\dfrac{1}{10\,m^2}\); the tail shrinks fast as \(C\) grows.

Finally, take a union bound over all \(m\) sets in \(\mathcal F\). The probability that some set \(S\) has \(\mathrm{Disc}_h(S)\ge C\sqrt{n\log m}\) is at most

\[ m\cdot\frac{1}{10\,m^2}=\frac{1}{10\,m}. \]

So with probability at least \(1-\dfrac{1}{10m}\) every set satisfies \(\mathrm{Disc}_h(S)\le C\sqrt{n\log m}\), i.e. \(\mathrm{Disc}_h(\mathcal F)\le C\sqrt{n\log m}\) with high probability, as required. The algorithm runs in \(O(n)\) time since it just flips one coin per element.

Intuition. Random \(\pm1\) colors mostly cancel, so each set's imbalance stays around \(\sqrt{s}\), and Chernoff plus a union bound keep all \(m\) sets small at once.
