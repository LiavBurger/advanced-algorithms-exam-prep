Start from the LP relaxation of the program in (a): replace \(x_i\in\{0,1\}\) by \(0\le x_i\le 1\). The upper bounds \(x_i\le 1\) are redundant here, because we minimize and every constraint has nonnegative coefficients, so no optimal \(x_i\) ever needs to exceed \(1\); we drop them and keep only \(x_i\ge 0\). The relaxed primal is

\[\min\ \sum_{i\in S}x_i\quad\text{s.t.}\quad \sum_{i\in D}x_i\ge 1\ \ \text{for all }D\in C,\qquad x_i\ge 0\ \ \text{for all }i\in S.\]

Now take the dual. There is one primal constraint for each \(D\in C\), so we introduce one dual variable \(y_D\) for each \(D\in C\). Since the primal is a minimization with "\(\ge\)" constraints and nonnegative variables, the dual is a maximization with "\(\le\)" constraints and nonnegative variables.

The dual objective uses the primal right-hand sides, which are all equal to \(1\), giving \(\max\ \sum_{D\in C}y_D\). The dual constraint for primal variable \(x_i\) reads off the coefficient of \(x_i\) across the primal constraints: \(x_i\) appears (with coefficient \(1\)) in the constraint of \(D\) exactly when \(i\in D\), and the primal objective coefficient of \(x_i\) is \(1\), so the constraint is \(\sum_{D:\,i\in D}y_D\le 1\). The dual is

\[\max\ \sum_{D\in C}y_D\quad\text{s.t.}\quad \sum_{D:\,i\in D}y_D\le 1\ \ \text{for all }i\in S,\qquad y_D\ge 0\ \ \text{for all }D\in C.\]

Intuition. One weight per subset, maximizing total weight while no single element is loaded past one.
