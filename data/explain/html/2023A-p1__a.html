Claim False: the simplex algorithm from class never moves to a different vertex having the same objective value.

Strategy Recall the pivot rule: the algorithm only relocates when the move strictly improves the objective.

Key idea A "sideways" step to an equal-value vertex is never taken; the only place equal values show up is a degenerate pivot, and that keeps you at the same vertex.

Why this move The statement sounds like degeneracy, so the trigger is to separate "the basis changed" from "the vertex changed" — degeneracy changes the former without the latter.

  1. The pivot rule. As presented in class, simplex leaves its current vertex only when it can strictly decrease the objective function.
  2. Degenerate case. When the solution is degenerate, a pivot may swap which variables are in the basis, but the actual point (vertex) does not move, so its value is unchanged. This is not a move to a different vertex.
  3. So equal-value moves don't happen. Either the objective strictly drops and you reach a genuinely new, better vertex, or the vertex stays put during a degenerate basis change. There is no step to a different vertex with the same value.
  4. Conclusion. The described behavior contradicts the rule, so the statement is false — here a different vertex always means a strictly better value.
