We prove by induction on \(n\) that \(E[T(n)]\le cn\) for a constant \(c\) chosen below; this gives \(E[T(n)]=O(n)\).

Let \(b\) be the constant hidden in the \(\Theta(n)\) partition cost, so that term is at most \(bn\).

Base case: let \(d\) be a constant with \(T(1)\le d\). If we choose \(c\ge d\), then \(E[T(1)]\le d\le c\cdot 1\), so the base case holds.

Inductive assumption: assume \(E[T(n')]\le cn'\) for every \(n'

Inductive step: using the recurrence from part (c) and then the assumption on each \(E[T(k)]\le ck\), \[E[T(n)]\le \frac{2}{n}\sum_{k=n/2}^{n-1}E[T(k)]+bn\le \frac{2}{n}\sum_{k=n/2}^{n-1}ck+bn.\] The sum \(\sum_{k=n/2}^{n-1}ck\) is an arithmetic series; by the given fact it equals its first plus last term times half the number of terms, which is at most \(\dfrac{\left(\frac{cn}{2}+cn\right)\cdot\frac{n}{2}}{2}\). Therefore \[E[T(n)]\le \frac{2}{n}\cdot\frac{\left(\frac{cn}{2}+cn\right)\frac{n}{2}}{2}+bn = n\left(\frac{3c}{4}+b\right)\le cn,\] where the last inequality holds as long as \(\frac{3c}{4}+b\le c\), i.e. \(c\ge 4b\).

So choosing \(c=\max(d,4b)\) makes every step go through, and \(E[T(n)]\le cn\) for all \(n\). Hence \(E[T(n)]=O(n)\).

Intuition. Recursing on halves of size at least \(n/2\) only pulls in about \(\tfrac34\) of the work, leaving room for the linear partition cost, so the total stays linear.
