Goal give an efficient randomized algorithm for Matrix Completion (max achievable rank), with correctness, runtime, and error probability.

Strategy replace each star by a random integer and return the rank; argue via Schwartz–Zippel that a random substitution almost surely realizes the best possible rank.

Key idea the max rank is achievable iff some submatrix determinant can be made nonzero, and that determinant is a low-degree polynomial in the starred entries, so a random plug-in rarely hits its roots.

Why this move the hint "determinants and rank" plus starred entries acting as variables is the classic signal to reach for Schwartz–Zippel.

  1. Algorithm. For each starred entry, independently plug in a uniform random integer from \(\{1,\dots,10n\}\); compute the rank \(r\) of the numeric matrix by Gaussian elimination and return \(r\). This is polynomial time.
  2. Name the target. Let \(k\) be the number of stars and \(r'=\max_{c\in\mathbb R^k}\mathrm{rank}(A_c)\) the true optimum, achieved by some \(c_0\). Since \(\mathrm{rank}(A_{c_0})=r'\), there are rows \(T_1\) and columns \(T_2\), \(|T_1|=|T_2|=r'\), whose \(r'\times r'\) submatrix has nonzero determinant.
  3. Build the polynomial. Treat the stars as variables \(x_1,\dots,x_k\); the determinant of that submatrix is a polynomial \(P\). It is not identically zero, since at \(x=c_0\) it equals the nonzero determinant above. Each entry has degree \(\le1\), so \(\deg P\le r'\le n\).
  4. Schwartz–Zippel and conclusion. A nonzero degree-\(d\) polynomial evaluated at uniform points from a size-\(N\) set is zero with probability \(\le d/N\); here \(d\le n\), \(N=10n\), so the failure probability is \(\le \tfrac{n}{10n}=\tfrac1{10}\). Thus with probability \(\ge9/10\) the random matrix still has that nonzero determinant, giving rank \(\ge r'\); and rank can never exceed \(r'\), so the algorithm returns exactly \(r'\). Error \(\le 1/10\), runtime polynomial.
