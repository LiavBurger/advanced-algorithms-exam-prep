Claim this ILP is the maximum independent set problem.

Strategy read what each variable and constraint says in graph language, and match it to a known problem.

Key idea a \(0/1\) value \(x_v\) is just a yes/no for "is \(v\) chosen", so a solution is a vertex subset \(S\).

Why this move whenever you see one binary variable per vertex plus a per-edge constraint, translate literally — the graph problem falls right out.

  1. Objective. \(\max\sum_{v\in V}x_v\) counts the chosen vertices, so we want a set \(S\) as large as possible.
  2. Edge constraint. \(x_u+x_v\le 1\) for every edge \((u,v)\in E\) forbids \(x_u=x_v=1\): the two endpoints of an edge can't both be in \(S\).
  3. Name it. "no edge has both endpoints inside \(S\)" is exactly the definition of an independent set, and we maximize its size — the maximum independent set.
