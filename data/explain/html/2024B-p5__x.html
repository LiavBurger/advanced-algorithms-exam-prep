We want a minimum-weight representative set \(H\subseteq V\) — one meeting every \(T_j\) — where each \(|T_j|\le d\). This is a hitting-set problem, and we \(d\)-approximate it by relaxing and rounding the given integer program \(\min\sum_i w_i x_i\) s.t. \(\sum_{i\in T_j}x_i\ge 1\ \forall j,\ x_i\in\{0,1\}\).

  1. Relax and solve. Replace \(x_i\in\{0,1\}\) by \(0\le x_i\le 1\) and solve the LP in polynomial time; let \(x^{*}\) be an optimal fractional solution, with value \(\text{LPOPT}=\sum_i w_i x_i^{*}\).
  2. Round. For each \(i\), set \(x_i=1\) if \(x_i^{*}\ge 1/d\), else \(x_i=0\); let \(H\) be the set whose characteristic vector is \(x\).
  3. \(H\) is representative. Fix \(T_j\). The constraint \(\sum_{i\in T_j}x_i^{*}\ge 1\) is a sum of at most \(|T_j|\le d\) terms, so their average is at least \(1/d\); hence some \(i\in T_j\) has \(x_i^{*}\ge 1/d\), giving \(x_i=1\) and \(i\in H\). Thus \(H\) hits every \(T_j\).
  4. Weight bound. For every \(i\), \(x_i\le d\,x_i^{*}\): if \(x_i=0\) this holds as \(x_i^{*}\ge 0\); if \(x_i=1\) then by construction \(x_i^{*}\ge 1/d\), so \(d\,x_i^{*}\ge 1=x_i\).
\[w(H)=\sum_{i=1}^{n}w_i x_i\ \le\ d\sum_{i=1}^{n}w_i x_i^{*}\ =\ d\cdot\text{LPOPT}\ \le\ d\cdot\text{OPT}.\]

The first inequality multiplies \(x_i\le d\,x_i^{*}\) by \(w_i\ge 0\) and sums; the last uses \(\text{LPOPT}\le\text{OPT}\), which holds because every integer solution is LP-feasible, so relaxing only lowers the minimum. Hence \(H\) is a representative set of weight at most \(d\) times optimal — a polynomial-time \(d\)-approximation.
