The converse fails because the degree constraints only enforce "in-degree \(1\) and out-degree \(1\) at every vertex" — they say nothing about the selected edges forming a single connected tour. A union of several disjoint cycles satisfies the same degree constraints.

  1. Take a graph on, say, six vertices consisting of two vertex-disjoint directed triangles: cycle \(1\to2\to3\to1\) and cycle \(4\to5\to6\to4\). Set \(x_{u,v}=1\) on these six edges and \(0\) elsewhere.
  2. Check the constraints: in each triangle every vertex has exactly one incoming and one outgoing chosen edge. So for every vertex the incoming sum is \(1\) and the outgoing sum is \(1\), and all variables are \(0/1\). This is a feasible IP solution.
  3. But this edge set is not a Hamiltonian cycle: a Hamiltonian cycle is a single cycle through all vertices, whereas here the vertices split into two separate cycles. The subgraph is not even connected, so it cannot be one cycle covering all six vertices.
This is the classic "subtour" phenomenon: the degree constraints permit any collection of vertex-disjoint cycles that together cover all vertices, not just one grand cycle. That is exactly the gap part (c) fixes with subtour-elimination constraints.
