Claim reading the dual of (e) as an ILP gives the minimum edge cover problem.

Strategy force \(y_{uv}\in\{0,1\}\) and translate each part into edge/vertex language.

Key idea a \(0/1\) value \(y_{uv}\) is a yes/no for "select edge \((u,v)\)", so a solution is a subset \(F\subseteq E\) of edges.

Why this move the dual constraint "\(\ge 1\) around each vertex" is the signature of a covering problem — read literally, it says every vertex must be touched.

  1. Constraint. \(\sum_{uv\ni v}y_{uv}\ge 1\) for each \(v\) says at least one chosen edge is incident to \(v\): every vertex is covered by some selected edge.
  2. Objective. \(\min\sum_{uv\in E}y_{uv}\) counts selected edges, so we want as few as possible.
  3. Name it. Choosing a smallest edge set that touches every vertex is exactly the minimum edge cover — the natural companion to the maximum independent set we started from.
