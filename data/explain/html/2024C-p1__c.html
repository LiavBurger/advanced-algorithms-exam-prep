False. The class \(\mathrm{BPP}(1/2,1/2)\) contains every language, even undecidable ones, while \(\mathrm{BPP}(1/3,2/3)\) contains only decidable languages, so the two classes are not equal.

Take any language \(A\) at all, say even an undecidable one. Consider the algorithm that on input \(x\) tosses one fair coin and accepts if it comes up heads. It accepts every input with probability exactly \(1/2\), so both when \(x\in A\) and when \(x\notin A\) it meets the accept threshold \(\ge 1/2\) and the reject threshold \(\le 1/2\). Thus this is a valid \(\mathrm{BPP}(1/2,1/2)\) algorithm for \(A\), and so \(\mathrm{BPP}(1/2,1/2)\) contains all languages.

Now take any language \(L\in\mathrm{BPP}(1/3,2/3)\). Its machine accepts inputs of \(L\) with probability at least \(2/3\) and others with probability at most \(1/3\). We can decide \(L\) by enumerating all coin-toss sequences, computing the exact acceptance probability, and answering "\(x\in L\)" iff it is at least \(1/2\). This always halts (in exponential time), so \(L\) is decidable. Hence \(\mathrm{BPP}(1/3,2/3)\) has only decidable languages, whereas \(\mathrm{BPP}(1/2,1/2)\) has undecidable ones, so they differ.

Intuition. With no gap between the accept and reject thresholds, a pure coin flip "solves" anything, so that class is uselessly huge.
