Split the variables into basic \(x_B\) and nonbasic \(x_N\). Since \(x\) is a basic feasible solution with basis \(B\), the constraint \(Ax=b\) reads \(A_Bx_B+A_Nx_N=b\), and as \(A_B\) is invertible, \[x_B=A_B^{-1}b-A_B^{-1}A_Nx_N,\] which holds at every feasible point. Plugging this into the objective, \[c^Tx=c_B^Tx_B+c_N^Tx_N=c_B^T\big(A_B^{-1}b-A_B^{-1}A_Nx_N\big)+c_N^Tx_N=c_B^TA_B^{-1}b+\tilde c_N^Tx_N,\] where \(\tilde c_N=c_N-(A_B^{-1}A_N)^Tc_B\) is exactly the reduced cost vector.

At the basic feasible solution \(x\) the nonbasic variables vanish, \(x_N=0\), so \(c^Tx=c_B^TA_B^{-1}b\). Now let \(y\) be any feasible solution; the same identity applied to \(y\) gives \(c^Ty=c_B^TA_B^{-1}b+\tilde c_N^Ty_N\). Since \(y\ge 0\) we have \(y_N\ge 0\), and by assumption \(\tilde c_N\ge 0\), so \(\tilde c_N^Ty_N\ge 0\) and therefore \[c^Ty=c_B^TA_B^{-1}b+\tilde c_N^Ty_N\ge c_B^TA_B^{-1}b=c^Tx.\]

Thus \(c^Tx\le c^Ty\) for every feasible \(y\), which means \(x\) is an optimal solution.

Intuition. Rewriting the objective, its value at any feasible point is \(x\)'s value plus a nonnegative reduced-cost term, so nothing can do better than \(x\).
