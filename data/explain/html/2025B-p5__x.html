The algorithm samples many random colorings and reports the fraction that are legal:

  1. Draw \(t\) independent, uniformly random \(3\)-colorings \(c_1,\dots,c_t:V\to\{1,2,3\}\) (each vertex colored uniformly and independently), where \(t\) is chosen below.
  2. Check each \(c_i\) for legality by scanning all edges (linear time).
  3. Output \(A(G)=\tfrac1t\sum_{i=1}^t X_i\), the fraction of the sampled colorings that are legal, where \(X_i\) is defined below.

Correctness. Let \(X_i\) be an indicator random variable for the event that \(c_i\) is a legal coloring. Since \(c_i\) is a uniform \(3\)-coloring, \(\mathbb E[X_i]=R(G)\). The \(X_i\) are mutually independent. Let \(X=\sum_{i=1}^t X_i\); then \(\mathbb E[X]=t\,R(G)\) and the output is \(X/t\), so \(\mathbb E[A(G)]=R(G)\). By the Chernoff bound, \[ \Pr\!\left[\,|A(G)-R(G)|\ge \tfrac1n\,\right] = \Pr\!\left[\,\Big|\tfrac{X}{t}-\tfrac{\mathbb E[X]}{t}\Big|\ge \tfrac1n\,\right] \le e^{-O(t/n^2)}, \] because the deviation \(1/n\) enters the exponent squared.

Choosing \(t=O(n^3)\) makes \(t/n^2=O(n)\), so the failure probability drops below \(2^{-n}\). Thus with probability at least \(1-2^{-n}\) the output is within \(1/n\) of \(R(G)\). Sampling \(O(n^3)\) colorings and checking each in linear time is polynomial, so the algorithm is efficient.

Intuition. A random coloring is legal with probability exactly \(R(G)\), so the observed legal-fraction estimates \(R(G)\), and enough samples make that estimate sharp with overwhelming probability.
