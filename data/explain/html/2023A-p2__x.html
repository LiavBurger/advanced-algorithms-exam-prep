We model Minimum Dominating Set as a \(0/1\) integer program. Recall \(D\subseteq V\) is dominating if every vertex is either in \(D\) or adjacent to a vertex in \(D\); we want the smallest such \(D\).

  1. Variables. For each vertex \(v\in V\) introduce \(x_v\in\{0,1\}\), where \(x_v=1\) means "\(v\) is selected into the dominating set" and \(x_v=0\) means it is not. Any \(0/1\) assignment thus encodes a candidate set \(D=\{v:x_v=1\}\).
  2. Objective. The size of \(D\) is \(\sum_{v\in V}x_v\), so we minimize \(\sum_{v\in V}x_v\).
  3. Domination constraints. For every vertex \(v\), the domination requirement says \(v\) itself is chosen or at least one neighbor is chosen. As a linear inequality: \[x_v+\sum_{u:(u,v)\in E}x_u\;\ge\;1\qquad\text{for all }v\in V.\] The term \(x_v\) covers "\(v\in D\)"; the sum covers "some neighbor of \(v\) is in \(D\)". At least one of these must be \(1\).
Full IP: \(\min\sum_{v\in V}x_v\) subject to \(x_v+\sum_{u:(u,v)\in E}x_u\ge1\) for all \(v\in V\), and \(x_v\in\{0,1\}\).

Correspondence. Every feasible \(0/1\) solution gives a set \(D=\{v:x_v=1\}\); the constraint for each \(v\) guarantees \(v\) is in \(D\) or has a neighbor in \(D\), so \(D\) is a dominating set. Conversely any dominating set yields a feasible solution. Since the objective counts \(|D|\), minimizing the IP finds a minimum dominating set.
