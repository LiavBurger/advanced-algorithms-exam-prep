Goal Give a \(2/3\)-approximation for Maximum Triple Cut (partition \(V\) into \(V_1,V_2,V_3\) maximizing edges between parts).

Strategy Assign each vertex to one of the three parts uniformly at random, compute the expected cut, then derandomize with conditional expectations.

Key idea With three parts, a random assignment separates any fixed edge's endpoints with probability \(2/3\), and linearity turns that into \(\tfrac23\) of all edges in expectation.

Why this move Random partitioning gives an easy per-edge probability, and the method of conditional expectations makes the guarantee deterministic without losing anything.

  1. Randomized algorithm. Independently put each vertex \(v\) into \(V_1\), \(V_2\), or \(V_3\), each with probability \(1/3\).
  2. Per-edge probability. Fix edge \((u,v)\). Whatever set \(u\) lands in, \(v\) lands in that same set with probability exactly \(1/3\), so the edge is cut with probability \(1-\tfrac13=\tfrac23\).
  3. Expected cut. Let \(X_e\) be an indicator random variable for the event that edge \(e\) is cut, so \(\mathbb{E}[X_e]=\tfrac23\). By linearity of expectation, \[\mathbb{E}[\mathrm{ALG}]=\sum_{e\in E}\mathbb{E}[X_e]=\tfrac{2}{3}|E|.\]
  4. Ratio. Since \(\mathrm{OPT}\le|E|\), we get \(\mathbb{E}[\mathrm{ALG}]=\tfrac23|E|\ge\tfrac23\mathrm{OPT}\).
  5. Derandomize. By the method of conditional expectations, fix vertices one at a time, each time choosing the set that keeps the conditional expected cut highest. This never drops below the starting \(\tfrac23|E|\), so the final deterministic partition cuts at least \(\tfrac23|E|\ge\tfrac23\mathrm{OPT}\) edges.
