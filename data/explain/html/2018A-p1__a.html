Set up the recurrence from Strassen's structure, then apply the Master Theorem.

  1. Recurrence. On \(n\times n\) inputs Strassen makes \(7\) recursive multiplications of \(\tfrac n2\times\tfrac n2\) matrices, giving the \(7T(n/2)\) term. The \(10\) additions of \(\tfrac n2\times\tfrac n2\) matrices (plus splitting/combining) each cost \(\Theta(n^2)\) elementwise operations, so the non-recursive work is \(\Theta(n^2)\). Thus \(\;T(n)=7\,T(n/2)+\Theta(n^2).\)
  2. Master Theorem form \(T(n)=a\,T(n/b)+\Theta(n^k)\) with \(a=7,\ b=2,\ k=2\). Compare \(a\) with \(b^{k}=2^{2}=4\). Here \(a=7>4=b^k\), the "leaf-heavy" case, so \(T(n)=\Theta\!\big(n^{\log_b a}\big)\).
  3. Evaluate the exponent: \(\log_b a=\log_2 7\approx 2.807\). Hence \(T(n)=\Theta\!\big(n^{\log_2 7}\big)\), which is below the \(n^3\) of naive multiplication.

Intuitively: the number of subproblems grows like \(7^{\text{depth}}\) while each shrinks by \(4\) in size-work, so the bottom level (the \(n^{\log_2 7}\) leaves) dominates the total.
