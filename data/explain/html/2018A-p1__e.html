Claim the randomized min-cut algorithm (Karger's) is Monte Carlo.

Key idea the distinction is which resource is fixed: Las Vegas always returns the correct answer with random runtime; Monte Carlo has bounded runtime but may be wrong.

Why this move just check Karger's guarantee — its running time is fixed but its answer isn't always right, which is the Monte Carlo signature.

  1. How it runs. Karger's algorithm contracts a uniformly random edge until two vertices remain, then outputs the surviving cut. It always halts after the same number of contractions — the runtime is fixed.
  2. Why it can be wrong. A single run returns a fixed minimum cut only with probability \(\ge \tfrac{2}{n(n-1)}\), since it must never contract an edge of that cut. Fixed time, possibly wrong answer — that is Monte Carlo. (Repeating many times drives the error down, but each run is still Monte Carlo.)
