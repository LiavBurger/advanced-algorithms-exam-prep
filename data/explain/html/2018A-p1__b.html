Goal solve \(T(n)=T\!\big(\tfrac{5n}{6}\big)+T\!\big(\tfrac{n}{10}\big)+\Theta(n^2)\).

Strategy this isn't Master-Theorem shaped (unequal subproblems), so reason level by level down the recursion tree.

Key idea the per-node work is \(\Theta(n^2)\) (the split dominates the combine), and squaring shrinks the total work each level by a constant factor, so the top level dominates.

Why this move when subproblem sizes differ, you can't just plug into a formula — but a geometric series across levels still settles it cleanly.

  1. Local work. The split costs \(\Theta(n^2)\), the combine only \(\Theta(n)\), so a node of size \(n\) does \(\Theta(n^2)\).
  2. Work shrinks per level. The children's work is \(\Theta\!\big((\tfrac{5n}{6})^2+(\tfrac{n}{10})^2\big)=\big(\tfrac{25}{36}+\tfrac1{100}\big)\Theta(n^2)\approx 0.70\,\Theta(n^2)\). Each level is a constant factor \(r<1\) of the one above.
  3. Sum it. Total \(=\Theta(n^2)(1+r+r^2+\cdots)=\Theta(n^2)\), a converging geometric series. The root alone already costs \(\Theta(n^2)\), so \(T(n)=\Theta(n^2)\) — the top level sets the pace.
