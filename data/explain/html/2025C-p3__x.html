The solution reduces the lazy walk to the standard random-walk theorem from class by expressing its transition matrix through the graph's normalized adjacency matrix and checking that all its eigenvalues lie in \([-1/3,1]\), with the second-largest magnitude bounded away from \(1\). Once those spectral facts hold, "the rest is identical to class."

Key idea: laziness \(C=\tfrac13 I+\tfrac23 A\) only rescales eigenvalues \(\lambda_i=\tfrac13+\tfrac23\mu_i\); this keeps the top eigenvalue at \(1\) and pushes all others safely inside \([-1/3,1]\), so the class mixing argument applies verbatim.
  1. Class facts about \(A\). Let \(A\) be the normalized adjacency matrix (a step to a uniform random neighbor). Since \(G\) is regular and connected, \(A\)'s eigenvalues satisfy \(-1\le\mu_n\le\cdots\le\mu_1=1\), with the spectral-gap bound \(\mu_2\le 1-\tfrac1{4n^5}\).
  2. Transition matrix of the lazy walk. Each step stays with prob. \(\tfrac13\) (the \(\tfrac13 I\) term) or moves to a uniform neighbor with prob. \(\tfrac23\) (the \(\tfrac23 A\) term), so \(C=\tfrac13 I+\tfrac23 A\). Because \(I\) and \(A\) share eigenvectors, \(C\) has the same eigenvectors with eigenvalues \(\lambda_i=\tfrac13+\tfrac23\mu_i\).
  3. Top eigenvalue unchanged: \(\lambda_1=\tfrac13+\tfrac23\mu_1=\tfrac13+\tfrac23=1\) (the stationary/uniform direction survives).
  4. Second eigenvalue bounded below \(1\): \(\lambda_2=\tfrac13+\tfrac23\mu_2\le\tfrac13+\tfrac23\big(1-\tfrac1{4n^5}\big)=1-\tfrac1{6n^5}\). So there is still a spectral gap of order \(n^{-5}\).
  5. No negative eigenvalue hurts. The point of laziness: from \(\mu_n\ge-1\), \(\lambda_n=\tfrac13+\tfrac23\mu_n\ge\tfrac13-\tfrac23=-\tfrac13\). Thus every \(\lambda_i\in[-\tfrac13,1]\), so \(|\lambda_i|\le|\lambda_2|\le1-\tfrac1{6n^5}\) for all \(i>1\) — no eigenvalue near \(-1\) can slow mixing.
  6. Conclusion. With top eigenvalue \(1\) and all others of magnitude \(\le 1-\tfrac1{6n^5}\), the class theorem gives: after \(\text{poly}(n)\) steps (roughly \(O(n^5\log n)\), enough for \((1-\tfrac1{6n^5})^t\) to become small) the distribution is close to uniform, so the probability of being at \(t\) is at least \(\tfrac1n-o(\tfrac1n)\ge\tfrac1{2n}\).
