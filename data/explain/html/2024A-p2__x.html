Goal Build a randomized polynomial-time algorithm estimating a CNF formula's density \(D(\varphi)\) to within \(1/10\), correct with probability at least \(1-2^{-n}\).

Strategy Sample many random assignments, output the fraction that satisfy \(\varphi\), and use a concentration bound to fix the sample size.

Key idea \(D(\varphi)\) is exactly the probability a uniformly random assignment satisfies \(\varphi\), so a sample average estimates it.

Why this move Whenever a quantity is a probability over a huge set you can't scan, Monte-Carlo sampling plus a Chernoff bound is the standard way to estimate it cheaply and reliably.

  1. The algorithm. Draw \(t\) independent uniform assignments \(\alpha_1,\dots,\alpha_t\in\{0,1\}^n\), evaluate \(\varphi(\alpha_i)\) for each (fast, linear in the formula size), and output \(A(\varphi)=\tfrac1t\sum_{i=1}^t X_i\), the fraction that satisfy.
  2. It aims at the right value. Let \(X_i\) be an indicator random variable for the event that \(\alpha_i\) satisfies \(\varphi\). Since \(\alpha_i\) is uniform, \(\mathbb{E}[X_i]=D(\varphi)\), so \(\mathbb{E}[A(\varphi)]=D(\varphi)\) — the estimate is centered correctly.
  3. Concentration. The \(X_i\) are independent and in \([0,1]\), so by the Chernoff bound the chance the estimate is off by more than \(1/10\) shrinks fast as \(t\) grows.
  4. Pick the sample size. Choose \(t=O(n)\) large enough that this error drops below \(2^{-n}\); then the algorithm succeeds with probability at least \(1-2^{-n}\), and with \(O(n)\) fast evaluations it runs in polynomial time.
