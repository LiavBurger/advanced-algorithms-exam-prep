We run the exact same greedy from part (a), processing each subset when it arrives:

  1. Keep \(X\), initially empty.
  2. When a subset \(D\) arrives: if \(X\cap D=\emptyset\), add all of \(D\) to \(X\); otherwise leave \(X\) unchanged.

This is a valid online algorithm: it never looks at future subsets and never removes an element once added. After each arriving \(D\) we have \(X\cap D\ne\emptyset\), so \(X\) is a hitting set for everything seen so far.

It is \(3\)-competitive: the offline analysis in part (b) allowed the subsets to be processed in an arbitrary order and never used any lookahead. So let that arbitrary order be the arrival order. The set \(X\) we build online is exactly what the offline greedy would build on the same sequence, so the bound \(|X|\le 3\,\mathrm{OPT}\) carries over and the algorithm is \(3\)-competitive.

Intuition. The offline greedy already works in any order and never undoes a choice, so the arrival order is just one more valid order.
