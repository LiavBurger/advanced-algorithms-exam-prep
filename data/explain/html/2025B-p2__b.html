Goal give an \(f\)-approximation for set cover of frequency \(f\) (each element in at most \(f\) sets) by relaxing and rounding the ILP from (a).

Strategy solve the LP relaxation, then take every set whose fractional value is at least \(1/f\).

Key idea an element's constraint sums at most \(f\) values that reach \(1\) in total, so one of them must be at least \(1/f\) — the threshold that guarantees coverage.

Why this move the LP optimum is a lower bound on OPT, and the frequency-\(f\) structure hands you the exact rounding threshold, so relax-and-round is the natural attack.

  1. Relax. Replace \(x_i\in\{0,1\}\) by \(0\le x_i\le 1\), solve the LP for \(x^*\). Since every integer cover is LP-feasible, \(\text{LPOPT}=\sum_i c_i x_i^*\le\text{OPT}\).
  2. Round. Put \(S_i\) in the cover exactly when \(x_i^*\ge 1/f\); call the result \(x\).
  3. Feasibility. Fix element \(j\). Its constraint \(\sum_{i:S_i\ni j}x_i^*\ge 1\) has at most \(f\) terms; if all were below \(1/f\) the sum would be below \(1\). So some containing set has \(x_i^*\ge 1/f\) and is taken — \(j\) is covered.
  4. Cost. For every \(i\), \(x_i\le f\,x_i^*\): true if \(x_i=0\) since \(x_i^*\ge 0\), and if \(x_i=1\) then \(x_i^*\ge 1/f\) makes \(f\,x_i^*\ge 1\).

Summing with weights \(c_i\ge 0\): \(\text{ALG}=\sum_i c_i x_i\le f\sum_i c_i x_i^*=f\cdot\text{LPOPT}\le f\cdot\text{OPT}\). So this runs in polynomial time and never costs more than \(f\) times optimal.
