We compute the boolean product by casting it to ordinary integer matrix multiplication and using fast matrix multiplication.

Observe that \((A\circ B)_{i,j}=\bigvee_{k=1}^n (A_{i,k}\wedge B_{k,j})\) equals \(1\) exactly when there is some index \(k\) with both \(A_{i,k}=1\) and \(B_{k,j}=1\). If we treat the \(0/1\) entries as ordinary integers and form the usual product \(C=A\cdot B\), then \(C_{i,j}=\sum_{k=1}^n A_{i,k}B_{k,j}\) counts exactly those indices \(k\). So \((A\circ B)_{i,j}=1\) if and only if \(C_{i,j}>0\).

Algorithm:

  1. Compute \(C=A\cdot B\) over the integers using fast matrix multiplication.
  2. Output the matrix whose \((i,j)\) entry is \(1\) if \(C_{i,j}>0\) and \(0\) otherwise.

Runtime: step 1 takes \(O(n^{\omega})\) time, where \(\omega<3\) is the fast matrix-multiplication exponent, and step 2 thresholds each of the \(n^2\) entries in \(O(n^2)\) time. The total is \(O(n^{\omega})\), which is asymptotically smaller than \(n^3\), as required.

Intuition. An OR of ANDs is nonzero exactly when the integer dot product is positive, so one fast integer multiply then a "is it \(>0\)?" test does the job below \(n^3\).
