The statement is true. For an LP in standard form the feasible region is the polytope \(\{x: Ax=b,\ x\ge 0\}\), and there is a clean algebraic test for a point being a vertex, all of whose steps run in polynomial time.

  1. Feasibility. First check that \(y\) even lies in the polytope: verify \(Ay=b\) (a matrix-vector product and comparison) and \(y\ge 0\) (coordinate-wise). Both are trivially polynomial. If either fails, \(y\) is not a vertex.
  2. Vertex characterization from class. Let \(A_y\) be the submatrix of \(A\) consisting of exactly those columns \(i\) where \(y_i>0\) (the support of \(y\)). The result proved in class is: a feasible \(y\) is a vertex if and only if these columns are linearly independent, i.e. \(A_y\) has full column rank.
  3. Checking the rank. Compute \(\operatorname{rank}(A_y)\) via Gaussian elimination, which is polynomial time, and compare it to the number of positive coordinates (the number of columns of \(A_y\)). Equality means full column rank.
  4. Combining: \(y\) is a vertex exactly when it is feasible and \(A_y\) has full column rank—both verifiable in polynomial time, so the decision algorithm is efficient.
