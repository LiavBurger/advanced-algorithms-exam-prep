This is the maximum independent set problem. Each variable \(x_v\in\{0,1\}\) decides whether vertex \(v\) is chosen, and the objective \(\max\sum_{v\in V}x_v\) counts the chosen vertices, so we are picking as many vertices as possible. The constraint \(x_u+x_v\le 1\) for every edge \((u,v)\in E\) forces at most one endpoint of each edge to be chosen, so no two chosen vertices are adjacent. A set of vertices with no edge inside it is exactly an independent set, so maximizing the number of chosen vertices is finding a maximum independent set.

Intuition. Forbidding both endpoints of every edge is the same as saying no two picked vertices are neighbors.
