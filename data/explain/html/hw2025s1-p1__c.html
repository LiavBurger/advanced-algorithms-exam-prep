We prove \(\mathsf{ZPP}=\mathsf{RP}\cap\mathsf{coRP}\), using the "I don't know" characterization of \(\mathsf{ZPP}\) from part (a): an algorithm \(M\) that is poly-time, never errs on a committed yes/no, and says "I don't know" with probability at most \(1/3\).

  1. \(\mathsf{ZPP}\subseteq\mathsf{RP}\). Let \(A\in\mathsf{ZPP}\) with such an \(M\). Define \(M'\) identical to \(M\) except that on "I don't know" it rejects. It runs in poly time. If \(x\notin A\), \(M\) never accepts and the fallback is a reject, so \(M'\) accepts with probability \(0\). If \(x\in A\), \(M'\) rejects only when \(M\) said "I don't know", which happens with probability at most \(1/3\); so it accepts with probability at least \(2/3\ge 1/2\). This is exactly an \(\mathsf{RP}\) algorithm, so \(A\in\mathsf{RP}\).
  2. \(\mathsf{ZPP}\subseteq\mathsf{coRP}\). Identical, except now on "I don't know" we accept. Then \(x\in A\) is always accepted and \(x\notin A\) is rejected with probability at least \(2/3\). Hence \(A\in\mathsf{coRP}\), and combining, \(\mathsf{ZPP}\subseteq\mathsf{RP}\cap\mathsf{coRP}\).
  3. \(\mathsf{RP}\cap\mathsf{coRP}\subseteq\mathsf{ZPP}\). Let \(M_1\) be an \(\mathsf{RP}\) algorithm and \(M_2\) a \(\mathsf{coRP}\) algorithm for \(A\); by amplification we may assume each errs with probability at most \(1/3\). Build \(M\): run both; if \(M_1\) accepts, accept; if \(M_2\) rejects, reject; otherwise say "I don't know".
  4. \(M\) has the properties of part (a). If \(x\in A\): \(M_1\) accepts with probability \(\ge 2/3\) and \(M_2\) never rejects (\(\mathsf{coRP}\) has no false rejects), so \(M\) either accepts or, with probability \(\le 1/3\), says "I don't know" — it never wrongly rejects. If \(x\notin A\): \(M_2\) rejects with probability \(\ge 2/3\) and \(M_1\) never accepts (\(\mathsf{RP}\) has no false accepts), so \(M\) either rejects or, with probability \(\le 1/3\), says "I don't know". Thus \(M\) never errs and abstains with probability at most \(1/3\), so \(A\in\mathsf{ZPP}\).
