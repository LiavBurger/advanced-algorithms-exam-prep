True. The isolation lemma does not really use that the weights come from \(\{1,\dots,N\}\); it only uses that we draw \(N\) distinct weights and that the weight of a set is the sum of its elements' weights. So we reduce the product version back to the usual sum version by taking logarithms.

Given a multiplicative weight function \(w\), define \(w_\ell(x)=\log w(x)\). The map \(w\mapsto w_\ell\) is a bijection, order-preserving, from weight functions into \(\{1,\dots,N\}\) onto weight functions into \(\{\log 1,\dots,\log N\}\), so it still gives \(N\) distinct weights. Moreover it turns products into sums: if \(w(A)=\prod_{i\in A}w(i)\) then \(w_\ell(A)=\sum_{i\in A}w_\ell(i)\).

Now apply the original (additive) isolation lemma to the weights \(w_\ell\): with high probability there is a unique set of minimum \(w_\ell\)-weight. Since \(\log\) is monotone, that same set is also the unique set of minimum \(w\)-weight under the product definition. Hence the isolation lemma still holds for product weights.

Intuition. Taking logs turns the product weight into an ordinary sum, so the usual isolation lemma applies unchanged.
