Each level of recursion halves both dimensions and does \(\Theta(m+n)\) work; write that per-level cost as \(c(m+n)\) for a constant \(c\). Unrolling the recurrence sums these costs down the single chain of calls, and the key point is that the sizes shrink geometrically, so the sum is a convergent geometric series.

  1. At the top level the work is \(c(m+n)\). The recursive call is on an \(\lfloor m/2\rfloor\times\lfloor n/2\rfloor\) matrix, whose work is \(c\!\left(\frac m2+\frac n2\right)=\tfrac12\,c(m+n)\). The next level contributes \(\tfrac14 c(m+n)\), and so on, each level being half of the previous one.
  2. Summing over all levels: \[ T(m,n)=c(m+n)\left(1+\tfrac12+\tfrac14+\tfrac18+\cdots\right). \]
  3. The bracket is a geometric series with ratio \(\tfrac12\), so it is bounded: \(\sum_{k\ge0}2^{-k}=2\). Hence \[ T(m,n)\le 2c(m+n)=\Theta(m+n). \]
  4. The lower bound \(T(m,n)=\Omega(m+n)\) is immediate because the very first level already does \(c(m+n)\) work. Together this gives \(\Theta(m+n)\).

The base case (a \(1\times n\) matrix handled in \(\Theta(n)\) time) is consistent with this bound, since \(\Theta(n)\le\Theta(m+n)\); it is reached after about \(\log_2 m\) levels but costs no more than one term of the series.

Answer: \(T(m,n)=\Theta(m+n)\).
