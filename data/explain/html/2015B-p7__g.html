Algorithm:

  1. Compute a maximum matching \(M\) in \(G\), using the polynomial-time matching algorithm from class.
  2. For every vertex not covered by \(M\), add one arbitrary edge incident to it (such an edge exists because \(G\) is connected, so there are no isolated vertices). Output the resulting edge set \(F\).

Correctness. \(F\) is an edge cover: a vertex matched by \(M\) is covered by its matching edge, and every unmatched vertex is covered by the edge we added for it. Its size is

\[|F|=|M|+\big(|V|-2|M|\big)=|V|-|M|,\]

because \(M\) covers \(2|M|\) vertices and we add exactly one edge for each of the remaining \(|V|-2|M|\) vertices.

Now we show \(F\) is optimal. Let \(\mathrm{OPT}\) be a minimum edge cover. Assign each vertex to one edge of \(\mathrm{OPT}\) that covers it. Let \(p\) be the number of edges assigned two vertices and \(q\) the number assigned exactly one; every vertex is assigned to some edge, so \(|V|=2p+q\). All \(p+q\) edges that received a vertex are in \(\mathrm{OPT}\), so \(|\mathrm{OPT}|\ge p+q\). The \(p\) doubly-assigned edges have disjoint endpoints, so they form a matching, giving \(p\le|M|\). Therefore

\[|\mathrm{OPT}|\ge p+q=(2p+q)-p=|V|-p\ge |V|-|M|=|F|.\]

Since \(F\) is itself a valid edge cover we also have \(|F|\ge|\mathrm{OPT}|\), so \(|F|=|\mathrm{OPT}|\) and the algorithm returns a minimum edge cover.

Runtime. The cost is dominated by the maximum matching computation, which is polynomial; adding one edge per unmatched vertex takes linear time. So the whole algorithm runs in polynomial time.

Intuition. A matching covers two vertices with one edge, the best an edge can do, so build on a biggest matching and patch up the leftovers one edge each.
