The statement is false. The confusion is between a change of basis and a change of vertex. In the simplex algorithm as presented in class, a pivot is performed only when it strictly decreases the objective value; the algorithm never moves to a different vertex whose value merely ties the current one.

  1. Each vertex (basic feasible solution) of the polytope corresponds to a basis \(B\)—a choice of columns of \(A\) that determines the basic variables. A pivot swaps one column in and one out, giving a new basis.
  2. When the solution is degenerate, some basic variable equals \(0\), and several different bases can describe the very same point. In that situation a pivot can change the basis while the vertex, and therefore the objective value, stays exactly the same. But this is not a move to a different vertex—it is the same geometric point.
  3. A genuine move to a different vertex changes the value of at least one variable and, in the class version of the pivot rule, is taken only when the objective strictly improves (decreases, for a minimization LP).
  4. Hence it is impossible for the algorithm to jump to a different vertex whose objective value equals the previous one: a different vertex is reached only with a strict decrease. The scenario described—equal value at a distinct vertex—does not occur.
