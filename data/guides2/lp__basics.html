When do I reach for this?

Any question that says "linear program", "minimize/maximize a linear objective subject to linear constraints", "put in standard form", "run one simplex pivot", or "is this point a vertex". The whole game is: an LP lives on a polyhedron, and its optimum sits at a corner. So we learn to (a) write the LP cleanly, (b) recognize corners, (c) walk between them.

  • "Convert this LP" / "add slack variables" → rewrite into standard form.
  • "Is \(y\) a vertex / basic feasible solution?" → the independent-columns test.
  • "Which variable enters / leaves the basis?" → one simplex pivot (reduced cost, then min-ratio).
  • "Prove LP \(\in\) P" → cite the ellipsoid algorithm, never simplex.

Core tools

STANDARD FORM
\[ \min\; c^\top x \quad\text{s.t.}\quad Ax=b,\; x\ge 0 \] To get here: flip \(\max\) to \(\min\) by negating \(c\); turn \(a^\top x\le b\) into \(a^\top x+s=b,\ s\ge 0\) (a slack); split a free variable \(x=x^{+}-x^{-}\) with \(x^{+},x^{-}\ge 0\). "put into standard form", "add slack variables"
VERTEX = BASIC FEASIBLE SOLUTION
For feasible \(x\), let \(A_x\) be the columns of \(A\) where \(x_j>0\). \[ x\text{ is a vertex}\iff A_x\text{ has independent columns.} \] Equivalently \(x\) is a vertex iff there is no \(y\ne 0\) with \(x+y,\ x-y\in P\). A standard-form polytope in \(\mathbb{R}^n\) has at most \(\binom{n}{m}\le 2^n\) vertices. "is \(y\) a vertex / BFS?"
SIMPLEX (one pivot)
With basis \(B\), reduced costs are \(\tilde c_N^\top=c_N^\top-c_B^\top A_B^{-1}A_N\). \[ \tilde c_N\ge 0\ \Rightarrow\ \text{current BFS optimal.} \] Otherwise raise a variable with \(\tilde c_j<0\); the min-ratio test says how far. "which variable enters/leaves?"
ELLIPSOID
Trap \(P\) in a big ball, repeatedly halve the volume around a separating hyperplane until you hit \(P\) or prove it empty. Runs in polynomial time — this is the theorem "LP \(\in\) P". Slow in practice; only needs a separation oracle, so it even handles exponentially many constraints. "prove LP is solvable in poly time"

Key facts

Theorem If \(\min\{c^\top x: x\in P\}\) is finite over a standard-form polytope, the optimum is attained at a vertex. Intuition: if \(x\) is not a corner, some direction \(y\) has \(x\pm y\in P\); slide along the non-worsening side until a coordinate hits \(0\) — you gain a zero coordinate each time, so after \(\le n\) steps you reach a corner no worse than \(x\).
Definition A basis is a set \(B\) of \(m\) column indices with \(A_B\) invertible; its BFS sets \(x_N=0,\ x_B=A_B^{-1}b\) and is feasible when \(x_B\ge 0\). "Degenerate" means some basic \(x_i=0\).

Worked example — the thinking

2014A P10. An LP with \(\le\) constraints; find a BFS, then do one pivot.

  1. Constraints are \(\le\), so I add one nonneg slack per row to reach \(Ax=b,\ x\ge 0\). The slacks hand me a free starting BFS: set the original \(x=0\), each slack \(=\) its \(b_i\).
  2. Asked for the BFS of basis \(\{x_1,s_2\}\): keep those two basic, force every other variable to \(0\), and solve the square system \(A_B x_B=b\) for the two values.
  3. Entering variable: compute reduced costs \(\tilde c_j\); pick a nonbasic column with \(\tilde c_j<0\) (most negative is the standard greedy choice). If none is negative, stop — already optimal.
  4. Leaving variable: the min-ratio test. Over rows \(i\) where the entering column is positive, take \(b_i/(\text{column entry}_i)\); the smallest ratio names who leaves. This is exactly "raise \(x_j\) until the first basic variable hits \(0\)", keeping \(x\ge 0\).
  5. Swap them in the basis, recompute the objective at the new vertex.

The theory behind step 3 is 2025B P3: prove \(\tilde c_N\ge 0\Rightarrow\) optimal. Reason: any feasible \(y\) has \(c^\top y=c_B^\top A_B^{-1}b+\tilde c_N^\top y_N\ge c_B^\top A_B^{-1}b=c^\top x\), since \(y_N\ge 0\).

Common traps

A slack must be \(\ge 0\), and you never add a slack to an equality. — A free variable is NOT just "\(\ge 0\)"; you must split it \(x^{+}-x^{-}\). — Degeneracy (2023A P1): a pivot can change the basis yet stay at the same physical vertex, so the objective need not strictly improve — but a move to a genuinely new vertex does strictly improve. — Never claim simplex is polynomial: a single pivot is poly, the number of pivots is exponential worst-case. The poly-time result is ellipsoid. — Deciding "is \(y\) a vertex?" is easy (rank check), a recurring T/F (2024B P1).

Checklist — one simplex pivot

  1. Standard form: \(\max\to\min\), add nonneg slacks, split free vars, enforce \(x\ge 0\).
  2. Fix the current basis \(B\); set \(x_N=0\); solve \(A_B x_B=b\).
  3. Compute \(\tilde c_N\); if all \(\ge 0\) → STOP (optimal).
  4. Entering \(=\) a \(j\) with \(\tilde c_j<0\).
  5. Leaving \(=\) min-ratio \(b_i/(A_B^{-1}A_j)_i\) over positive entries.
  6. Update basis, recompute the objective.
