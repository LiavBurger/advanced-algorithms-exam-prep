The claim is true. Read the statement carefully: it asks whether there is always an assignment satisfying at most \(7m/8\) clauses. This is a weaker demand than the familiar "at least \(7m/8\)" statement, and it follows from the same averaging (probabilistic-method) argument.

  1. Pick a uniformly random assignment: set each variable to true or false independently with probability \(1/2\). A fixed clause of a 3-CNF has 3 literals; it is unsatisfied only when all 3 literals are false, which happens with probability \((1/2)^3 = 1/8\). So it is satisfied with probability \(7/8\).
  2. Let \(Y\) be the number of satisfied clauses. By linearity of expectation, \(\mathbb{E}[Y] = \sum_{j=1}^{m}\Pr[\text{clause } j \text{ satisfied}] = m\cdot\tfrac{7}{8} = \tfrac{7m}{8}\).
  3. A random variable cannot always lie strictly above its mean, nor always strictly below it. Formally, if every assignment satisfied strictly more than \(7m/8\) clauses, then \(\mathbb{E}[Y] > 7m/8\), a contradiction. Hence there exists at least one assignment with \(Y \le 7m/8\).

That is exactly the requested assignment satisfying at most \(7m/8\) clauses, so the statement holds. Note the same expectation also gives an assignment satisfying at least \(7m/8\); the mean is sandwiched, so both directions have witnesses.
