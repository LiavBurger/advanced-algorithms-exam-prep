Goal Show a random walk from \(s\) reaches a target \(t\) within \(8mn\) steps with probability \(\ge 3/4\), given cover time \(\le 2mn\).

Strategy Bound the expected time to hit \(t\) by the cover time, then apply Markov at four times that mean.

Key idea Reaching a single vertex \(t\) is easier than covering all of them, so \(\mathbb{E}[\text{hit }t]\le 2mn\); Markov converts that mean into a tail bound.

Why this move We only have a bound on an expectation and want a "within so many steps" probability — Markov is exactly the mean-to-tail conversion.

  1. Define the variable. Let \(X\) be the number of steps until the walk first reaches \(t\).
  2. Bound its mean. The cover time is the expected time to visit all vertices, which in particular visits \(t\), so \(\mathbb{E}[X]\le 2mn\).
  3. Apply Markov. Since \(X\ge0\), \[\Pr[X>8mn]\le \frac{\mathbb{E}[X]}{8mn}\le \frac{2mn}{8mn}=\frac14.\]
  4. Complement. Hence \(\Pr[X\le 8mn]\ge 1-\tfrac14=\tfrac34\). The factor \(8mn=4\cdot 2mn\) is chosen precisely so Markov lands on the clean \(1/4\) failure probability.
