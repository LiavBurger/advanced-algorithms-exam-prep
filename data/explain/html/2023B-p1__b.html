Claim True — one pivoting step of simplex runs in polynomial time.

Strategy List what happens in a single pivot and note each piece is cheap linear algebra.

Key idea The claim is about the cost of one pivot, not how many pivots the whole run takes (that count can be exponential).

Why this move "Polynomial per step" is decided by opening up the step into its operations, so we just itemize a pivot.

  1. Pick the entering variable. Compute the reduced-cost vector and choose a coordinate \(i\) whose reduced cost shows the objective can improve. This is a matrix-vector computation on the input data.
  2. Pick the leaving variable. Using the entering column, the ratio test scans polynomially many ratios and selects a coordinate \(j\) to drop from the basis.
  3. Update the basis. Swapping \(i\) in and \(j\) out needs a basis-inverse recompute and the new basic solution — some matrix inversions and multiplications, each polynomial in the input dimensions.

Every ingredient of a pivot is a standard polynomial-time routine, so the step is polynomial. The hard part of simplex is the possible number of steps, not the price of one.
