Let \(H\) be a Hamiltonian cycle. Define a solution by setting \(x_{u,v}=1\) if the edge \((u,v)\) belongs to \(H\) and \(x_{u,v}=0\) otherwise. These values are in \(\{0,1\}\), so the integrality constraint holds.

Now check the degree constraints. A Hamiltonian cycle is a single closed tour that visits each vertex exactly once, so at every vertex \(v\) it enters through exactly one edge and leaves through exactly one edge. Hence for each \(v\) the chosen incoming edges sum to \(1\),

\[\sum_{u:(u,v)\in E} x_{u,v}=1,\]

and the chosen outgoing edges sum to \(1\),

\[\sum_{w:(v,w)\in E} x_{v,w}=1.\]

All constraints are satisfied, so this indicator vector is a feasible solution (and its objective value equals the total weight of the cycle, which is why the IP models TSP).

Intuition. Marking the cycle's edges automatically gives every vertex one edge in and one out, exactly what the constraints demand.
