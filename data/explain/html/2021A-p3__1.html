Goal finish a \(\tfrac43\)-approximation for TSP on a complete graph with edge weights \(1\) or \(2\), where the given first step computes a minimum-cost cycle cover \(C\).

Strategy stitch the vertex-disjoint cycles of \(C\) into a single tour by rerouting one edge of each cycle to jump into the next cycle.

Key idea a cycle cover is a cheap stand-in for a tour (a tour is a cover with one cycle), so we only need to merge the pieces without paying much.

Why this move the minimum cycle cover is computable in polynomial time and lower-bounds OPT; each cycle has \(\ge 3\) vertices, so there are few of them and few patch edges to pay for.
