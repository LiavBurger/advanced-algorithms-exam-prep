The running time is \(\Theta(m+n)\). I write the recurrence, then unfold it and sum the resulting geometric series.

Each call does \(\Theta(m+n)\) work outside the recursion (the divide step plus the combine step, each \(\Theta(m+n)\)), and then makes one recursive call on a matrix of size \(\lfloor m/2\rfloor\)-by-\(\lfloor n/2\rfloor\). Writing the per-call cost as \(c(m+n)\) for a constant \(c\),

\[ T(m,n)=T\!\left(\tfrac{m}{2},\tfrac{n}{2}\right)+c(m+n). \]

Now I unfold the recursion. Going one level deeper halves both dimensions, so the added cost at the next level is \(c\left(\tfrac{m}{2}+\tfrac{n}{2}\right)=\tfrac12\,c(m+n)\), the level after that contributes \(\tfrac14\,c(m+n)\), and so on. Summing the costs over all levels gives

\[ T(m,n)=c(m+n)\left(1+\tfrac12+\tfrac14+\tfrac18+\cdots\right). \]

The series in parentheses is a geometric sum with ratio \(\tfrac12\), so it is at most \(2\). Therefore

\[ T(m,n)\le 2c(m+n)=\Theta(m+n). \]

It is also \(\Omega(m+n)\), since the very first call already does \(c(m+n)\) work. The recursion stops once the matrix has a single row (a \(1\)-by-\(n'\) matrix handled directly in \(\Theta(n')\) time), which is consistent with this bound. Hence \(T(m,n)=\Theta(m+n)\).

Intuition. The work halves at every deeper level, so the whole recursion costs only a constant factor more than the first call.
