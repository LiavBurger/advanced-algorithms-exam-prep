Claim False: it is not the case that \(x\) is optimal for an LP if and only if \(x\) is a vertex.

Strategy Give one tiny counterexample that breaks the equivalence in both directions.

Key idea Optima can lie at non-vertex points, and vertices can be far from optimal; "there exists an optimal vertex" is the correct, weaker fact.

Why this move A claimed iff is fastest to kill with a single small LP that violates each direction, rather than arguing in general.

  1. Optimal need not be a vertex. Minimize \(0\) subject to \(0\le x\le 1\). Every feasible point is optimal, including all interior points of \((0,1)\), which are not vertices.
  2. Vertex need not be optimal. In the same box, minimize \(x\): the vertex \(x=1\) is feasible with value \(1\), while the optimum is \(0\) at \(x=0\). So a vertex can be strictly worse than optimal.
  3. What is actually true. For a feasible bounded LP there exists an optimal solution that is a vertex — an existence statement, not an equivalence.
  4. Conclude. Both directions of the iff fail, so the statement is false.
