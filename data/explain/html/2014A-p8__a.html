Goal Give a randomized MAX-3SAT algorithm that is a \(7/8\)-approximation in expectation, and prove it.

Strategy Assign each variable a fair coin, compute the per-clause success probability, and sum with linearity of expectation.

Key idea A random assignment satisfies each clause with probability \(7/8\), and expectations of the per-clause indicators add up regardless of dependence.

Why this move Linearity of expectation lets us total per-clause probabilities without worrying about clauses sharing variables — no independence required.

  1. Algorithm. Set each variable to \(0\) or \(1\) independently and uniformly at random.
  2. One clause. A 3-literal clause fails only if all three literals are false. The literals are from distinct variables, so independent, each false with probability \(1/2\): \(\Pr[\text{unsatisfied}]=(1/2)^3=1/8\), hence \(\Pr[\text{satisfied}]=7/8\).
  3. Indicators. Let \(X_i\) be an indicator random variable for the event that clause \(i\) is satisfied, so \(\mathbb{E}[X_i]=7/8\), and let \(X=\sum_{i=1}^m X_i\) count the satisfied clauses.
  4. Linearity. Even though clauses may share variables, \[\mathbb{E}[X]=\sum_{i=1}^m \mathbb{E}[X_i]=\frac{7m}{8}.\]
  5. Ratio. Since \(\mathrm{OPT}\le m\), we get \(\mathbb{E}[X]=\tfrac{7}{8}m\ge\tfrac{7}{8}\mathrm{OPT}\), so the algorithm is a \(7/8\)-approximation in expectation.
