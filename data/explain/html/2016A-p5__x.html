The claim "the greedy algorithm is a \(2\)-approximation for maximum cut" is false; we refute it by tracing the algorithm and showing it can output a cut of value \(0\), which no finite approximation ratio can justify.

  1. Read the rule carefully. Both \(S\) and \(T\) start empty. A vertex \(w\) is placed in \(S\) only "if \(w\) has more neighbors at \(S\) than at \(T\)"; otherwise it goes to \(T\). Note the tie case (equal counts) fails the strict "more than", so it defaults to \(T\).
  2. First vertex. With \(S,T\) both empty, \(w\) has \(0\) neighbors in each. Since \(0>0\) is false, \(w\) is added to \(T\). So \(S\) is still empty.
  3. By induction, everything goes to \(T\). As long as \(S\) stays empty, every later vertex \(w\) has \(0\) neighbors in \(S\) and \(\ge0\) neighbors in \(T\); the condition \(0>(\text{neighbors in }T)\) is never true, so \(w\) is added to \(T\) again. Hence all vertices end in \(T\) and \(S=\varnothing\).
  4. The cut is empty. The cut counts edges with one endpoint in \(S\) and one in \(T\); with \(S=\varnothing\) that count is \(0\). Yet for any graph with at least one edge the optimum cut is positive (e.g. \(\ge1\)).

So the algorithm outputs value \(0\) while \(\mathrm{OPT}>0\). A \(2\)-approximation would require \(\mathrm{ALG}\ge \mathrm{OPT}/2>0\), which is violated. The ratio \(\mathrm{OPT}/\mathrm{ALG}\) is unbounded (and the output is not even a valid partition into two non-empty sets), so the claim is refuted.
