We compute \(H_n x\) by a recursive divide-and-conquer, just like FFT: split \(x\) in half, make two half-size transforms, and combine them with one addition and one subtraction. The running time is \(O(N\log N)\), where \(N=2^n\).

Write \(x=(x_0,x_1)\), where \(x_0,x_1\) are the two halves, each of length \(N/2=2^{n-1}\). Using the recursive block structure of the matrix, \[H_n x=\begin{bmatrix}H_{n-1}&H_{n-1}\\ H_{n-1}&-H_{n-1}\end{bmatrix}\begin{bmatrix}x_0\\ x_1\end{bmatrix}=\begin{bmatrix}H_{n-1}x_0+H_{n-1}x_1\\ H_{n-1}x_0-H_{n-1}x_1\end{bmatrix}.\]

Only the two products \(H_{n-1}x_0\) and \(H_{n-1}x_1\) appear, and each is a Walsh–Hadamard transform of order \(N/2\). So we recursively compute those two half-size transforms, then form the top half by adding them and the bottom half by subtracting them, which is \(O(N)\) extra work. The base case \(n=1\) applies \(H_1=\begin{bmatrix}1&1\\1&-1\end{bmatrix}\) directly in \(O(1)\).

Let \(T(N)\) be the running time. We make two recursive calls of size \(N/2\) plus \(O(N)\) to combine, so \[T(N)=2\,T(N/2)+O(N),\] which is the same recurrence as merge sort and FFT, giving \(T(N)=O(N\log N)\).

Intuition. Both halves of the answer reuse the same two half-size transforms, so one add and one subtract finish the job.
