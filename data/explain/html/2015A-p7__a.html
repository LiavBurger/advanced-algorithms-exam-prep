We turn the three "\(\le\)" inequalities into equalities by adding a non-negative slack variable to each, then run one simplex pivot in dictionary form (each basic variable and the objective written in terms of the current non-basic variables).

  1. Initial dictionary. With slacks \(s_1,s_2,s_3\ge0\), the non-basic variables are \(x_1,x_2,x_3,x_4\) (all \(=0\)): \[z=2x_1+4x_2+3x_3+x_4,\quad s_1=12-3x_1-x_2-x_3-4x_4,\] \[s_2=7-x_1+3x_2-2x_3-3x_4,\quad s_3=10-2x_1-x_2-3x_3+x_4.\]
  2. Entering variable. Choose a non-basic variable with a positive objective coefficient; \(x_2\) has the largest (\(4\)), so \(x_2\) enters.
  3. Ratio test (leaving variable). Increase \(x_2\) and see which basic hits \(0\) first. In \(s_1\) the coefficient of \(x_2\) is \(-1\Rightarrow\) bound \(12\); in \(s_2\) it is \(+3\), so \(s_2\) only grows (no bound); in \(s_3\) it is \(-1\Rightarrow\) bound \(10\). The minimum is \(10\), so \(s_3\) leaves.
  4. Solve for the entering variable. From the \(s_3\) row, \(x_2=10-2x_1-3x_3+x_4-s_3\).
  5. Substitute this into \(z,s_1,s_2\): \[z=40-6x_1-9x_3+5x_4-4s_3,\quad s_2=37-7x_1-11x_3-3s_3,\] \[s_1=2-x_1+2x_3-5x_4+s_3.\]

For \(s_1\): substituting \(-x_2\) contributes \(-x_4\), which adds to the original \(-4x_4\) to give \(-5x_4\). (The printed solution writes \(-4x_4\) here, a small slip; the correct coefficient is \(-5x_4\).)
