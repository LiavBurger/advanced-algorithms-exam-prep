We want a minimum-cost subgraph in which every receiver \(r\in R\) has a path to some sender in \(S\) (senders may differ across receivers). The trick is to merge all senders into a single artificial terminal so the problem becomes an ordinary Steiner tree, for which we already have a \(2\)-approximation.

  1. Reduction. Add one new artificial vertex \(v\) to \(G\) and connect \(v\) to every sender \(s\in S\) with an edge of cost \(0\). Call this augmented graph \(G'\).
  2. Equivalence of the two problems. In \(G'\), a receiver \(r\) is connected to \(v\) if and only if it is connected (in the original graph) to some sender: a path from \(r\) to \(v\) must use one of the zero-cost edges \((s,v)\), so it reaches a sender \(s\); conversely any \(r\)-to-\(s\) path extends to \(v\) for free. Requiring every receiver to reach \(v\) is exactly requiring every receiver to reach some sender.
  3. Steiner-tree formulation. A minimum-cost subgraph of \(G'\) connecting all of \(R\) to \(v\) is a minimum-cost Steiner tree with required (terminal) set \(R\cup\{v\}\). Because the added edges cost \(0\), the optimal Steiner-tree cost in \(G'\) equals the optimal cost of the original connection problem.
  4. Apply the known algorithm. Run the \(2\)-approximation for Steiner tree (proved in Problem Set 2) on \(G'\) with terminals \(R\cup\{v\}\). It returns a subgraph of cost at most twice the optimal Steiner-tree cost, hence at most twice the optimum of our problem. Dropping the zero-cost artificial edges yields the desired subgraph of the original graph, giving a \(2\)-approximation.
