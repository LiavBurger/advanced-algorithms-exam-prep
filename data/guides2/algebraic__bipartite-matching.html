When do I reach for this?

You want to know whether a bipartite graph has a perfect matching — without running an augmenting-path algorithm. The algebraic idea: build a matrix whose determinant is a polynomial that is nonzero exactly when a matching exists. Each permutation term in the determinant expansion corresponds to a way of pairing the two sides; a surviving term is a perfect matching. Then test "is this polynomial nonzero?" with PIT and Schwartz–Zippel.

  • "Does this bipartite graph have a perfect matching?" → symbolic determinant \(\neq0\).
  • Need a fast randomized check (or a parallel one) instead of combinatorial augmenting paths.
  • Counting flavor: "parity of the number of perfect matchings" → \(\det\) over \(\mathbb{F}_2\).

Core tools

SYMBOLIC (TUTTE) MATRIX
For bipartite \(G=(L\cup R,E)\) with \(|L|=|R|=n\), define \(B\) with a distinct variable on each edge: \[ B_{ij}=\begin{cases}x_{ij}&\text{if }(i,j)\in E\\[2pt]0&\text{otherwise.}\end{cases} \] encoding a bipartite graph so that matchings become determinant terms
DET ↔ MATCHING
\[ \det B=\sum_{\sigma\in S_n}\operatorname{sgn}(\sigma)\prod_{i=1}^n B_{i,\sigma(i)}. \] A term survives \(\iff\) every \(B_{i,\sigma(i)}\neq0\) \(\iff\) \(\sigma\) is a perfect matching. Because each variable is distinct, no two terms cancel, so \[ \det B\not\equiv 0\iff G\text{ has a perfect matching.} \] turning "matching exists?" into "polynomial nonzero?"
TEST BY PIT
\(\det B\) has degree \(\le n\) but exponentially many monomials — don't expand it. Substitute random values \(x_{ij}\gets r_{ij}\in S\), \(|S|\ge 2n\), and compute the numeric determinant in \(O(n^3)\). Nonzero \(\Rightarrow\) matching exists; error \(\le n/|S|\le\tfrac12\) by Schwartz–Zippel, amplify by repetition. deciding the symbolic determinant is nonzero, efficiently

Worked example — the thinking

2024C P1d. True/False: the parity of the number of perfect matchings in a bipartite graph is efficiently decidable via \(\det(A)\bmod 2\).

  1. Set all variables to \(1\). Let \(A\) be the \(0/1\) biadjacency matrix (each present edge \(=1\)). Then \(\det A=\sum_{\sigma}\operatorname{sgn}(\sigma)\prod_i A_{i,\sigma(i)}\) sums \(\pm1\) over all perfect matchings.
  2. Reduce mod \(2\). Over \(\mathbb{F}_2\) the signs \(\operatorname{sgn}(\sigma)=\pm1\) collapse to \(1\), so \(\det A\bmod2=(\#\text{perfect matchings})\bmod2\).
  3. It is efficient. A determinant mod \(2\) is computable by Gaussian elimination over \(\mathbb{F}_2\) in \(O(n^3)\) — deterministic, no randomness needed. So the statement is True.
  4. Contrast. This gives only the parity. Counting matchings exactly is #P-hard (permanent), and existence needs the symbolic determinant \(+\) PIT above, not the \(0/1\) determinant.
Traps. The \(0/1\) determinant is not a matching test: signed terms can cancel, so \(\det A=0\) does not mean "no matching" (e.g. the all-ones \(2\times2\) matrix has a matching yet \(\det=0\)). That cancellation is exactly why you need distinct variables — they make the terms unable to cancel. One direction is easy without algebra (a nonzero numeric \(\det\Rightarrow\) matching), but the clean equivalence needs the symbolic matrix. And keep \(|S|\ge 2n\) so the Schwartz–Zippel error stays \(\le\tfrac12\).

Checklist

  1. Check \(|L|=|R|\); otherwise no perfect matching (matrix isn't square).
  2. Build the symbolic matrix \(B\) with a distinct variable \(x_{ij}\) per edge.
  3. Argue \(\det B\not\equiv0\iff\) perfect matching exists (surviving permutation \(=\) matching, no cancellation).
  4. Test \(\det B\not\equiv0\) by PIT: random substitution, numeric \(\det\) in \(O(n^3)\), degree \(\le n\).
  5. State the one-sided error \(n/|S|\); amplify. (For parity only, use \(\det\bmod2\) — deterministic.)
