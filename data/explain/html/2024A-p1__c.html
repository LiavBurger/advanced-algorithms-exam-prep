True. The Gram-Schmidt process finds an orthonormal basis in polynomial time. First, if \(v_1,\dots,v_k\) are linearly dependent, greedily keep a maximal linearly independent subset of them (each independence check is a rank computation, done in polynomial time); this subset spans the same subspace. Assume now the vectors are independent.

Define \(\tilde b_1=v_1\) and, for \(i\ge 2\),

\[\tilde b_i=v_i-\sum_{j=1}^{i-1}\mu_{i,j}\,\tilde b_j,\qquad \mu_{i,j}=\frac{\langle v_i,\tilde b_j\rangle}{\langle \tilde b_j,\tilde b_j\rangle}.\]

The coefficient \(\mu_{i,j}\) is chosen exactly so that \(\langle\tilde b_i,\tilde b_j\rangle=0\) for every \(j

Intuition. Subtracting from each vector its projection onto the earlier ones makes them mutually orthogonal, and it is all just inner products and subtractions.
