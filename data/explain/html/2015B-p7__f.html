Read the dual of (e) as an ILP by forcing \(y_{uv}\in\{0,1\}\): now \(y_{uv}=1\) means "select edge \((u,v)\)" and a \(0/1\) vector is a subset \(F\subseteq E\) of edges.

  1. The constraint \(\sum_{uv\ni v} y_{uv}\ge 1\) for each vertex \(v\) says: at least one selected edge is incident to \(v\). In words, every vertex is covered (touched) by some chosen edge.
  2. The objective \(\min\sum_{uv\in E} y_{uv}\) counts the selected edges, so we want as few edges as possible.

Choosing a smallest set of edges so that every vertex is incident to at least one of them is exactly the minimum edge cover problem. (It is the natural "dual" companion to the maximum independent set problem we started from.)
