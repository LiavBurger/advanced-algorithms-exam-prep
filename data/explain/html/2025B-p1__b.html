True. Let \(A\) be \(n\times n\) and \(B\) be \(n\times n^2\). Split \(B\) into \(n\) blocks of size \(n\times n\), writing \(B=[\,B_1\mid B_2\mid\cdots\mid B_n\,]\). Then

\[AB=[\,AB_1\mid AB_2\mid\cdots\mid AB_n\,],\]

so computing \(AB\) reduces to \(n\) separate products of two \(n\times n\) matrices. Each \(n\times n\) product costs \(n^{\omega}\) operations with \(\omega<3\) (using fast matrix multiplication), so the total is

\[n\cdot n^{\omega}=n^{\omega+1}

arithmetic operations, which is fewer than \(n^4\). So such an algorithm exists.

Intuition. A wide matrix is just several square ones side by side, so fast square multiplication carries straight over.
