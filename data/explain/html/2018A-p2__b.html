We show the greedy runs in polynomial time, always outputs a hitting set, and returns a set of size at most \(3\,\mathrm{OPT}\). The proof is like the \(2\)-approximation for vertex cover from class.

Polynomial time: represent \(X\) as a linked list. Testing \(X\cap D=\emptyset\) takes \(O(|X|)\) time, and \(X\subseteq\bigcup_{D\in C}D\), so \(|X|\) is bounded by the input size. Since there are \(|C|\) iterations, the total time is polynomial in the input size.

It is a hitting set: by the rule in the loop, right after processing any subset \(D\) we have \(X\cap D\ne\emptyset\), so every subset is hit at the end.

Approximation ratio: let \(k\) be the number of subsets that triggered an add (those with \(X\cap D=\emptyset\) when reached). Each add inserts at most \(|D|\le 3\) elements, so \(|X|\le 3k\). On the other hand, these \(k\) added subsets are pairwise disjoint (we add \(D\) only when it meets nothing already in \(X\)), so no single element belongs to two of them. Any hitting set, and in particular OPT, must contain at least one element from each of these \(k\) disjoint subsets, so \(\mathrm{OPT}\ge k\).

Combining, \(|X|\le 3k\le 3\,\mathrm{OPT}\), which proves the \(3\)-approximation.

Intuition. The disjoint grabbed subsets force OPT to spend at least one element on each, and we spent at most three.
