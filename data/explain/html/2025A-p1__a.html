True. We use the averaging (probabilistic) argument: the average number of satisfied clauses over all assignments equals \(7m/8\), so some assignment satisfies at most that many.

Pick an assignment at random by setting each variable to true or false independently with probability \(1/2\). A single clause has three literals; it is unsatisfied only when all three literals are false, which happens with probability \((1/2)^3=1/8\). So each clause is satisfied with probability \(7/8\).

For clause \(i\), let \(X_i\) be an indicator random variable for the event that clause \(i\) is satisfied, and let \(X=\sum_{i=1}^m X_i\) be the number of satisfied clauses. By linearity of expectation \[\mathbb{E}[X]=\sum_{i=1}^m \mathbb{E}[X_i]=\frac{7m}{8}.\] A random quantity cannot always be strictly above its own average, so there must exist at least one assignment that satisfies at most \(7m/8\) clauses. Hence the statement is true.

Intuition. On average \(7/8\) of the clauses are satisfied, so some assignment must land at or below that average.
