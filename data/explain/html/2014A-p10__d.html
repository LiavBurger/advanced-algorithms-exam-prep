Goal find which basic variable leaves as \(x_3\) enters.

Strategy raise \(x_3\) from \(0\) (others still \(0\)) and see which basic variable hits \(0\) first.

Key idea the entering variable can only grow until some basic variable would go negative; that variable is the one that leaves.

Why this move feasibility needs every variable \(\ge 0\), so the min-ratio test just asks "which \(\ge 0\) wall do we hit first?"

  1. Write basics in terms of \(x_3\). With \(x_2=s_1=0\): \(x_1=10\) and \(s_2=6-x_3\).
  2. \(x_1\) sets no limit. It has no \(x_3\) term, so it stays at \(10\) no matter how large \(x_3\) grows.
  3. \(s_2\) sets the limit. \(s_2=6-x_3\) reaches \(0\) at \(x_3=6\), so \(s_2\ge 0\) caps \(x_3\) at \(6\) (ratio \(6/1=6\)).

So \(s_2\) leaves the basis and \(x_3\) enters at value \(6\); the new basis is \(\{x_1,x_3\}\).
