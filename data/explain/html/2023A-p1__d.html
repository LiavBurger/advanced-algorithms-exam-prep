The statement is true. The naive algorithm multiplies two \(4\times 4\) matrices with \(4^3=64\) scalar multiplications, but Strassen's method beats this. Recall Strassen multiplies two \(2\times 2\) matrices using only 7 multiplications (instead of \(8\)), and crucially the seven products are combined using only additions and subtractions.

  1. View each \(4\times 4\) matrix as a \(2\times 2\) block matrix whose four blocks are themselves \(2\times 2\) matrices. Matrix multiplication respects this block structure: the product's blocks are computed by the same formulas as for scalar \(2\times 2\) multiplication, treating blocks as "entries."
  2. Apply Strassen at the block level. This produces the answer using \(7\) block-multiplications (plus block additions/subtractions, which cost no scalar multiplications).
  3. Each of those \(7\) operations is itself a product of two \(2\times 2\) matrices. Compute each one with Strassen again, using \(7\) scalar multiplications.
  4. The total is therefore \(7\times 7 = 49\) scalar multiplications, i.e. one level of recursion of Strassen on top of the base \(2\times 2\) case. Since \(49\le 49\), the bound is met.
In general \(T(2^k)=7\,T(2^{k-1})\) with \(T(2)=7\); here \(k=2\) gives \(T(4)=7\cdot 7=49<64\).
