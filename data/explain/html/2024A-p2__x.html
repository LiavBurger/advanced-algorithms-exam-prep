The algorithm estimates \(D(\varphi)\) by sampling. On input \(\varphi\):

  1. Draw \(t\) independent, uniformly random assignments \(\alpha_1,\dots,\alpha_t\in\{0,1\}^n\) (the value of \(t\) is chosen below).
  2. Evaluate \(\varphi(\alpha_1),\dots,\varphi(\alpha_t)\); each evaluation is fast (linear in the size of \(\varphi\)).
  3. Output \(A(\varphi)=\dfrac1t\sum_{i=1}^{t}X_i\), the fraction of the sampled assignments that satisfy \(\varphi\).

To analyze it, let \(X_i\) be an indicator random variable for the event that \(\alpha_i\) satisfies \(\varphi\). The \(X_i\) are mutually independent, and since \(\alpha_i\) is uniform over all \(2^n\) assignments, \(\mathbb{E}[X_i]=D(\varphi)\). Let \(X=\sum_{i=1}^{t}X_i\), so \(\mathbb{E}[X]=t\,D(\varphi)\) and the output is \(A(\varphi)=X/t\), giving \(\mathbb{E}[A(\varphi)]=D(\varphi)\).

By the Chernoff bound, the probability that the estimate is off by more than \(1/10\),

\[\Pr\!\left[\,|A(\varphi)-D(\varphi)|>\tfrac{1}{10}\,\right]\;\le\;e^{-O(t)},\]

shrinks fast as \(t\) grows. Taking \(t=O(n)\) makes this error drop below \(2^{-n}\), so with probability at least \(1-2^{-n}\) the output satisfies \(|A(\varphi)-D(\varphi)|\le \tfrac1{10}\). Since \(t=O(n)\) and each evaluation is fast, the algorithm runs in polynomial time.

Intuition. The density is just the chance a random assignment works, so a fraction over enough random tries lands close to it.
