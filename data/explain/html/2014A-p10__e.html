The objective value at any basic solution is found by plugging the current variable values into the objective. The most convenient form is the one from part (c), where the objective is already written using only the non-basic variables plus a constant.

  1. Recall from part (c) that the objective equals \(20+x_2+2x_3-2s_1\).
  2. Identify the new solution after the pivot of parts (c)–(d): the basis is \(\{x_1,x_3\}\), so the non-basic variables are \(x_2=0\) and \(s_1=0\), while the entering variable reached \(x_3=6\).
  3. Substitute these values: \[ 20+x_2+2x_3-2s_1=20+0+2(6)-0=20+12=32 . \]
After the first pivot the objective value is \(32\).

As a sanity check, this matches the increase predicted by the pivot: \(x_3\) entered with per-unit rate \(+2\) and rose by \(6\), adding \(2\times 6=12\) to the previous objective value of \(20\).
