Claim The Walsh–Hadamard transform \(H_n x\) can be computed in \(O(N\log N)\) time, where \(N=2^n\).

Strategy Split \(x\) in half, use the recursive block structure of \(H_n\) so only two half-size transforms are needed, then combine them cheaply.

Key idea The two block-rows of \(H_n\) reuse the same two subproducts \(H_{n-1}x_0\) and \(H_{n-1}x_1\), so one add and one subtract build the whole answer.

Why this move A matrix defined by self-similar \(2\times 2\) blocks is the FFT signal: divide and conquer, and shared subproducts collapse four multiplications into two.

  1. Split. Write \(x=(x_0,x_1)\), each half of length \(N/2=2^{n-1}\).
  2. Block formula. Using \(H_n=\begin{bmatrix}H_{n-1}&H_{n-1}\\ H_{n-1}&-H_{n-1}\end{bmatrix}\), \[H_n x=\begin{bmatrix}H_{n-1}x_0+H_{n-1}x_1\\ H_{n-1}x_0-H_{n-1}x_1\end{bmatrix}.\] Only the two products \(H_{n-1}x_0\) and \(H_{n-1}x_1\) appear.
  3. Recurse and combine. Recursively compute those two half-size transforms, then form the top half by adding and the bottom half by subtracting — \(O(N)\) work.
  4. Base case. At \(n=1\), \(H_1=\begin{bmatrix}1&1\\1&-1\end{bmatrix}\) is applied directly in \(O(1)\).

The cost satisfies \(T(N)=2\,T(N/2)+O(N)\), the same recurrence as merge sort and FFT, so \(T(N)=O(N\log N)\).
