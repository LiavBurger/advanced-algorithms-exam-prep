Claim True — every 3-CNF with \(m\) clauses has an assignment satisfying at most \(7m/8\) clauses.

Strategy Compute the average number of satisfied clauses over all assignments, then argue some assignment must sit at or below that average.

Key idea A random assignment satisfies exactly \(7m/8\) clauses in expectation, and no quantity is entirely above its own average.

Why this move "There exists an assignment with property X" is the classic cue for the averaging (probabilistic) argument — bound the average, then a real assignment must reach it.

  1. Expected count. Set each variable true or false by a fair coin. A 3-clause fails only when all three literals are false, probability \((1/2)^3 = 1/8\), so it is satisfied with probability \(7/8\). Let \(Y\) be the number of satisfied clauses; by linearity of expectation \(\mathbb{E}[Y] = 7m/8\).
  2. Average forces a witness. If every assignment satisfied strictly more than \(7m/8\), then \(\mathbb{E}[Y] > 7m/8\), a contradiction. So some assignment satisfies at most \(7m/8\) clauses.

Such an assignment always exists — the average is just a value that some actual assignment cannot exceed. The same mean also gives a witness for "at least" \(7m/8\).
