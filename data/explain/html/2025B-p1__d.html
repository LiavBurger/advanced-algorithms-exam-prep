Claim True — if \(\det(A+I)=0\) for the normalized adjacency matrix, then \(G\) is bipartite.

Strategy Turn the zero determinant into an eigenvalue statement, then use the class fact linking \(-1\) to bipartiteness.

Key idea \(\det(A+I)=0\) says exactly that \(-1\) is an eigenvalue of \(A\).

Why this move A vanishing determinant means the matrix is singular, and \(\det(A+I)=0\) is the standard signature of the eigenvalue \(-1\) — the one theorem tying the spectrum to bipartiteness.

  1. Singular matrix gives a vector. Since \(\det(A+I)=0\), the matrix is singular, so there is a nonzero \(v\) with \((A+I)v=0\), i.e. \(Av=-v\).
  2. Identify the eigenvalue. So \(v\) is an eigenvector of \(A\) with eigenvalue \(-1\).
  3. Use the class fact. For a connected regular graph, \(-1\) is an eigenvalue of the normalized adjacency matrix if and only if \(G\) is bipartite, so \(G\) is bipartite.
