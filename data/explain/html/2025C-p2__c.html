The algorithm: solve the dual LP \((D)\) to get an optimal \(y^\*\), then output the family \(C\) of sets whose dual constraint is tight (by part (b) this is a valid set cover). Solving an LP and reading off tight constraints is polynomial time, so the algorithm is efficient. We bound its cost using the frequency-\(f\) assumption: every element \(j\) lies in at most \(f\) of the sets \(S_1,\dots,S_m\).

  1. Tightness rewrites each set's cost. For every \(S_i\in C\) the constraint is tight, so \(c_i=\sum_{j:\,j\in S_i}y^\*_j\). Summing over the chosen sets, \[ \sum_{S_i\in C}c_i=\sum_{S_i\in C}\ \sum_{j\in S_i}y^\*_j. \]
  2. Swap the order of summation. Group the double sum by element \(j\): each \(y^\*_j\) is counted once for every chosen set that contains \(j\). Writing \(\bigl|\{S_i\in C:j\in S_i\}\bigr|\) for that count, \[ \sum_{S_i\in C}\sum_{j\in S_i}y^\*_j=\sum_{j=1}^n \bigl|\{S_i\in C:j\in S_i\}\bigr|\,y^\*_j. \]
  3. Apply the frequency bound. Element \(j\) appears in at most \(f\) sets overall, hence in at most \(f\) sets of \(C\). Since \(y^\*_j\ge0\), each coefficient is \(\le f\): \[ \sum_{j=1}^n \bigl|\{S_i\in C:j\in S_i\}\bigr|\,y^\*_j\ \le\ f\sum_{j=1}^n y^\*_j. \]
  4. Relate to the optimum. The sum \(\sum_j y^\*_j\) is the optimal value of \((D)\), which equals the optimal value \(\mathrm{LPOPT}\) of the primal relaxation (LP duality). Since the relaxation lower-bounds the integral set cover, \(\mathrm{LPOPT}\le\mathrm{OPT}\). Therefore \[ \sum_{S_i\in C}c_i\le f\cdot\mathrm{LPOPT}\le f\cdot\mathrm{OPT}. \]
The returned cover costs at most \(f\cdot\mathrm{OPT}\), so this is an efficient \(f\)-approximation for set cover with frequency \(f\).
