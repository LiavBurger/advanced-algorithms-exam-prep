The answer is Yes, and the reason is worth spelling out because it is exactly the point of randomization.

Key idea: the randomness lives in the algorithm's coin flips, not in the input. So the expected-time guarantee holds for every input, including the adversary's worst one.

For a deterministic algorithm, "worst case" and "average case" refer to averaging over inputs, so a bound proved on random inputs need not survive on the single nastiest input. Randomized selection is different: for a fixed input array, the running time \(T(n)\) is still a random variable, but the source of that randomness is the algorithm's own uniformly random pivot choices, not any assumption about the array.

  1. Fix any input array \(A\), even one chosen adversarially to be worst possible.
  2. The analysis bounds \(\mathbb{E}[T(n)]\) where the expectation is taken over the internal coin flips (pivot selections). Nowhere does it assume the array elements are random or ordered in a lucky way.
  3. Hence the bound \(\mathbb{E}[T(n)] = O(n)\) is a statement about the worst-case input, averaged over the algorithm's randomness.

So yes: the expected-running-time analysis applies to the worst-case input array. An adversary who sees the array but not the future coin flips cannot force bad behavior in expectation.
