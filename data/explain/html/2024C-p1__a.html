True. A point \(y\in P=\{x:Ax=b,\ x\ge 0\}\) is a vertex if and only if the columns of \(A\) at the coordinates where \(y\) is strictly positive are linearly independent, i.e. the submatrix \(A_y\) built from those columns has full column rank. This characterization was proved in class.

Consequently a vertex is determined by its support, the set of coordinates on which it is positive: if two vertices had the same support \(S\), both would be the solution of \(A_S z=b\) with \(A_S\) having independent columns, so that solution is unique and the two vertices coincide. Each support is a subset of the \(n\) columns of \(A\), and there are only \(2^n\) subsets of an \(n\)-element set. Hence there are at most \(2^n\) possible supports, so at most \(2^n\) vertices.

Intuition. Each vertex is pinned down by which coordinates it turns on, and there are only \(2^n\) such on/off patterns.
