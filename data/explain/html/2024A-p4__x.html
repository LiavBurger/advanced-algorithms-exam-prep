Weighted Max-SAT: given a CNF formula \(\varphi\) with variables \(x_1,\dots,x_n\) and clauses \(C_1,\dots,C_m\) of nonnegative weights \(w_1,\dots,w_m\), find a truth assignment maximizing the total weight of satisfied clauses. We encode it as an integer program with two families of binary variables.

Variables: for each Boolean variable \(x_i\) introduce \(y_i\in\{0,1\}\) with \(y_i=1\) meaning \(x_i\) is set true. For each clause \(C_j\) introduce \(z_j\in\{0,1\}\), intended to be \(1\) exactly when \(C_j\) is satisfied. Let \(C_j^{+}\) (resp. \(C_j^{-}\)) be the set of variables appearing positively (resp. negated) in \(C_j\).

The IP is \[\text{maximize}\ \sum_{j=1}^{m} w_j z_j\quad\text{s.t.}\quad z_j\le \sum_{i\in C_j^{+}} y_i+\sum_{i\in C_j^{-}}(1-y_i)\ \ (1\le j\le m),\qquad y_i,z_j\in\{0,1\}.\]

  1. A literal-satisfaction count. For a positive literal \(x_i\) the term \(y_i\) is \(1\) iff that literal is true; for a negative literal \(\lnot x_i\) the term \((1-y_i)\) is \(1\) iff \(x_i\) is false, i.e. iff that literal is true. So the right-hand side counts how many literals of \(C_j\) are satisfied.
  2. The constraint links \(z_j\) to satisfaction. If no literal of \(C_j\) is satisfied, the sum is \(0\), forcing \(z_j\le 0\), so \(z_j=0\). If at least one literal is satisfied, the sum is \(\ge 1\), so \(z_j\) is allowed to be \(1\). Since \(z_j\) has positive coefficient \(w_j\ge 0\) in a maximization, the optimum sets \(z_j=1\) whenever it is permitted. Thus at optimum \(z_j=1\) iff \(C_j\) is satisfied.
  3. Feasible solutions match assignments. Any assignment to \(x_1,\dots,x_n\) is the same as choosing \(y_1,\dots,y_n\); the constraints then permit \(z_j=1\) exactly for satisfied clauses, and the objective \(\sum_j w_j z_j\) is the total satisfied weight. Maximizing it therefore solves weighted Max-SAT.
